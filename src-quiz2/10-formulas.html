Formulas to remember

Know these by heart. They're where each proof starts and what it boxes at the end. Every one is proved further down.

1 · 2-D stability and limit cycles

  • Eigenvalue equation\(\lambda^2 - \tau\lambda + \Delta = 0\), with \(\tau = a + d\), \(\Delta = ad - bc\), so \(\lambda = \frac{\tau\pm\sqrt{\tau^2 - 4\Delta}}{2}\)
  • Classify\(\Delta<0\) saddle. Otherwise \(\tau<0\) stable, and \(\tau^2>4\Delta\) node, \(\tau^2<4\Delta\) spiral, \(\tau = 0\) center
  • Jacobian\(J_{ij} = \partial f_i/\partial x_j\) at the fixed point. Stable if every eigenvalue has negative real part
  • Rabbits vs sheep\(\dot x = x(3 - x - 2y)\), \(\dot y = y(2 - x - y)\). \((1,1)\) is a saddle, so one species wins
  • Predator–prey\(\dot N = N(a - bP)\), \(\dot P = P(cN - d)\). Center at \((d/c,\ a/b)\), \(\lambda = \pm i\sqrt{ad}\)
  • Hopf normal form\(\dot z = (\mu + i\omega - |z|^2)z\) gives \(\dot r = \mu r - r^3\), \(\dot\theta = \omega\)
  • Limit cycleRadius \(\sqrt\mu\), stable for \(\mu>0\). Origin eigenvalues \(\mu\pm i\omega\). Supercritical Hopf at \(\mu = 0\)
  • Van der Pol\(\ddot x + \mu(x^2 - 1)\dot x + x = 0\). Pushes small swings out, damps big ones, so there's a cycle in between
  • Poincaré–BendixsonA trapping region with no fixed point holds a closed orbit. 2-D only, so no chaos in 2-D

2 · Maps

  • Fixed point\(x^* = f(x^*)\)
  • StabilityStable iff \(|f'(x^*)|<1\), because \(\varepsilon_{n+1} = f'(x^*)\varepsilon_n\)
  • Euler with \(\Delta t = 1\)\(\dot x = x(K-1) - Kx^2\) becomes \(x_{n+1} = Kx_n(1 - x_n)\)
  • Logistic map\(x_{n+1} = rx_n(1 - x_n)\), \(f'(x) = r(1 - 2x)\). \(x^* = 0\) stable for \(r<1\). \(x^* = 1 - 1/r\) has \(f' = 2 - r\), stable for \(1
  • 2-cycle\(x_\pm = \frac{(r+1)\pm\sqrt{(r-3)(r+1)}}{2r}\), born at \(r = 3\)
  • Route to chaosPeriod doubles at 3, 3.449, 3.544. Chaos from about 3.57
  • Examples\(x^2\): 0 stable, 1 unstable. \(\cos x\): \(x^*\approx0.739\), stable

3 · Lorenz

  • Equations\(\dot x = \sigma(y - x)\), \(\dot y = \rho x - y - xz\), \(\dot z = xy - \beta z\)
  • Fixed points\((0,0,0)\), and for \(\rho>1\): \(\left(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho - 1\right)\)
  • Jacobian\(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}\)
  • OriginStable iff \(\rho<1\)
  • ChaosAbove \(\rho\approx24.74\) (for \(\sigma = 10\), \(\beta = 8/3\))

4 · Synchronisation

  • Two oscillators\(\dot\theta_1 = \omega_1 + k_1\sin(\theta_2 - \theta_1)\), \(\dot\theta_2 = \omega_2 + k_2\sin(\theta_1 - \theta_2)\)
  • Phase difference\(\dot\phi = (\omega_2 - \omega_1) - (k_1 + k_2)\sin\phi\)
  • LockingIff \(|\omega_2 - \omega_1|\le k_1 + k_2\). Equal couplings: \(k_c = |\omega_2 - \omega_1|/2\)
  • Common frequency\(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}\)
  • Kuramoto\(re^{i\psi} = \frac1N\sum_j e^{i\theta_j}\), \(\dot\theta_i = \omega_i + Kr\sin(\psi - \theta_i)\)
  • Critical coupling\(K_c = \frac{2}{\pi g(0)}\). Lorentzian: \(K_c = 2\gamma\), \(r = \sqrt{1 - K_c/K}\)
