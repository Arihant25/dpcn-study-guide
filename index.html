Before any content, it helps to know the shape of the target. Every past paper in your folder falls into one of three moulds, and each one rewards a slightly different kind of preparation. Match your effort to the mould and you stop wasting time.

Read this first

Three formats, three habits

The surprise quizzes are multiple-choice on MS Forms. They test whether you can recognise a definition quickly — "which centrality counts direct connections?", "what does a high out-degree mean in a citation network?". There is no arithmetic, but the wording is often negated: "which statement is wrong", "which characteristics do NOT define a spanning tree". The single most common way people lose marks here is misreading that negation, so read every option twice.

The written Quiz 1 (around 20 marks) asks you to actually compute things — a clustering coefficient, a betweenness, an in/out-degree sequence — and to state properties of star and complete graphs. The instruction that matters most is printed on the paper itself: "only attempting the options will NOT fetch marks — give a one-line reason for each." A bare answer, even a correct one, scores zero. Always write the sentence of reasoning.

The proof / derivation questions (in the surprise quizzes, Quiz 2, and the mid-sem) are where he stretches you: prove that the number of triangles equals 16tr(A3), work out when a discrete map is stable, solve the SIS equation. Section 15 is built entirely for these, and every step is spelled out.

Convention trap

Your course's own bifurcation note draws stability the opposite way to most textbooks: it uses dashed lines for stable branches and solid lines for unstable ones. Strogatz and almost every other book do the reverse. Every diagram in this guide is labelled by colour and by word as well, so you never have to rely on the line style. But if a bare diagram turns up on the paper, read it by his convention: dashed = stable.

0Network science, in brief

The opening module is mostly motivation. Only a handful of facts from it appear in the MCQs, so hold onto these rather than the stories around them.

What makes a system "complex"

A complex system is made of many parts that interact, where those interactions change over time, and where the behaviour of the whole is not simply the sum of the parts. The headline idea is emergence: a pattern the whole system shows that no single component carries on its own — a crowd synchronising, an epidemic wave, a traffic jam forming out of individual cars.

A complex network is just the diagram you draw to study such a system. You represent each part as a node (also called a vertex) and each interaction as a link (also called an edge). Once the system is a network, you can measure it — and that is the whole game of this course.

One more fact that shows up: networks come in directed and undirected flavours. The Web and citation networks are directed (a link points one way). The physical internet, power grids, and co-authorship networks are undirected (the link is mutual).

1Graphs & the adjacency matrix

Almost everything else in Block A — degree, paths, triangles, centralities — is read off one object: the adjacency matrix. If you get comfortable turning a picture into this matrix and back, half of Quiz 1 becomes free marks.

Definition

The adjacency matrix A

Give every node a number from 1 to N. The adjacency matrix is the N×N grid of numbers where the entry in row i, column j records whether there is an edge from node i to node j:

Aij = { 1if an edge joins i to j 0otherwise

Two nodes joined by an edge are called adjacent, and the edge is said to be incident to each of them. That vocabulary turns up in MCQ options.

Here is a concrete example. The picture and the matrix below describe the same four-node network — the picture is what you see, the matrix is how the computer stores it.

A= [ 0110 1011 1100 0100 ]

Read row 2, for instance: it has 1's in columns 1, 3 and 4, which says node 2 is joined to nodes 1, 3 and 4. Notice the matrix is a mirror image across its diagonal — that is what "undirected" looks like numerically.

The properties he turns into MCQ options

These come up almost verbatim on the surprise quizzes, so learn to say why each is true or false.

  • It is always square, of size N×N — one row and one column per node.
  • Undirected ⇒ symmetric. If i links to j then j links to i, so Aij=Aji. A directed graph is generally not symmetric.
  • No self-loops ⇒ the diagonal is all zeros. A node is not joined to itself, so Aii=0. A 1 on the diagonal means a self-loop.
  • Binary vs weighted. In a plain (binary) graph the entries are only 0 or 1. In a weighted graph you store a real number wij — the strength of the link — instead of just 1.
  • A disconnected graph gives a block-diagonal matrix. If you number the nodes so that each component's nodes are grouped together, the matrix splits into separate blocks along the diagonal with zeros between them. So "there are non-zero entries between the components" is false.
  • The rank can be less than N, even for a connected graph — the matrix may be singular (non-invertible). So "the rank is always N" is false.
Common trap

"If two vertices are connected, the entry is always 1" is false for a weighted graph — there the entry is the weight, which need not be 1. It is only guaranteed to be 1 in an unweighted graph. Always check whether the question says "binary" or "unweighted" before ticking that option.

2Degree, in/out-degree & the handshaking lemma

The degree of a node is simply "how many links does it have". It is the most basic measure of importance, and it is the raw material for the handshaking lemma and the triangle-counting proof later on.

Definition

Degree in an undirected graph

The degree of node i, written ki, is the number of edges touching it. Because row i of the adjacency matrix has a 1 for every neighbour of i, you get the degree just by adding up that row:

ki= ∑jAij

The symbol ∑j means "add up over every column j". Since an undirected matrix is symmetric, adding the row or the column gives the same answer.

Directed graphs: split the count in two

When links have a direction (an arrow), a node has two separate degrees. The in-degree counts arrows pointing at the node; the out-degree counts arrows pointing away from it. With the convention that Aij=1 means "an arrow from i to j":

kiout =∑jAij (row sum) kiin =∑jAji (column sum)

In one sentence: row‑sum = out-degree, column‑sum = in-degree. Memorise that direction — a whole question depends on getting it the right way round.

You are handed only the matrix. The last node has a 1 on the diagonal, which is a self-loop — it counts once for in and once for out.

Key theorem

The handshaking lemma

Add up the degrees of every node and you always get exactly twice the number of edges:

∑iki=2L

The reason is simple: each edge has two ends, so when you walk around counting degrees, every edge gets counted once at each of its two endpoints — twice in total. (The full write-up is Proof 2 in §15.) A useful consequence: the number of odd-degree nodes is always even. That single fact is what makes the Eulerian criterion in §5 work.

Reading the meaning (MCQ)

In a citation network (arrows point from a paper to the papers it cites): a high in-degree means "cited by many" — an influential article. A high out-degree means "cites many" — typically a review or a book. In a co-authorship network the links are undirected, so in-degree equals out-degree; a researcher with 10 collaborators simply has degree 10, and cannot be "isolated".

3Mean degree & link density

Two summary numbers for a whole network: on average how many links does a node have, and how "full" is the network compared to the most links it could possibly have.

Mean degree

The mean degree ⟨k⟩ is just the average of all the individual degrees. Add every degree and divide by the number of nodes. Using the handshaking lemma (the degrees add to 2L) this simplifies nicely:

⟨k⟩ = 1N∑iki = 2LN (undirected)

For a directed network each edge contributes 1 to some node's out-degree and 1 to some node's in-degree, so the average in-degree equals the average out-degree, and both equal ⟨k⟩=L/N.

Link density

The link density ρ asks: of all the links that could exist, what fraction actually do? In a simple undirected graph on N nodes, the largest possible number of edges is every distinct pair joined once, which is N(N−1)2. So the density is the edges you have divided by that maximum:

ρ= LN(N−1)/2 = 2LN(N−1) = ⟨k⟩N−1

The last form says something intuitive: density is the average degree measured against the biggest degree a node could have, which is N−1 (linked to everyone else).

Exam favourite

The Erdős–Rényi relation: ⟨k⟩=p(N−1)

In the Erdős–Rényi random graph you take N nodes and join each possible pair independently with probability p. Think about one node: it has N−1 possible partners, and each becomes a real link with probability p. The expected number of links it ends up with is therefore probability × opportunities:

⟨k⟩=p(N−1) ≈pN and L=p·N(N−1)2

Quiz 1 asks exactly this — "the relationship between p, ⟨k⟩ and N". Give the formula and the one-line reason (probability times number of possible partners). The ≈pN version holds when N is large so that N−1≈N.

4Walk, trail, path, cycle, circuit

Five words that sound interchangeable but are examined precisely. The only thing that separates them is what you are forbidden from repeating as you move through the graph — an edge, a vertex, or nothing.

Start with the loosest idea and add restrictions:

  • A walk is any route at all — hop from node to node along edges, repeating whatever you like.
  • A trail is a walk that never reuses the same edge. You may pass through a node twice, as long as you arrive and leave on different edges each time.
  • A path is stricter still: it never revisits the same vertex (and so automatically never reuses an edge either).

"Closed" just means you finish where you started. A closed trail is a circuit; a closed path is a cycle.

TermThe ruleMay repeat a vertex?May repeat an edge?
Walkany route along edgesyesyes
Trailno repeated edgeyesno
Pathno repeated vertexnono
Circuitclosed trail (start = end)yesno
Cycleclosed path (start = end)no (except the endpoints)no

The handy nesting to remember: every path is a trail, and every trail is a walk. A path is the most restrictive; a walk is anything goes.

5Eulerian & Hamiltonian graphs

This is the module's signature topic — the Königsberg bridges — and it appears both as a quick MCQ and as a "justify your answer" written question. The whole thing rests on one idea: count the odd-degree nodes.

Definition

Two very different questions, easy to mix up:

  • Eulerian is about edges. An Eulerian trail uses every edge exactly once. An Eulerian circuit does the same and returns to where it started.
  • Hamiltonian is about vertices. A Hamiltonian path visits every vertex exactly once. A Hamiltonian circuit does that and returns to the start.

Slogan: Euler = every edge once, Hamilton = every vertex once.

The criterion — this is the whole game

For a connected graph, look only at how many nodes have an odd degree. That number alone decides everything:

Number of odd-degree nodesWhat existsWhere it must start and end
0 (every degree even)an Eulerian circuit (and trail)anywhere; you return to the start
exactly 2an Eulerian trail, but no circuitstart at one odd node, finish at the other
more than 2neither trail nor circuit—

Why never "exactly 1 or 3"? Because the handshaking lemma from §2 guarantees the count of odd-degree nodes is always even. So the only cases that can arise are 0, 2, 4, 6, …

Worked

Why you can't cross every bridge exactly once

All four nodes have odd degree. Four odd nodes is "more than 2", so by the criterion no Eulerian trail exists — there is no way to walk across all seven bridges using each exactly once. That was Euler's answer in 1735, and it launched graph theory.

"How could you make it possible?" You need to get the odd count down to 2 (or 0). Removing one bridge that connects two odd land masses turns both of them even, leaving exactly two odd nodes — and then an Eulerian trail becomes possible, starting at one of the two remaining odd nodes and ending at the other. (Adding a bridge between two odd nodes does the same job.)

The distinction he asks outright

"Main difference between an Eulerian and a Hamiltonian path?" An Eulerian path is about covering every edge once (you're allowed to revisit nodes); a Hamiltonian path is about covering every vertex once (you're allowed to skip edges). And crucially, Eulerian has the clean odd-degree test above, whereas Hamiltonian has no simple criterion — deciding it is a genuinely hard problem, so you settle it by trying to construct one by hand.

Quiz 1Graph with edges 6–4, 4–5, 4–3, 5–1, 5–2, 3–2, 2–1: is there a Hamiltonian path? An Eulerian trail or circuit? If not, how do you create an Eulerian trail?›

Degrees: node 6 = 1, node 4 = 3, node 5 = 3, node 3 = 2, node 2 = 3, node 1 = 2.

Odd-degree nodes: 6, 4, 5, 2 — that is four. Four is more than two, so there is no Eulerian trail and no Eulerian circuit.

Hamiltonian path: try to string all six nodes together with no repeat, e.g. 6→4→3→2→1→5. Check each step is a real edge: 6–4 ✓, 4–3 ✓, 3–2 ✓, 2–1 ✓, 1–5 ✓. All six visited once, so yes, a Hamiltonian path exists.

To create an Eulerian trail: you must cut the odd count from 4 down to 2. Add one edge between two of the odd nodes — say join 6 and 5, or 4 and 2 — which makes both of them even. Two odd nodes then remain, and an Eulerian trail exists that starts at one of them and ends at the other. (Equivalently, delete an edge that currently joins two odd nodes.)

6Distance, shortest path, diameter & BFS

"How far apart are two nodes?" In a network, distance is not measured in metres — it is measured in hops, the number of links you must cross.

Definitions
  • The distance d(i,j) between two nodes — also called the shortest path or geodesic — is the smallest number of edges on any route connecting them. If they are in different components there is no route, so d=∞.
  • In a directed graph you must follow the arrows, so the distance from A to B can differ from the distance from B to A.
  • The diameter is the largest distance between any pair of nodes — the "width" of the network, the worst case.
  • The average path length ⟨d⟩ is the mean distance taken over every pair.
⟨d⟩ = ∑i<jd(i,j) N(N−1)/2

The denominator N(N−1)/2 is just the number of distinct pairs of nodes — you are averaging one distance per pair.

Shortest paths come from BFS

Breadth-first search (BFS) is how you actually find these distances. Starting from one node, you visit the graph in layers: first all its direct neighbours (distance 1), then all of their not-yet-seen neighbours (distance 2), and so on outward. The layer in which a node first appears is its distance from the source — which is exactly why BFS gives shortest paths in an unweighted graph.

Also examined

Connected components and the Laplacian

A connected component is a maximal group of nodes that can all reach each other. The graph Laplacian is defined as L=D−A, where D is the diagonal matrix of degrees. Its key property, which he asks directly, is:

number of components=nullity of L =multiplicity of eigenvalue 0

So a graph with 3 separate components has a Laplacian whose eigenvalue 0 appears three times (its null space is 3-dimensional). The second-smallest Laplacian eigenvalue is the "algebraic connectivity": the bigger it is, the more robustly connected the graph.

7Clustering coefficient

This answers "do my friends know each other?". It is the single most-computed quantity across Quiz 1 and the surprise quizzes, so it is worth being able to do in your head.

Definition

Local clustering coefficient

Take a node i with degree ki (so it has ki neighbours). Now ignore i itself and look only at those neighbours: how many of them are linked to each other? The clustering coefficient is the fraction of possible neighbour-to-neighbour links that are actually present.

Ci = links among the neighbours of i possible links among them = 2ei ki(ki−1)

Here ei is the number of edges that actually exist between i's neighbours. The denominator ki(ki−1)2 is the number of pairs among the neighbours, i.e. the most links they could possibly have. The result is always between 0 (no friends of mine know each other) and 1 (all of them do). If a node has fewer than two neighbours, Ci is taken to be 0.

Worked · the MCQ answer

Node A has neighbours B, C, D; B and C are not linked — the minimum CA?

Three neighbours means kA=3, and the number of possible links among them is 3·22=3. We are told B–C is missing. The smallest non-zero situation the options allow has exactly one of the remaining pairs linked (say B–D), giving

CA=2·13·2=13≈0.33
Quiz 1 technique

When asked for CX from a drawn graph: (1) list the neighbours of X; (2) count edges that run between those neighbours only — ignore X's own edges; (3) divide by k(k−1)2. A hub whose neighbours are all leaves has C=0; a node sitting inside a single triangle has C=1.

8The four centralities

"What makes a node important?" has four standard answers, and they disagree with each other on purpose. The surprise quizzes test which one is which; Quiz 1 tests computing them. Learn both the plain-English idea and the formula for each.

CentralityA node is important if…How you measure it
Degreeit has many direct linksCD(i)=ki
Closenessit is close to everyone (small distances)CC(i)=1∑jd(i,j)
Betweennessmany shortest paths run through it (a bridge)CB(v)=∑s≠tσst(v)σst
Eigenvectorit is linked to other important nodesAx=λx

In the betweenness formula, σst is the number of shortest paths from s to t, and σst(v) is how many of those pass through v. Centralities are used to name the most influential person in a social network, the most critical routers on the internet, or the biggest disease-spreaders.

Eigenvector centrality — the recursive idea, unpacked

Definition

Degree centrality gives one point for every link, treating all neighbours as equal. Eigenvector centrality says that's too crude: a link from an important node should count for more than a link from a nobody. So a node's score is built from its neighbours' scores. Writing xi for the score of node i:

xi = 1λ ∑jAijxj ⟺ Ax=λx

Read the left form as: "my score is the sum of my neighbours' scores (divided by a constant λ)". That self-referential rule is exactly the definition of an eigenvector: the score vector x is the eigenvector of the adjacency matrix belonging to its largest eigenvalue λ (chosen because it is the one guaranteed to give all-positive scores).

On a straight line, a node in position i sits on the shortest route of every pair that has one node on its left and one on its right — there are (i−1) nodes to the left and (N−i) to the right, so its betweenness is their product (i−1)(N−i). Bipartite graphs

A bipartite graph splits the nodes into two groups, with every edge crossing from one group to the other and none staying inside a group. Reach for it whenever you are relating two different kinds of thing: users and movies, authors and papers, buyers and sellers, customers and products, genes and pathways, airports and airlines. It is not the right model for a single-type network like friendships between individuals, because those links stay within one group.

Spanning tree

A spanning tree of a connected graph is a "skeleton" that keeps everything joined using as few edges as possible. On N nodes it must:

  • include all N nodes,
  • stay connected and be acyclic (contain no cycle), and
  • have exactly N−1 edges.

The trap options are "it must contain a cycle" and "it need not have N−1 edges" — both false, because a tree by definition has no cycle and always has exactly N−1 edges. To build one, keep removing edges that lie on a cycle (one per independent cycle) until none remain, while never disconnecting the graph.

10Fixed points & linear stability

The whole of nonlinear dynamics on this quiz boils down to two questions about a system: where does it sit still, and if you nudge it, does it come back or run away. Everything else is detail on top of these.

Definition

A one-dimensional system is written x˙=f(x), where the dot means "rate of change with time", dxdt. A fixed point (also: equilibrium, steady state) is a value x* where the rate of change is zero, so the system, once there, stays there forever:

f(x*)=0

The phase-line picture — no calculus needed

Plot x˙=f(x) against x. The sign of the curve tells you which way x is being pushed at each point:

  • Where the curve is above the axis, x˙>0, so x is increasing — the arrow points right.
  • Where it is below the axis, x˙<0, so x is decreasing — the arrow points left.
  • Where it crosses the axis, x˙=0 — that is a fixed point.

Now the key insight: look at the arrows on either side of a fixed point. If they both point toward it, any small nudge dies away and the point is stable. If they point away, a nudge grows and it is unstable.

Shortcut for reading a plot: where the curve crosses the axis going from + down to −, the fixed point is stable; crossing from − up to +, it is unstable.

The one criterion to know cold

Linear stability (continuous system)

Instead of drawing arrows you can just check the slope of f at the fixed point:

f′(x*)<0 ⟹stable f′(x*)>0 ⟹unstable

The reason (derived step-by-step in §15) is that a small nudge η grows or shrinks like η(t)≈η(0)ef′(x*)t — it only decays when the exponent is negative. If f′(x*)=0 the test is inconclusive, and that borderline is precisely where bifurcations live (§12).

On the slides · flow on the line

Charging a capacitor (RC circuit)

A neat physical example of reading an equation as a phase line. For a resistor and capacitor charged by a battery of voltage V0, Kirchhoff's law says V0−qC=iR. Since the current is the rate of change of charge, i=dqdt, this is a one-dimensional flow:

q˙=f(q)= V0R−qRC
  1. Fixed point: set f(q*)=0 ⇒ q*=CV0 — the fully-charged state.
  2. Stability: the slope is f′(q)=−1RC<0 everywhere, so q* is stable — the charge always heads toward CV0 regardless of where it starts.
  3. Solution over time (integrating the linear equation): the charge rises from 0 up to its maximum,
    q(t)=CV0(1−e−t/RC)
    with q(0)=0 and q→CV0 as t→∞. The constant RC is the time it takes to close most of the gap.
Continuous vs discrete — do not mix these up

For a step-by-step iterated map xn+1=f(xn) the rule is different: a fixed point is stable when the size of the slope is below one, |f′(x*)|<1 — not simply f′<0. So: continuous flow uses the sign of f′; a discrete map compares the magnitude of f′ against 1. He has set the discrete version (the logistic map and cosx) — see §15.

11Euler's method (numerical integration)

Most models in this course can't be solved with a neat formula, so the computer marches the solution forward in small time steps. Euler's method is the simplest way to do that, and you should be able to write its update rule and name its two sources of error.

The tangent-line method

You know the starting value y(t0)=y0 and you know the slope everywhere, because the slope is the differential equation y˙=f(t,y). So take a small step h forward along the current slope, land on a new point, read off the new slope there, and repeat:

yn+1 = yn + h·f(tn,yn)

Each step is "new value = old value + step size × slope". Smaller h means a more accurate but slower march.

On the slides · estimating a slope

Forward vs central difference

Both Euler's method and the demos need to estimate a derivative from nearby values. The obvious way is the forward difference — rise over run using the point just ahead:

f′(x)≈ f(x+h)−f(x)h (first order, error O(h))

A sharper trick is the central difference, which uses the points on both sides. Because you straddle x symmetrically, the leading h2 error terms from the two Taylor expansions cancel, leaving an error one order smaller:

f′(x)≈ f(x+h)−f(x−h)2h (second order, error O(h2))

Same step size, smaller error — that is why central differences are preferred when you can look both ways. (At the very start of a simulation you only have the forward point, so Euler uses the forward version.)

The two kinds of error (an MCQ topic)

  • Truncation (discretisation) error comes from approximating a curve by its tangent line — you are throwing away the higher-order bends. It would happen even on a perfect, infinitely precise computer, and it shrinks as h→0. Euler's method is "first-order accurate", meaning this error scales like h per step.
  • Round-off error comes from the computer storing numbers with only finitely many digits. Counter-intuitively it gets worse if you make h ridiculously small, because you then take far more steps and accumulate more tiny rounding mistakes. The higher-accuracy method used in the demos, RK4, reduces the truncation error dramatically for the same step size.

13Bistability & hysteresis (Spruce Budworm)

The interesting behaviour in ecology and physics — tipping points, sudden collapse, states that depend on history — happens when a system can settle into two different stable states. The Spruce Budworm model is the course's worked example of this.

The model
x˙ = rx(1−xK) − x21+x2 , K=10,r>0

The first term is ordinary logistic growth of the budworm population. The second is predation (birds eating budworms) that saturates — birds can only eat so fast. Setting the whole thing to zero to find the non-zero equilibria leads to a cubic equation, and a cubic can have three positive roots. That is why up to three steady states can coexist.

The core concepts
  • Bistability. For roughly 0.384≲r≲0.560 the system has three positive equilibria in the pattern stable – unstable – stable. The low stable one is a "refuge" population; the high stable one is an "outbreak".
  • The middle, unstable equilibrium acts as a threshold. Start below it and the population slides down to the low state; start above it and it climbs to the high state. (At r=0.5 the threshold is near x=2: below it you fall to ≈ 0.68, above it you rise to ≈ 7.3.)
  • Hysteresis. Turn r up slowly and the population clings to the low branch until that branch simply disappears (the upper fold), then it jumps up. Turn r back down and it clings to the high branch until the lower fold. The path up is not the path down — that gap is hysteresis, and the folds are saddle-node bifurcations.
Fold detection (a derivation he likes)

A fold (saddle-node) is the special place where a fixed point exists and the curve x˙ only just touches the axis — it is tangent to it. So you solve two equations at once:

f(x*;r)=0 and f′(x*;r)=0

Solving both together gives the two critical values of r (about 0.384 and 0.560 for K=10). On a x˙-versus-x plot, a curve just kissing the axis is the visual signature of a saddle-node.

14SIS, SIR & predator–prey

Three dynamical models the course applies to disease and ecology. The SIS derivation is a mid-sem staple, while the SIR and predator–prey facts turn up as MCQs.

SIS — susceptible ⇄ infected (you can catch it again)

Model & solution

Split the population into a fraction s that is susceptible and a fraction i that is infected, with s+i=1. Infection happens when a susceptible meets an infected (rate β), and infected people recover back to susceptible (rate γ):

didt =βsi−γi

Now use s=1−i to write everything in terms of i:

didt =βi(1−i)−γi =(β−γ)i−βi2

This is the logistic equation. Setting didt=0 and discarding i=0 gives the endemic equilibrium — the long-run infected fraction:

i*=1−γβ=1−1R0 where R0=βγ
The threshold — asked every time

The quantity R0=β/γ (the basic reproduction number) decides everything:

R0>1 ⟹disease spreads, settles at i*>0 R0<1 ⟹dies out

So "in which condition does the disease not spread?" — when β<γ (people recover faster than they infect), i.e. R0<1. This matches the stability rule: the disease-free state i=0 has slope f′(0)=β−γ, which is negative (stable) exactly when β<γ.

SIS on a network — the eigenvalue threshold

On a network, each node k follows i˙k=−γik+β(1−ik)∑jAkjij. Right at the start of an outbreak every ik is tiny, so the ik-times-ij term is negligible and the equation becomes linear:

i˙ ≈ (βA−γI)i ⟹ growth rate=βλmax−γ

The infection grows only if that rate is positive, so the network sets the threshold through its largest adjacency eigenvalue λmax:

(βγ)c = 1λmax

This is the answer to "how does the network affect the infection at the start?" — through λmax. Denser, more connected networks have a larger λmax, which lowers the threshold, so disease spreads more easily.

SIR — susceptible → infected → removed (immunity or death)

dsdt=−βsi didt=βsi−γi drdt=γi
  • The susceptible fraction can only ever decrease (there is no arrow back into S), dropping roughly exponentially as the epidemic runs.
  • The infectious period is assumed the same for everyone — a constant recovery rate γ — with homogeneous mixing.
  • At any steady state the three rates of change sum to zero, because the total population s+i+r is conserved. An outbreak only takes off if R0=β/γ>1 while almost everyone is still susceptible.
On the slides · SIR-X (quarantine)

The COVID-era extension adds a compartment X for quarantined people, removed from circulation by containment. Susceptibles are pulled out at rate k0 and infecteds are quarantined at rate k:

dSdt=−βSI−k0S dIdt=βSI−γI−k0I−kI dRdt=γI+k0S dXdt=(k+k0)I

It is just SIR with two extra "drain" terms that move people into quarantine — stronger containment (larger k,k0) pulls the effective growth rate of I below zero sooner.

Predator–prey (Lotka–Volterra)

Key behaviour (MCQ)
  • The two populations oscillate: prey grow, predators grow after them, prey crash from being eaten, predators then starve and crash, and the cycle repeats. They do not settle quietly at a constant level.
  • The equilibrium levels shift with the parameters — a higher predation rate lowers the predators' steady level, a higher prey birth rate raises it, and introducing a competing species does affect stability.
  • Starting the prey above its carrying capacity just feeds into the same oscillating cycle, not a smooth settle.

15Proofs he actually asks

The surprise quiz that asked you to prove triangles=16tr(A3) is the giveaway: he wants derivations, not just recall. These are the ones that fit the current syllabus, and each one is spelled out line by line — nothing skipped.

Proof 1 · the one he sprang on you

Number of triangles =16tr(A3)

Step A — what does multiplying A by itself even count? Start with the powers of the adjacency matrix. The claim is that the entry in row i, column j of An is exactly the number of walks of length n (i.e. using n edges) that go from node i to node j.

See why for n=2 first. By the rule for matrix multiplication, the (i,j) entry of A2 is a sum over every possible middle node k:

(A2)ij = ∑k Aik Akj

Look at one term AikAkj. It equals 1 only when both Aik=1 (there is an edge i–k) and Akj=1 (there is an edge k–j) — which is precisely one two-step walk i→k→j. Adding over all middle nodes k counts every such two-step walk. The same argument repeated (multiply by one more A to tack on one more edge) gives the general result for any power n.

Step B — apply it at n=3 and look at the diagonal. The diagonal entry (A3)ii counts walks of length 3 that start and end at the same node i. A three-step walk that comes back to where it started is a triangle: i→a→b→i only closes up if i,a,b are three mutually connected nodes. The trace adds up all these diagonal entries:

tr(A3) = ∑i(A3)ii = total number of closed 3-step walks

Step C — count how badly a single triangle is over-counted. Take one triangle on nodes a,b,c. How many closed 3-walks does it produce?

  • You can start at any of its 3 corners — start at a, or b, or c. That is a factor of 3.
  • From each start you can go around in 2 directions — clockwise (a→b→c→a) or anticlockwise (a→c→b→a). That is a factor of 2.

So each triangle shows up 3×2=6 times inside tr(A3). To recover the true number of triangles, divide by 6:

number of triangles = 16tr(A3) ∎

Handy relatives he may combine with this: the diagonal of A2 gives degrees, (A2)ii=ki (a closed 2-walk is just "out along an edge and back"), so tr(A2)=∑iki=2L.

Proof 2

Handshaking lemma: ∑iki=2L

Count the same thing two different ways: the number of "(node, edge-touching-it)" pairs, called incidences.

Way one — go node by node. Each node i is touched by ki edges (that is the definition of degree), so the total number of incidences is ∑iki.

Way two — go edge by edge. Each edge has exactly two ends, so it contributes exactly 2 incidences. With L edges that is 2L.

Both count the identical set of incidences, so they must be equal: ∑iki=2L. ∎

The corollary he cares about: 2L is even. Even numbers only come from adding an even count of odd numbers, so the number of odd-degree nodes must itself be even. That is why an Eulerian graph can only have 0 or 2 odd nodes — never exactly 1.

Proof 3 · continuous stability

Why f′(x*)<0 means stable

Nudge the system a tiny bit off the fixed point. Write the state as the fixed point plus a small deviation η: let x(t)=x*+η(t) with η small. Since x* is a constant, the rate of change of x is just the rate of change of η:

η˙=x˙=f(x*+η)

Now approximate f near the fixed point with a Taylor expansion (a straight-line approximation), and use f(x*)=0:

η˙≈f(x*)+f′(x*)η=f′(x*)η

This is the simplest growth equation there is; its solution is an exponential:

η(t)=η(0)ef′(x*)t

If f′(x*)<0 the exponent is negative, so the deviation shrinks back to zero — stable. If f′(x*)>0 it grows — unstable. And if it is exactly 0, the straight-line approximation tells you nothing and you need the higher terms — the bifurcation case. ∎

Proof 4 · discrete-map stability

An iterated map xn+1=f(xn) is stable when |f′(x*)|<1

Same idea, but now time moves in discrete jumps. Write step n as the fixed point plus a small error: xn=x*+εn. Feed it through one step and Taylor-expand:

x*+εn+1=f(x*+εn)≈f(x*)+f′(x*)εn

Because f(x*)=x*, the x* cancels from both sides, leaving a rule for how the error changes each step:

εn+1=f′(x*)εn⟹εn=[f′(x*)]nε0

Each step multiplies the error by f′(x*). Repeated multiplication shrinks the error only if that multiplier has size below 1, i.e. |f′(x*)|<1 (stable); above 1 it blows up (unstable). ∎ Cases he has actually set:
