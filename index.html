—How the quiz is actually set

Before the content, know the shape of the target. Every past paper in your folder falls into one of three moulds, and each rewards a different kind of preparation.

Read this first

Three formats, three habits

  • Surprise quizzes (MS Forms, MCQ). Fast conceptual recall — "which centrality counts direct connections?", "what does high out-degree in a citation network mean?". No arithmetic, but the wording is often negated: "which statement is wrong", "which do NOT define a spanning tree". Misreading the negation is the usual way marks are lost.
  • Written Quiz 1 (~20 marks, calculation + one-line reasoning). Compute a clustering coefficient, a betweenness, an in/out-degree sequence; state properties of star and complete graphs. Crucially: "only attempting the options will NOT fetch marks — give a one-line reason for each." Bare answers score zero.
  • Proof / derivation (surprise + Quiz 2 + mid-sem). This is where he stretches you: triangles = ⅙·tr(A³), stability of a discrete map, solving the SIS equation, classifying a bifurcation. Section 15 is built entirely for these.
Convention trap

Your course's bifurcation note uses dashed = stable, solid = unstable — the opposite of most textbooks (Strogatz uses solid = stable). Every diagram in this guide is labelled by colour and word as well, so you're never guessing. But if a diagram appears on the paper with no colour, read the dashed/solid line by his convention.

0Network science, in brief

The opening module is mostly motivation — a few crisp facts show up in MCQs, so hold onto these rather than the anecdotes.

What makes a system "complex"

A complex system has many interconnected parts, time-dependent interactions, and behaviour that is not the sum of its parts. The headline property is emergence: a pattern the whole shows that no single component carries on its own — synchronisation, an epidemic wave, a traffic jam. A complex network is the graph you draw to study such a system: nodes are the parts, links are the interactions.

The five landmarks (for a date-matching MCQ)

YearWhoWhat
1735EulerSeven Bridges of Königsberg — the birth of graph theory
1959Erdős & RényiRandom graph model G(N,p)
1967Milgram"Six degrees of separation" — small-world experiment (avg ≈ 5.5–6 hops)
1998Watts & StrogatzSmall-world networks (high clustering + short paths)
1999Barabási & AlbertScale-free networks, preferential attachment

Networks can be directed or undirected: the WWW and citations are directed; the internet (routers), power grids, and collaboration networks are undirected. N = number of nodes, L = number of links.

1Graphs & the adjacency matrix

Everything downstream — degree, paths, triangles, centralities — is read off one object: the adjacency matrix. Get fluent with it and half the quiz is free.

Definition

The adjacency matrix A of a graph on N nodes is the N×N matrix with

Aij = 1  if there is an edge from  i → j,    else  0

Two vertices joined by an edge are adjacent; the edge is incident to them.

Properties you must be able to state (these are literally MCQ options)

  • Square, order N. Always.
  • Undirected ⇒ symmetric (Aij = Aji). Directed ⇒ generally not symmetric.
  • No self-loops ⇒ diagonal is all zero. A 1 on the diagonal means a self-loop.
  • Binary graph: entries are 0/1. A weighted graph stores real weights wij instead.
  • Disconnected graph: with the right labelling A is block-diagonal — one block per component, zeros between blocks. (So "non-zero off-diagonal entries between the components" is false.)
  • Rank can be less than N, even when connected — the matrix may be singular. "Rank is always N" is false.
Common trap

"If two vertices are connected, the entry is always 1" is false for a weighted graph — it's the weight, not necessarily 1. In an unweighted graph it is 1. Read whether the question says binary/unweighted.

2Degree, in/out-degree & the handshaking lemma

Definition

The degree ki of node i in an undirected graph is the number of edges touching it:

ki = Σj Aij = Σj Aji   (row sum = column sum, by symmetry)

Directed graphs: split the sum

in-degree   ki(in) = Σj Aji   =  column i sum   (arrows pointing to i)
out-degree  ki(out) = Σj Aij   =  row i sum    (arrows pointing from i)

With the convention Aij = edge i→j: row sum = out-degree, column sum = in-degree. Memorise this direction — a whole question depends on it.

Worked · past-paper style

In/out-degree sequence from a matrix

Given the directed graph (Quiz 1 style):

      to→   1  2  3  4
  A =  1 [  0  1  0  0 ]
       2 [  1  0  1  1 ]
       3 [  0  1  0  0 ]
       4 [  1  1  0  1 ]   ← A₄₄=1 is a self-loop
  • Out-degree = row sums: node1 = 1, node2 = 3, node3 = 1, node4 = 3. → out-sequence (1, 3, 1, 3).
  • In-degree = column sums: col1 = 2, col2 = 3, col3 = 1, col4 = 2. → in-sequence (2, 3, 1, 2).
  • Check: Σ in = Σ out = 9 (total number of directed edges, counting the self-loop). They must be equal — a fast sanity check.
Key theorem

Handshaking lemma

Σi ki = 2L

The degrees of all vertices sum to twice the number of edges, because every edge is counted once at each of its two endpoints. Corollary: the number of odd-degree vertices is always even. (Proof in §15.)

Reading the meaning (MCQ)

Citation network — high in-degree = much-cited, influential article. High out-degree = cites many works → a review or book. Co-authorship is undirected, so in-degree = out-degree; a node can't be "isolated" if it has any links. A node can have high degree yet be functionally isolated only in the directed sense (all out, no in, or vice-versa).

3Mean degree & link density

Mean degree  ⟨k⟩ = (1/N) Σi ki
   undirected: ⟨k⟩ = 2L / N     directed: ⟨k⟩ = L / N
Link density  ρ = (existing links) / (max possible links)
   undirected: ρ = 2L / [N(N−1)] = ⟨k⟩ / (N−1)

Max possible edges in a simple undirected graph on N nodes is N(N−1)/2 — every distinct pair once.

Exam favourite

The Erdős–Rényi relation: ⟨k⟩ = p(N−1)

If each of the N(N−1)/2 possible edges exists independently with probability p (this is the density in expectation), then a node has N−1 chances each with probability p, so

⟨k⟩ = p (N − 1) ≈ pN  (large N),    L = p · N(N−1)/2

Quiz 1 asks exactly this: "relationship between p, ⟨k⟩ and N". Answer with the formula and the one-line reason above.

4Walk, trail, path, cycle, circuit

Four words that sound alike and are examined precisely. The distinction is what you're not allowed to repeat.

TermRuleRepeats allowed?
WalkAny route along edges, vertex to vertexEdges ✓   Vertices ✓
TrailA walk with no repeated edgeEdges ✗   Vertices ✓
PathA walk with no repeated vertex (so no repeated edge either)Edges ✗   Vertices ✗
CircuitA closed trail — trail that starts and ends at the same vertexEdges ✗
CycleA closed path — starts and ends at the same vertex, no other repeatsVertices ✗ (except endpoints)

Hierarchy to remember: path ⊂ trail ⊂ walk. A path is the strictest (nothing repeats); a walk is anything-goes.

5Eulerian & Hamiltonian graphs

This is the module's signature topic — Königsberg — and it shows up as both an MCQ and a "justify your answer" written question.

Definition

Eulerian is about edges; Hamiltonian is about vertices.

  • Eulerian trail — uses every edge exactly once.
  • Eulerian circuit — an Eulerian trail that returns to its start.
  • Hamiltonian path — visits every vertex exactly once.
  • Hamiltonian circuit — a Hamiltonian path that returns to its start.
The criterion (this is the whole game)

For a connected graph, count the vertices of odd degree:

Odd-degree verticesWhat existsWhere it starts / ends
0 (all even)Euler circuit (and trail)Start = end, anywhere
exactly 2Euler trail, but not a circuitMust start at one odd vertex, end at the other
more than 2No Euler trail or circuit—

(There can only ever be 0 or 2, never exactly 1, because odd-degree vertices come in pairs — handshaking.) The number of odd vertices is always even, so 1 or 3 is impossible.

The classic · Königsberg

Why the bridge walk is impossible

Four land masses (nodes) A, B, C, D with degrees A=5, B=3, C=3, D=3 — all four are odd. Four odd vertices > 2, so no Euler trail exists: you cannot cross all seven bridges exactly once. That is Euler's 1735 answer.

"How would you make one possible?" Remove (or add) a bridge so that at most two vertices have odd degree. E.g. removing one bridge that connects two odd-degree land masses turns both even, leaving exactly two odd → an Euler trail becomes possible (start at one odd land mass, finish at the other).

The distinction he asks outright

"Main difference between an Eulerian and a Hamiltonian path?" — Eulerian = every edge once (may revisit vertices); Hamiltonian = every vertex once (may skip edges). Eulerian has a clean degree criterion; Hamiltonian has no simple criterion (it's an NP-hard problem in general) — so you check it by inspection.

Quiz 1For the graph 6–4, 4–5, 4–3, 5–1, 5–2, 3–2, 2–1: is there a Hamiltonian path? An Euler path/circuit? If not, how to make an Euler path?›

Degrees: node 6 = 1, node 4 = 3, node 5 = 3, node 3 = 2, node 2 = 3, node 1 = 2.

Odd-degree vertices: 6, 4, 5, 2 — that's four odd vertices. More than 2 ⇒ no Euler trail and no Euler circuit.

Hamiltonian path: try to visit all 6 vertices once, e.g. 6 → 4 → 3 → 2 → 1 → 5. Check each edge exists: 6-4 ✓, 4-3 ✓, 3-2 ✓, 2-1 ✓, 1-5 ✓. Yes — a Hamiltonian path exists.

To create an Euler trail: reduce the odd count from 4 to 2. Add one edge between two of the odd vertices (say 6–5, or 4–2) so both become even; two odd vertices remain, giving an Euler trail that starts at one and ends at the other. (Equivalently, remove an edge joining two odd vertices.)

6Distance, shortest path, diameter & BFS

Definitions
  • Distance d(i,j) (a.k.a. shortest path / geodesic) — the fewest edges connecting i and j. Disconnected ⇒ d = ∞.
  • In a directed graph you must follow arrow directions, so d(A,B) ≠ d(B,A) in general.
  • Diameter — the largest distance between any pair: dmax. The "width" of the network.
  • Average path length ⟨d⟩ — mean of d(i,j) over all pairs.
⟨d⟩ =   [ Σi<j d(i,j) ]  /  [ N(N−1)/2 ]  (undirected: number of pairs is N(N−1)/2)

Shortest paths are computed by BFS

Breadth-first search from a source explores the graph in layers: all neighbours (distance 1), then their unvisited neighbours (distance 2), and so on. The layer at which a node is first reached is its distance from the source. That's why BFS gives shortest paths in an unweighted graph.

Worked · path graph

Distances, diameter, ⟨d⟩ on the line 1–2–3–4–5

  • Diameter = d(1,5) = 4 — the two ends are the farthest apart.
  • Distances by pair: there are C(5,2)=10 pairs. Sum of all shortest distances = 20 (four at d=1, three at d=2, two at d=3, one at d=4 → 4+6+6+4).
  • Average path length = 20 / 10 = 2.0.
Also examined

Connected components & the Laplacian

A connected component is a maximal set of mutually reachable nodes. The graph Laplacian is L = D − A (D = diagonal degree matrix). Its key fact, asked directly:

number of connected components = nullity of L = multiplicity of eigenvalue 0

So a graph with 3 components has a Laplacian with a 3-dimensional null space (eigenvalue 0 repeated 3×). The second-smallest Laplacian eigenvalue is the algebraic connectivity — larger means "better connected".

7Clustering coefficient

"Do my friends know each other?" — the single most-computed quantity in Quiz 1 and the surprise quizzes.

Definition

The local clustering coefficient of node i is the fraction of its neighbour-pairs that are themselves linked:

Ci =  (links among the neighbours of i)  /  (possible links among them)  =  2 ei / [ ki(ki−1) ]

ei = number of edges actually present between the ki neighbours; the denominator ki(ki−1)/2 is the number of possible such edges. Always 0 ≤ Ci ≤ 1. If ki < 2, Ci is defined as 0.

Worked · the MCQ answer

Node A has neighbours B, C, D; B and C are not linked — minimum CA?

Three neighbours ⇒ kA=3, possible neighbour-links = 3·2/2 = 3. To get the minimum, assume only the forced/least links exist. With B–C absent, the fewest edges among {B,C,D} that any answer allows is one (e.g. B–D), giving

CA = 1 / 3 ≈ 0.33

(If no neighbours were linked it would be 0; the quiz's phrasing and options fix the minimum at 1/3.)

Quiz 1 technique

When asked for CX and CY from a drawn graph: (1) list X's neighbours, (2) count edges between those neighbours only, (3) divide by k(k−1)/2. A leaf-heavy hub often has C = 0 (its neighbours aren't linked); a node inside a triangle has C = 1 if that's its only neighbourhood.

8The four centralities

"What makes a node important?" has four answers. The surprise quizzes test which-is-which; Quiz 1 tests computing them. Learn both the one-line idea and the formula.

CentralityA node is important if…Formula / how
Degreeit has many direct connectionsCD(i) = ki; normalised ki/(N−1)
Closenessit is close to everyone (short distances)CC(i) = 1 / Σj d(i,j); normalised (N−1)/Σjd(i,j)
Betweennessmany shortest paths pass through it (a bridge)CB(v) = Σs≠t≠v σst(v)/σst
Eigenvectorit is linked to other important nodesA x = λ x, take x for the largest λ

In the betweenness formula, σst = number of shortest paths from s to t, and σst(v) = how many of them pass through v. Centralities are used to find the most influential person in a social network, the most critical routers on the internet, or the top disease spreaders.

Eigenvector centrality — the recursive idea

Definition

Degree centrality gives one point per link. Eigenvector centrality weights each link by how important the neighbour is — endorsements from important nodes count more:

xi = (1/λ) Σj Aij xj   ⟺   A x = λ x

So the centrality vector x is the eigenvector of A for its largest eigenvalue λ (guaranteed positive entries by Perron–Frobenius).

Worked · past-paper MCQ

Eigenvector centrality of the 4-node graph A²=[0111;1010;1101;1010]

The matrix has rows: A↔{B,C,D}, B↔{A,C}, C↔{A,B,D}, D↔{A,C}. By symmetry A and C are equivalent (both degree 3), and B and D are equivalent (both degree 2). So the centrality vector must have the form (a, b, a, b).

The eigenvector equation for the top eigenvalue works out to give the same value at every node here, so the correct option is

A: 0.5,   B: 0.5,   C: 0.5,   D: 0.5

Exam shortcut: eigenvector-centrality options that respect the graph's symmetry (equal-degree, symmetric nodes get equal scores) are the ones to trust. Here all four map onto each other, so all equal.

Worked · betweenness & closeness

Node X (an endpoint) vs Y (interior) on the line 1–2–3–4–5

Betweenness on a path: interior node at position i lies on the shortest path of every (left, right) pair, so CB = (i−1)(N−i). Endpoint ⇒ CB = 0 (no pair routes through an end). Centre of P₅ ⇒ (2)(2) = 4.

Closeness: centre node has distances 2,1,1,2 → sum 6 → CC = 4/6 = 0.67 (normalised). An endpoint has distances 1,2,3,4 → sum 10 → CC = 4/10 = 0.40.

So the interior node beats the endpoint on both — higher betweenness and higher closeness. That's the reasoning the "one line per option" questions want.

9Special graphs, bipartite & spanning trees

Star and complete graphs — memorise the numbers

Graph on N nodesDiameterAvg path lengthAvg degree
Star (1 hub + N−1 leaves)2 (leaf–hub–leaf)2(N−1)/N2(N−1)/N
Complete KN (all-to-all)11N−1
Worked · Quiz 1

Star graph, N = 5: average path length and diameter?

  • C(5,2)=10 pairs. Hub–leaf pairs: 4, each distance 1. Leaf–leaf pairs: C(4,2)=6, each distance 2 (must hop through the hub).
  • Sum of distances = 4·1 + 6·2 = 16.
  • Average path length = 16/10 = 1.6  (= 2(N−1)/N = 8/5). Diameter = 2.
Worked · Quiz 1

All-to-all network KN — which statements are true?

  • (a) Symmetric — TRUE, it's undirected so A=Aᵀ.
  • (b) Diameter = N — FALSE, diameter = 1; every pair is directly linked.
  • (c) Average path length = 1 — TRUE, all distances are 1.
  • (d) Average degree = N−1 — TRUE, each node connects to all others.
Bipartite graphs

A bipartite graph splits nodes into two sets U and V with every edge going across (U-node to V-node), none inside a set. Use it whenever you relate two different kinds of thing: users–movies, authors–papers, buyers–sellers, customers–products, genes–pathways, airports–airlines. It is not suitable for a single-type network like friendships between individuals.

Spanning tree

A spanning tree of a connected graph on N nodes is a subgraph that:

  • covers all N vertices,
  • is connected and acyclic (no cycle),
  • has exactly N − 1 edges.

"Must have a cycle" and "must have N−1 edges is false" are the trap options — a tree by definition has no cycle. To build one, remove edges until no cycle remains while keeping the graph connected (remove one edge per independent cycle).

10Fixed points & linear stability

The whole of nonlinear-dynamics on the quiz reduces to two questions: where does the system sit still, and does it stay there if nudged.

Definition

A one-dimensional autonomous system is ẋ = f(x) (a dot means d/dt). A fixed point (equilibrium, steady state) x* is where nothing changes:

f(x*) = 0

The phase-line picture (no calculus needed)

Plot ẋ = f(x) against x. The sign of ẋ tells you which way x moves:

  • ẋ > 0 (curve above axis) → x increases → arrow points right.
  • ẋ < 0 (curve below axis) → arrow points left.
  • Zeros of the curve are the fixed points.
 →  [x*]  ←    stable (arrows point in)       ←  [x*]  →   unstable (arrows point out)
  + → − crossing = stable            − → + crossing = unstable
The one criterion to know cold

Linear stability (continuous system)

f′(x*) < 0  ⟹  x* is stable
f′(x*) > 0  ⟹  x* is unstable

Reason (derived in §15): a small perturbation η obeys η(t) ≈ η(0) e^{f′(x*) t}, so it decays only when the exponent is negative. If f′(x*)=0 the test is inconclusive — and that borderline is exactly where bifurcations live.

Continuous vs discrete — do not mix these

For an iterated map xn+1 = f(xn) the criterion is different: a fixed point is stable when |f′(x*)| < 1 (not f′<0). Continuous flow → sign of f′; discrete map → magnitude of f′ against 1. He has asked the discrete version (logistic map, cos x) — see §15.

11Euler's method (numerical integration)

The demos integrate every model with this. You should be able to write the update rule and name its error.

The tangent-line method

To solve ẏ = f(t, y) from y(t₀)=y₀, step forward along the tangent with step size h:

yn+1 = yn + h · f(tn, yn)  ,   tn+1 = tn + h

The two error types (MCQ)

  • Truncation / discretisation error — from dropping higher-order Taylor terms. Present even with perfect arithmetic; shrinks as h→0. Euler's is first-order accurate (O(h) per step).
  • Round-off error — from finite-precision floating point. Gets worse if h is made absurdly small (more steps). RK4 is the higher-accuracy upgrade used in the demos.

12The four one-dimensional bifurcations

A bifurcation is a qualitative change in the fixed points as a parameter r is varied — points appearing, vanishing, colliding, or swapping stability. Four normal forms cover the whole 1D syllabus. Learn the equation, the fixed points, and the shape.

stable branch unstable branch (diagrams: x* vertical, r horizontal)

Saddle-node (fold)

ẋ = r − x² · two equilibria for r>0, none for r<0. They collide & vanish at r=0 — creation/destruction.

Transcritical

ẋ = rx − x² · two branches x*=0 and x*=r cross at r=0 and exchange stability.

Supercritical pitchfork

ẋ = rx − x³ · at r=0 the stable point at 0 splits into two stable branches ±√r. Soft transition.

Subcritical pitchfork

ẋ = rx + x³ · two unstable branches ±√(−r) for r<0. Linked to abrupt jumps / hysteresis.

BifurcationNormal formFixed pointsSignature
Saddle-nodeẋ = r − x²x* = ±√r (r≥0); none for r<0pair appears from nothing (+ stable, − unstable)
Transcriticalẋ = rx − x²x*=0 and x*=rtwo branches cross, swap stability at r=0
Supercritical pitchforkẋ = rx − x³x*=0; ±√r for r>00 loses stability, two stable branches born
Subcritical pitchforkẋ = rx + x³x*=0; ±√(−r) for r<0two unstable branches; jump to a distant state
How to classify in the exam (his exact wording)

"Describe the role of r. What bifurcation do you expect?"

  1. Set f(x)=0 and solve for x* as a function of r.
  2. Count how the number of real fixed points changes as r passes through the critical value.
  3. Match the count to the table: 0↔2 appearing = saddle-node; two lines crossing = transcritical; 1↔3 with symmetry = pitchfork.
Mid-semClassify ẋ = rx − x² and ẋ = 1 + rx + x².›

(1) ẋ = rx − x² = x(r − x). Fixed points x*=0 and x*=r. They coincide at r=0 and cross, and f′=r−2x gives f′(0)=r, f′(r)=−r — opposite signs, so the two branches swap stability at r=0. This is a transcritical bifurcation. Role of r: it is the growth rate; for r>0 the non-zero state x*=r is the stable one.

(2) ẋ = 1 + rx + x². Fixed points solve x² + rx + 1 = 0 ⇒ x* = [−r ± √(r²−4)]/2. Real roots need the discriminant r²−4 ≥ 0, i.e. |r| ≥ 2. So:

  • |r|<2: no fixed points.
  • |r|=2: one double fixed point appears.
  • |r|>2: two fixed points (one stable, one unstable).

A pair of equilibria is created out of nothing as |r| crosses 2 — saddle-node bifurcations at r = +2 and r = −2.

13Bistability & hysteresis (Spruce Budworm)

When a system has two stable states at once, the interesting physics — tipping points, sudden collapse, hysteresis — appears. The Budworm model is the course's worked case.

The model
ẋ = r x (1 − x/K) − x² / (1 + x²)  ,   K = 10,   r > 0

First term = logistic growth of the population; second = saturating predation (birds eating budworms). The non-zero equilibria solve a cubic, which is why up to three positive states can coexist.

The core concepts
  • Bistability: for 0.384 ≲ r ≲ 0.560 there are three positive equilibria in the pattern stable – unstable – stable. The low stable state = "refuge"; the high stable state = "outbreak".
  • The middle unstable equilibrium is a threshold: start below it and you fall to the low state, start above it and you climb to the high state. (At r=0.5: below x=2 → 0.68; above → 7.3.)
  • Hysteresis: raise r slowly and the system clings to the low branch until it vanishes at the upper fold, then jumps up. Lower r again and it clings to the high branch until the lower fold. The up-path ≠ the down-path — that gap is hysteresis. The folds are saddle-node bifurcations.
Fold detection (a derivation he likes)

A fold (saddle-node) is where a fixed point exists and the curve is tangent to the axis:

f(x*; r) = 0  and  f′(x*; r) = 0

Solving both simultaneously gives the two critical r values (≈0.384 and ≈0.560 for K=10). "Tangency to the axis" on a ẋ-vs-x plot is the visual tell of a saddle-node.

14SIS, SIR & predator–prey

Three dynamical models the course applies to networks. The SIS derivation is a mid-sem staple; the SIR and predator–prey facts are MCQ material.

SIS — susceptible ⇄ infected (reinfection possible)

Model & solution
ds/dt = −β s i + γ i  ,   di/dt = β s i − γ i  ,   s + i = 1

Substitute s = 1 − i into the infected equation:

di/dt = β i (1 − i) − γ i = (β − γ) i − β i²

This is the logistic equation. Its non-zero steady state (the endemic equilibrium) is found by setting di/dt = 0:

i* = 1 − γ/β = 1 − 1/R₀  ,   R₀ = β/γ
The threshold — asked every time
R₀ = β/γ > 1  ⟹  disease spreads, settles at endemic i* > 0
R₀ = β/γ < 1  ⟹  disease dies out, i* → 0

"In which condition will the disease not spread?" → when β < γ (recovery outpaces infection), i.e. R₀ < 1. Equivalently, the fixed point i*=0 is stable exactly when β < γ — check via f′(0)=β−γ.

SIS on a network — the eigenvalue threshold

On a network, node k obeys i̇k = −γ ik + β(1 − ik) Σj Akj ij. Early on (ik tiny) drop the quadratic term:

i̇ ≈ (β A − γ I) i  ⟹  growth rate = β λmax(A) − γ

The infection grows if β λmax > γ. So the network sets the threshold through its largest adjacency eigenvalue:

(β/γ)c = 1 / λmax(A)

This is the answer to "how does the network affect infection at the initial stage?" — via λmax. Denser / more-connected networks (larger λmax) lower the threshold, so disease spreads more easily.

SIR — susceptible → infected → removed (immunity/death)

ds/dt = −β s i  ,   di/dt = β s i − γ i  ,   dr/dt = γ i  ,   s+i+r = 1
  • Susceptibles only ever decrease (monotone, roughly exponential decay) — no reinfection route back to S.
  • Infectious period is assumed constant for everyone (constant recovery rate γ); homogeneous mixing.
  • At any steady point the three rates of change sum to zero (population conserved). An epidemic takes off only if R₀ = β/γ > 1 with s ≈ 1 initially.

Predator–prey (Lotka–Volterra)

Key behaviour (MCQ)
  • The populations oscillate — prey rise, predators follow, prey crash, predators crash, repeat. Not a steady stabilisation.
  • Equilibrium points shift with the parameters: higher predation rate → lower predator steady state; higher prey reproduction → higher predator steady state; a competing species does affect stability.
  • Starting the prey above its carrying capacity leads into the same oscillatory cycle, not a smooth settle.

15Proofs he actually asks

The surprise quiz that asked you to prove triangles = ⅙ tr(A³) is the tell: he wants derivations, not just recall. These are the ones that fit the current syllabus — learn to reproduce each in a few lines.

Proof 1 · the one he sprang on you

Number of triangles = ⅙ · tr(A³)

Lemma (powers count walks). The entry (Aⁿ)ij equals the number of walks of length n from i to j.

Why: (A²)ij = Σk AikAkj counts intermediate nodes k with edges i–k and k–j — exactly the 2-step walks. Induction extends it: (Aⁿ)ij = Σk(An−1)ikAkj appends one edge to every (n−1)-walk.

Apply at n = 3. (A³)ii counts closed walks of length 3 from i back to i — that is, triangles through i. So

tr(A³) = Σi (A³)ii = total closed 3-walks over all nodes.

Count the over-counting. A single triangle on vertices {a,b,c} is counted:

  • once at each of its 3 vertices (as start point) → factor 3, and
  • in each of 2 directions (a→b→c→a and a→c→b→a) → factor 2.

So every triangle contributes 3 × 2 = 6 to tr(A³). Therefore

Number of triangles = tr(A³) / 6  =  ⅙ tr(A³).  ∎

Bonus links he may combine: (A²)ii = ki (the degree — closed 2-walks are out-and-back along one edge), so tr(A²) = Σki = 2L. And the number of paths of length 2 centred at i is C(ki,2) = ki(ki−1)/2.

Proof 2

Handshaking lemma: Σ ki = 2L

Count the pairs (vertex, edge-incident-to-it) two ways. Summing over vertices gives Σi ki. But each edge has exactly two endpoints, so summing over edges gives 2L. The two counts are equal:

Σi ki = 2L.  ∎

Corollary: 2L is even, and even terms don't change parity, so the odd-degree vertices must sum to an even count — there is always an even number of odd-degree vertices. (This is why Euler graphs have 0 or 2 odd vertices, never 1.)

Proof 3 · continuous stability

Why f′(x*) < 0 means stable

Perturb the fixed point: x(t) = x* + η(t) with |η| small. Then η̇ = ẋ = f(x* + η). Taylor-expand and use f(x*)=0:

η̇ = f(x*) + f′(x*) η + … ≈ f′(x*) η  ⟹  η(t) = η(0) e^{f′(x*)·t}

The perturbation decays (stable) iff the exponent is negative, i.e. f′(x*) < 0; it grows (unstable) iff f′(x*) > 0. If f′(x*)=0 the linear term vanishes and you need higher orders — the bifurcation case. ∎

Proof 4 · discrete-map stability

Iterated map xn+1 = f(xn): stable iff |f′(x*)| < 1

Let xn = x* + εn. Then x* + εn+1 = f(x* + εn) ≈ f(x*) + f′(x*) εn. Since f(x*) = x*,

εn+1 = f′(x*) εn  ⟹  εn = [f′(x*)]ⁿ ε₀

This shrinks iff |f′(x*)| < 1 (stable), grows iff > 1 (unstable). ∎ Worked cases he has set:

Proof 5 · solving SIS

Solve di/dt = (β−γ)i − βi², find i* and the no-spread condition

Write a = β − γ. The equation is logistic: di/dt = a·i(1 − i/K) with carrying capacity K = a/β = 1 − γ/β. Separating variables and integrating gives

i(t) = K / [ 1 + ((K − i₀)/i₀) e^{−a t} ] ,    a = β − γ
  • Endemic equilibrium (t→∞): if a>0, i* = K = 1 − γ/β = 1 − 1/R₀.
  • Disease does not spread when a = β − γ < 0, i.e. β < γ (R₀ < 1): then i(t) → 0. ∎

17Final self-test

MCQIn a directed network A has out-degree 2, B has out-degree 1, and there are 3 total edges among {A,B,C} pointing so that in-degrees sum correctly. If A→B, A→C, B→C, what is C's in/out-degree?›

Out-degrees: A=2 (→B,→C), B=1 (→C), C=0. In-degrees: A=0, B=1, C=2. C has in-degree 2, out-degree 0. Sanity: Σin = Σout = 3. ✓

CalcA graph has degree sequence (2, 2, 3, 3, 3, 1). Does an Euler circuit exist? An Euler trail? How many edges?›

Odd-degree vertices: the three 3's and the one 1 → four odd vertices. More than 2 ⇒ no Euler trail and no circuit. Edges: Σki/2 = 14/2 = 7.

ProofShow that the number of closed walks of length 2 at node i equals its degree, and hence tr(A²) = 2L.›

(A²)ii = ΣkAikAki = ΣkAik². For a binary graph Aik²=Aik, so (A²)ii=ΣkAik=ki. Summing: tr(A²)=Σiki=2L by handshaking. ∎

CalcCompute the local clustering coefficient of a node with 4 neighbours, of which 3 mutual links exist among them.›

k=4, possible neighbour links =4·3/2=6, present e=3. C = 2·3/(4·3) = 6/12 = 0.5. C = 0.5.

ProofFor the map xn+1 = cos(xn), find the fixed point and its stability.›

Fixed point x* = cos x* ⇒ x* ≈ 0.739. f′(x)=−sin x, |f′(x*)|=|−sin 0.739|≈0.673 < 1 ⇒ stable (iterating cos on a calculator converges here — the Dottie number).

ClassifyWhat bifurcation does ẋ = r − x² undergo, and what happens to the fixed points as r passes 0?›

x*=±√r: two equilibria for r>0 (+√r stable since f′=−2x<0; −√r unstable), colliding at r=0, none for r<0. Saddle-node (fold) bifurcation — a pair of equilibria created/destroyed.

ConceptAn SIS disease has β = 0.2, γ = 0.5. Does it spread? What is the endemic level?›

R₀ = β/γ = 0.4 < 1 ⇒ it dies out. Endemic i* = 1 − 1/R₀ = 1 − 2.5 = −1.5, which is non-physical (negative), confirming the only stable state is i*=0. Disease spreads only when β > γ.

CalcA graph on 6 nodes has 3 connected components. What is the nullity of its Laplacian?›

Nullity of L = D − A equals the number of connected components. Nullity = 3 (eigenvalue 0 with multiplicity 3).
