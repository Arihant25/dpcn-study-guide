Part 1Degree distributions and path length

1The power law and its averages

Syllabus · power law, ⟨k⟩, ⟨k²⟩, critical β, k_min

In a real network, like the web or a citation network, most nodes have only a few links, but a small number of nodes (called hubs) have an enormous number. A formula called a power law describes this. In this section we find the average degree of such a network, the average of the squared degrees, and the conditions under which these averages are infinite. That last part is what "critical β" and "range of β" on the syllabus mean.

What the exam can ask
  • Find the constant \(C\) in the power law, and the condition for it to exist. (2024 Quiz 2, 3 marks)
  • Find ⟨k⟩ and ⟨k²⟩, and say for which exponents they are infinite. (2024 Quiz 2, 4 marks)
  • Say how the smallest degree \(k_{\min}\), the average degree ⟨k⟩ and the exponent are related.
  • Work out ⟨k⟩, ⟨k²⟩ and the variance from a list of degrees.

Step 0 · averages from a list of degrees

Before the power law, here is what ⟨k⟩ and ⟨k²⟩ mean on real numbers. Ten nodes have degrees

1, 1, 1, 1, 2, 2, 2, 2, 3, 5

The degree distribution is the fraction of nodes with each degree: \(P(1) = 4/10 = 0.4\), \(P(2) = 0.4\), \(P(3) = 0.1\), \(P(5) = 0.1\).

  • The average degree ⟨k⟩ multiplies each degree by its fraction and adds them up: \(\langle k\rangle = 1(0.4) + 2(0.4) + 3(0.1) + 5(0.1) = 2\).
  • The second moment ⟨k²⟩ does the same with each degree squared: \(\langle k^2\rangle = 1(0.4) + 4(0.4) + 9(0.1) + 25(0.1) = 5.4\).
  • The variance is \(\langle k^2\rangle - \langle k\rangle^2 = 5.4 - 4 = 1.4\). It measures how spread out the degrees are.

Look at the single node with degree 5. It adds only 0.5 to ⟨k⟩, but it adds 2.5 to ⟨k²⟩, almost half of the total. Squaring makes big numbers much bigger, so ⟨k²⟩ is dominated by the hubs. That is why ⟨k²⟩ is the quantity that tells you whether a network has hubs. (We reuse these ten nodes in §7.)

"Moment" is just the name for these averages. The first moment is ⟨k⟩, the average of \(k\). The second moment is ⟨k²⟩, the average of \(k^2\).

Step 1 · what a power law is

A power law says the fraction of nodes with degree \(k\) is

\[P(k) = C\,k^{-\gamma} = \frac{C}{k^{\gamma}}\]

\(k\) is a degree (number of links). \(P(k)\) is the fraction of nodes with that degree. \(\gamma\) (gamma) is a fixed number called the exponent. Your syllabus notes call it \(\beta\) and write \(P(k) = k^{-\beta}\); it is the same thing. \(C\) is a constant number that we will work out. The formula applies from some smallest degree \(k_{\min}\) upwards (for example, every node has at least 1 link, so \(k_{\min} = 1\)).

Take \(\gamma = 2\) and ignore \(C\) for a moment. Then \(P(k)\) is proportional to \(1/k^2\):

Degree k12101001000
\(1/k^2\)10.250.010.00010.000001

Nodes with degree 1 are very common. Degree 100 is 10,000 times rarer, but it still happens. In a network with a million nodes, you expect about one node with 1000 links. That is a hub. Compare people's heights, which all sit near an average and never reach ten times the average. A power law has no "typical" size, which is why such networks are called scale-free.

Step 2 · why we use integrals ("not discrete!")

Degrees are whole numbers, so strictly we should add up \(P(1) + P(2) + P(3) + \dots\) with a sum. Those sums are hard to work out exactly. Instead, the course pretends \(k\) can take any value and uses an integral (the smooth version of a sum, see M7). The answers are close, and the conditions for being finite are exactly the same. This is what "not discrete!" in your notes means: treat \(k\) as continuous.

We will use one rule from M7 three times:

\[\int_{k_{\min}}^{\infty} k^{a}\,dk = \left[\frac{k^{a+1}}{a+1}\right]_{k_{\min}}^{\infty}\]

At the top limit (\(k = \infty\)), \(k^{a+1}\) is 0 if the power \(a+1\) is negative, and infinite if it is positive or zero. So:

  • if \(a + 1 < 0\), the answer is finite: \(0 - \frac{k_{\min}^{a+1}}{a+1} = \frac{k_{\min}^{a+1}}{-(a+1)}\);
  • if \(a + 1 \ge 0\), the answer is infinite.

Step 3 · finding the constant C

The fractions \(P(k)\) must add up to 1 (every node has some degree). This is called normalisation. With an integral:

\[\int_{k_{\min}}^{\infty} C\,k^{-\gamma}\,dk = 1\]

\(C\) is a constant, so it comes outside. The power is \(a = -\gamma\), so \(a + 1 = 1 - \gamma\). Using the rule:

\[C\left[\frac{k^{1-\gamma}}{1-\gamma}\right]_{k_{\min}}^{\infty} = 1\]

This is finite only if \(1 - \gamma < 0\), that is \(\gamma > 1\). Then the top limit gives 0, the bottom limit gives \(\frac{k_{\min}^{1-\gamma}}{1-\gamma}\), and subtracting:

\[C\cdot\frac{k_{\min}^{1-\gamma}}{\gamma - 1} = 1 \quad\Longrightarrow\quad C = \frac{\gamma-1}{k_{\min}^{1-\gamma}} = (\gamma - 1)\,k_{\min}^{\gamma-1}.\]

(Dividing by \(k_{\min}^{1-\gamma}\) is the same as multiplying by \(k_{\min}^{\gamma-1}\), by the power rules in M4.) If \(\gamma \le 1\), the area is infinite and no value of \(C\) can make the total equal 1.

\[C = (\gamma - 1)\,k_{\min}^{\gamma-1}, \qquad\text{which exists only if } \gamma > 1\]

Step 4 · the average degree ⟨k⟩

The average is "degree times fraction, added up" (Step 0), so we integrate \(k \times P(k)\):

\[\langle k\rangle = \int_{k_{\min}}^{\infty} k\cdot C k^{-\gamma}\,dk = C\int_{k_{\min}}^{\infty} k^{1-\gamma}\,dk\]

(\(k \times k^{-\gamma} = k^{1-\gamma}\).) Now \(a = 1 - \gamma\), so \(a + 1 = 2 - \gamma\). This is finite only if \(2 - \gamma < 0\), that is \(\gamma > 2\). Then

\[\langle k\rangle = C\cdot\frac{k_{\min}^{2-\gamma}}{\gamma - 2} = (\gamma-1)k_{\min}^{\gamma-1}\cdot\frac{k_{\min}^{2-\gamma}}{\gamma-2} = \frac{\gamma-1}{\gamma-2}\,k_{\min}.\]

(The powers of \(k_{\min}\) combine: \(k_{\min}^{\gamma-1}\times k_{\min}^{2-\gamma} = k_{\min}^{1}\).)

\[\langle k\rangle = \frac{\gamma - 1}{\gamma - 2}\,k_{\min}, \qquad\text{finite only if } \gamma > 2\]

Step 5 · the second moment ⟨k²⟩

Same again with \(k^2\times P(k)\), which is \(C k^{2-\gamma}\). Now \(a + 1 = 3 - \gamma\), finite only if \(\gamma > 3\):

\[\langle k^2\rangle = C\int_{k_{\min}}^{\infty} k^{2-\gamma}\,dk = C\cdot\frac{k_{\min}^{3-\gamma}}{\gamma-3} = \frac{\gamma-1}{\gamma-3}\,k_{\min}^2 .\]
\[\langle k^2\rangle = \frac{\gamma - 1}{\gamma - 3}\,k_{\min}^2, \qquad\text{finite only if } \gamma > 3\]

Step 6 · the critical values of the exponent

Steps 3 to 5 give two critical values, 2 and 3. They split the possible exponents into three ranges.

Exponent⟨k⟩⟨k²⟩What it means
\(\gamma \le 2\)infiniteinfiniteThe hubs are so big that even the average degree is infinite.
\(2 < \gamma \le 3\)finiteinfiniteThe usual case for real networks. The average is a normal number, but the spread of degrees has no limit.
\(\gamma > 3\)finitefiniteHubs are rare enough that the network behaves much like a random one.

A real network has a finite number of nodes, so nothing is literally infinite. "Infinite" here means "keeps growing as the network grows". A bigger network contains bigger hubs, and because ⟨k²⟩ is dominated by the hubs, it keeps increasing with network size when \(\gamma < 3\).

The general pattern: the average of \(k^m\) is finite only if \(\gamma > m + 1\).

Step 7 · how k_min, ⟨k⟩ and the exponent are related

Step 4 already connects the three numbers:

\[\langle k\rangle = \frac{\gamma - 1}{\gamma - 2}\,k_{\min} \qquad\Longleftrightarrow\qquad \gamma = \frac{2\langle k\rangle - k_{\min}}{\langle k\rangle - k_{\min}}\]

To get the second form, multiply out \(\langle k\rangle(\gamma - 2) = (\gamma - 1)k_{\min}\), collect the \(\gamma\) terms on one side, \(\gamma(\langle k\rangle - k_{\min}) = 2\langle k\rangle - k_{\min}\), and divide. So if you know any two of the three numbers, you can find the third.

⟨k⟩ ÷ k_min11321.5close to 1

As \(\gamma\) comes down towards 2, the average climbs without limit (more and bigger hubs). As \(\gamma\) gets large, big degrees become so rare that almost every node has the minimum degree, and ⟨k⟩ approaches \(k_{\min}\). The average is always at least \(k_{\min}\), as it must be.

Worked example

\(\gamma = 2.5\) and \(k_{\min} = 1\).

  1. \(C = (2.5 - 1)\times 1^{1.5} = 1.5\).
  2. \(\langle k\rangle = \frac{2.5-1}{2.5-2}\times1 = \frac{1.5}{0.5} = 3\).
  3. ⟨k²⟩ needs \(\gamma > 3\). Here \(2.5 < 3\), so ⟨k²⟩ is infinite.

Going backwards: if a network has \(k_{\min} = 1\) and \(\langle k\rangle = 3\), then \(\gamma = \frac{6 - 1}{3 - 1} = 2.5\).

For comparison · the second moment of a Poisson distribution

Your notes also ask for the second moment of the Poisson distribution, which is the degree distribution of a random network (explained in §4). For Poisson, the variance equals the average, so

\[\langle k^2\rangle = \operatorname{var}(k) + \langle k\rangle^2 = \langle k\rangle + \langle k\rangle^2 ,\]

which is always finite. For example, average degree 4 gives \(\langle k^2\rangle = 4 + 16 = 20\). This is the key difference: a random network has a finite ⟨k²⟩, while a real scale-free network (\(2 < \gamma < 3\)) does not.

How to write it in the exam
  1. Write the normalisation condition \(\int_{k_{\min}}^\infty Ck^{-\gamma}dk = 1\). Say you treat \(k\) as continuous.
  2. Integrate. Say the value at infinity is zero only if \(\gamma > 1\). Get \(C = (\gamma - 1)k_{\min}^{\gamma-1}\).
  3. For ⟨k⟩ integrate \(k\cdot Ck^{-\gamma}\). Finite only if \(\gamma > 2\). Get \(\frac{\gamma-1}{\gamma-2}k_{\min}\).
  4. For ⟨k²⟩ integrate \(k^2\cdot Ck^{-\gamma}\). Finite only if \(\gamma > 3\). Get \(\frac{\gamma-1}{\gamma-3}k_{\min}^2\).
  5. Draw the table of the three ranges and state that real networks usually have \(2 < \gamma < 3\): finite ⟨k⟩, infinite ⟨k²⟩.
What to remember
  • Power law: \(P(k) = Ck^{-\gamma}\) (your notes write \(k^{-\beta}\)).
  • \(C = (\gamma - 1)k_{\min}^{\gamma-1}\), needs \(\gamma > 1\).
  • \(\langle k\rangle = \frac{\gamma-1}{\gamma-2}k_{\min}\), finite only for \(\gamma > 2\).
  • \(\langle k^2\rangle = \frac{\gamma-1}{\gamma-3}k_{\min}^2\), finite only for \(\gamma > 3\).
  • Critical values 2 and 3. Real networks: \(2 < \gamma < 3\).
  • Poisson: \(\langle k^2\rangle = \langle k\rangle + \langle k\rangle^2\).
Optional · the version with sums instead of integrals

If you keep \(k\) as a whole number with \(k_{\min} = 1\), then \(C = 1\big/\sum_{k=1}^\infty k^{-\gamma}\). The sum is finite exactly when \(\gamma > 1\), just like the integral. The conditions \(\gamma > 2\) and \(\gamma > 3\) for the two averages are also unchanged. Only the exact numbers differ, which is why the course uses integrals.

ConceptWhy does ⟨k²⟩ become infinite at a larger exponent than ⟨k⟩ does?›

⟨k²⟩ multiplies each fraction by \(k^2\) instead of \(k\), so very large degrees count much more. The thing being integrated, \(k^{2-\gamma}\), shrinks more slowly than \(k^{1-\gamma}\), so it needs a steeper fall-off (\(\gamma > 3\) instead of \(\gamma > 2\)) for the area to be finite.

2Drawing a degree distribution · linear and log binning

Syllabus · binning, linear and log, log-log scale

To see a degree distribution you draw a histogram: a bar chart of how many nodes have each degree. For a power law, the ordinary way of drawing it hides the pattern. This section explains the special axes (log-log) and the special way of grouping degrees (log binning) that make a power law show up as a straight line.

What the exam can ask
  • Why plot a degree distribution on log-log axes?
  • What is linear binning, what goes wrong with it, and how does log binning fix it?
  • Given bins and counts, compute \(P(k)\), or read the exponent off a plot.

What a histogram and a bin are

Suppose you have the degrees of 1000 nodes. You split the possible degrees into ranges called bins, for example 1–5, 6–10, 11–15, and count how many nodes fall into each bin. Drawing those counts as bars gives a histogram. Linear binning means every bin has the same width. The slide steps are: find the smallest and largest value, split that range into equal intervals, put each value in its interval, and count.

For heights of people or car speeds this works well, because the values sit around a typical size. For a power law, one bin at the left holds nearly all the nodes and the rest look empty. The slides show exactly this with "linbin/lin-scale": one tall bar, then almost nothing.

What a log scale is

On a normal axis, equal distances mean equal differences: 0, 10, 20, 30. On a logarithmic (log) axis, equal distances mean equal multiples: 1, 10, 100, 1000. Each step to the right multiplies by 10. This lets one chart show both tiny and huge values. A log-log plot uses a log scale on both axes.

Why a power law is a straight line on log-log axes

Take the logarithm of both sides of \(P(k) = Ck^{-\gamma}\). Using the rules \(\log(ab) = \log a + \log b\) and \(\log(k^n) = n\log k\) from M5:

\[\log P(k) = \log C - \gamma\,\log k\]

Call \(y = \log P(k)\) and \(x = \log k\). Then \(y = \log C - \gamma x\), which is the equation of a straight line (like \(y = c + mx\)) with slope \(-\gamma\). A log-log plot draws exactly \(\log P\) against \(\log k\). So a power law appears as a straight line, and its slope is minus the exponent. Other distributions, such as the Poisson distribution of a random network, curve sharply downwards on these axes.

To read the exponent from two points \((k_1, P_1)\) and \((k_2, P_2)\) on the line, use "slope = rise over run":

\[\gamma = -\,\frac{\log P_2 - \log P_1}{\log k_2 - \log k_1}\]

Example: if \(P(10) = 10^{-2}\) and \(P(100) = 10^{-4.5}\), then in base-10 logs the rise is \(-4.5 - (-2) = -2.5\) and the run is \(2 - 1 = 1\), so the slope is \(-2.5\) and \(\gamma = 2.5\).

What goes wrong with linear bins on log-log axes

  1. The right-hand end is noise. Large degrees are rare. With bins of equal width, most bins at large \(k\) contain 0 or 1 node. A bin with 0 cannot be drawn at all, since \(\log 0\) does not exist. The bins with exactly 1 node all have the same height, so they make a flat row of points (a "floor") that has nothing to do with the true distribution.
  2. The points are in the wrong places. On a log axis, equal-width bins crowd together at the right end. Most of your points land in the noisy region, and the useful left part gets only one or two points.

Log binning

In logarithmic binning, each bin is a fixed multiple wider than the previous one. For example, with a factor of 2 the bin edges are 1, 2, 4, 8, 16, 32 and so on. With a factor of 10 they are 1, 10, 100, 1000. At small degrees, where there is lots of data, the bins are narrow and keep the detail. At large degrees, where data is rare, the bins are wide, so each bin still collects enough nodes to give a reliable count. On a log axis these bins are evenly spaced.

The step people forget · divide by the bin width

The bins now have different widths, and a wider bin collects more nodes just because it covers more degrees. To make them comparable, divide each count by the bin width. Also divide by the total number of nodes \(N\) to turn counts into fractions:

\[P(k) \approx \frac{\text{number of nodes in the bin}}{N \times \text{bin width}}\]

Plot each value at the middle of its bin. If you forget to divide by the width, the slope comes out as \(-(\gamma - 1)\) instead of \(-\gamma\).

Worked example

1000 nodes are put into log bins with factor 2. The counts are:

Bin (degrees)WidthCountCount ÷ (1000 × width)
1 up to 214800.48
2 up to 422400.12
4 up to 841200.03
8 up to 168600.0075

Each time the degree doubles, the last column is divided by 4. Since \(4 = 2^2\), this is a power law with \(\gamma = 2\). The raw counts only halve each time (\(2 = 2^1\)), which would wrongly suggest \(\gamma = 1\). That is the mistake that dividing by the width prevents.

Optional · cumulative plots

Some slide figures (word counts in Moby Dick, citations, earthquakes) are marked "these plots are cumulative". A cumulative plot shows, for each \(k\), the fraction of nodes with degree at least \(k\). It needs no bins at all. For a power law with exponent \(\gamma\), it is also a straight line on log-log axes, with slope \(-(\gamma - 1)\).

How to write it in the exam
  1. Take logs: \(\log P = \log C - \gamma\log k\), so a power law is a straight line of slope \(-\gamma\) on log-log axes.
  2. Linear binning uses equal-width bins. For a power law, the tail bins hold 0 or 1 node, giving noise, a flat floor, and points that cannot be plotted.
  3. Log binning makes each bin a constant factor wider (for example 2 times), so wide bins at large \(k\) collect enough nodes.
  4. Divide each count by \(N\) times the bin width, and plot at the bin centre.
What to remember
  • Log-log axes turn a power law into a straight line with slope \(-\gamma\).
  • Linear bins: equal widths, noisy tail. Log bins: widths grow by a fixed factor.
  • \(P \approx \text{count}/(N\times\text{width})\).

3Path length and degree of star, chain and ring

Syllabus · star, chain, closed chain, ring with degree k

Here we take four simple network shapes and work out, for each, how many steps it takes on average to get from one node to another (the average path length), plus the degree of each node. The method is the same every time: count how many pairs of nodes are 1 step apart, 2 steps apart, and so on, and take the average.

What the exam can ask
  • Average path length and diameter of a star with a given number of nodes. (2024 Quiz 1: 5 nodes and 6 nodes)
  • Derive the average path length of the open chain, the ring, or the ring with degree \(k\). Give their degrees and clustering.
  • Say how the average path length changes as the network gets bigger.

The method

  1. Count the pairs. With \(N\) nodes there are \(\frac{N(N-1)}{2}\) pairs (M3).
  2. Group the pairs by distance: how many are 1 step apart, how many 2 steps apart, and so on.
  3. Add up (distance × number of pairs at that distance), then divide by the number of pairs.

For the ring, every node sees the same picture around it. Then there is a shortcut: pick any one node, average its distances to the other \(N - 1\) nodes, and that is already the answer for the whole network.

Star

Start with a star of 5 nodes: one hub and 4 outer nodes (called leaves). There are \(\frac{5\times4}{2} = 10\) pairs.

  • Hub with a leaf: 4 pairs, each 1 step apart (they are directly linked).
  • Leaf with a leaf: the other 6 pairs, each 2 steps apart (leaf → hub → leaf).

Average path length \(= \frac{4\times1 + 6\times2}{10} = \frac{16}{10} = 1.6\). The diameter (largest distance) is 2.

Now any size \(N\). There are \(N - 1\) leaves, so \(N - 1\) hub–leaf pairs at distance 1, and \(\frac{(N-1)(N-2)}{2}\) leaf–leaf pairs at distance 2. Put these into the method:

\[\langle l\rangle = \frac{(N-1)\times 1 + \frac{(N-1)(N-2)}{2}\times 2}{\frac{N(N-1)}{2}} = \frac{(N-1) + (N-1)(N-2)}{\frac{N(N-1)}{2}}\]

The top is \((N-1)\) times \(\big(1 + (N - 2)\big) = (N-1)^2\). Dividing by \(\frac{N(N-1)}{2}\) is the same as multiplying by \(\frac{2}{N(N-1)}\), and one factor of \((N-1)\) cancels:

\[\langle l\rangle_{\text{star}} = \frac{2(N-1)}{N}, \qquad \text{diameter} = 2\]

Check with \(N = 5\): \(2\times4/5 = 1.6\). For \(N = 6\): \(10/6 \approx 1.67\). As \(N\) grows, \(\frac{2(N-1)}{N} = 2 - \frac2N\) gets closer to 2 but never reaches it. The hub keeps everyone within two steps however big the star is.

Degrees: the hub has \(N - 1\) links, each leaf has 1. The average is \(\langle k\rangle = \frac{2L}{N} = \frac{2(N-1)}{N}\), the same number as \(\langle l\rangle\). Clustering is 0 everywhere: a leaf has only one neighbour, and the hub's neighbours (the leaves) are never linked to each other.

Open chain

Take 4 nodes in a line, A–B–C–D, as on the slide. The pairs at distance 1 are AB, BC, CD (3 pairs). At distance 2: AC, BD (2 pairs). At distance 3: AD (1 pair). So

\[\langle l\rangle = \frac{3\times1 + 2\times2 + 1\times3}{6} = \frac{10}{6} = \frac53 .\]

The pattern (3, 2, 1 pairs for \(N = 4\); 4, 3, 2, 1 for \(N = 5\)) is that there are \(N - j\) pairs at distance \(j\). Using the two sums from M2, the slide's calculation gives

\[\langle l\rangle = \frac{2}{N(N-1)}\sum_{j=1}^{N-1} j\,(N-j) = \frac{2}{N(N-1)}\left[N\cdot\frac{N(N-1)}{2} - \frac{(N-1)N(2N-1)}{6}\right] = N - \frac{2N-1}{3}\]

(Inside the bracket, \(\sum j(N - j) = N\sum j - \sum j^2\), and each sum runs up to \(n = N - 1\).)

\[\langle l\rangle_{\text{chain}} = \frac{N+1}{3}, \qquad \text{diameter} = N - 1\]

Check with \(N = 4\): \(5/3\). Degrees: the two end nodes have 1, the others have 2. Clustering is 0 (no triangles).

Closed chain (ring)

Join the two ends of the chain. Take 6 nodes. Stand on any one node and look both ways around the ring: 2 nodes are 1 step away, 2 nodes are 2 steps away, and 1 node (directly opposite) is 3 steps away. The average of these 5 distances is \(\frac{1+1+2+2+3}{5} = \frac95 = 1.8\). Every node sees the same, so \(\langle l\rangle = 1.8\).

In general, a node has 2 nodes at each distance 1, 2, 3, … up to about \(N/2\) (the node opposite). The average of the numbers from 1 to \(N/2\) is about half of \(N/2\), which is \(N/4\):

\[\langle l\rangle_{\text{ring}} \approx \frac{N}{4}\]

Exact values, if asked: \(\frac{N+1}{4}\) when \(N\) is odd, \(\frac{N^2}{4(N-1)}\) when \(N\) is even. For \(N = 6\): \(36/20 = 1.8\).

Diameter is about \(N/2\). Degree is exactly 2 for every node. The slides write this as \(P(k) = \delta(k - 2)\), which means "all nodes have degree 2 and no other degree occurs". Clustering is 0 (for \(N > 3\)).

Ring with degree k

Now link each node to its nearest \(k/2\) nodes on each side, so every node has degree \(k\). The slide picture has \(k = 4\): each node is linked to the nodes 1 and 2 places away on both sides.

In one step you can now move up to \(k/2\) places around the ring, in either direction. So each extra step reaches \(k\) new nodes (\(k/2\) on each side). The slide writes this as \(1 + \sum_{l=1}^{l_{\max}} k \approx N\): the starting node plus \(k\) new nodes per step, until all \(N\) are reached. That takes about

\[l_{\max} \approx \frac{N}{k}\ \text{steps}.\]

Distances are spread evenly from 1 to \(l_{\max}\), so the average is about half of \(l_{\max}\):

\[\langle l\rangle \approx \frac{N}{2k}, \qquad\text{so for } k = 4,\ \ \langle l\rangle \approx \frac{N}{8}\]

With \(k = 2\) this gives \(N/4\), the plain ring, as it should. The slide simulation with 500 nodes found 125.25 for \(k = 2\) (formula: \(500/4 = 125\)) and 62.88 for \(k = 4\) (formula: 62.5).

Degree is \(k\) for every node (\(P(k) = \delta(k - 4)\) on the slide). Clustering is no longer 0. For \(k = 4\), node \(i\)'s neighbours are \(i - 2,\ i - 1,\ i + 1,\ i + 2\). Among these 4 neighbours there are 6 possible pairs, and 3 of them are linked: \((i-2, i-1)\), \((i-1, i+1)\) and \((i+1, i+2)\), since each of these is at most 2 places apart. So \(C = 3/6 = 1/2\) for every node, as on the slide (which says "if \(N > 6\)", so that the ring is big enough for these to be different nodes).

General formula, rarely needed: \(C = \frac{3(k-2)}{4(k-1)}\).

Two more for comparison

  • Complete graph (every node linked to every other, the "all-to-all" network in Quiz 1): every distance is 1, so \(\langle l\rangle = 1\) and the diameter is 1. Every node has degree \(N - 1\). Clustering is 1. The adjacency matrix is symmetric.
  • Square grid (2-D lattice): \(\langle l\rangle\) grows like \(\sqrt N\). In \(D\) dimensions it grows like \(N^{1/D}\). The ring is the 1-dimensional case, growing like \(N\).
How to write it in the exam
  1. Draw the network for a small \(N\) and state the number of pairs, \(N(N-1)/2\).
  2. List how many pairs are at each distance (star: two kinds; chain: \(N - j\) at distance \(j\); ring: 2 at each distance, seen from one node).
  3. Write the weighted average, simplify, and box the formula.
  4. Check it against your small drawing, then give degree, clustering and diameter, and say how ⟨l⟩ grows with \(N\).

Quiz 1For an all-to-all network (undirected, no self-loops), which are true? (a) symmetric (b) diameter N (c) ⟨l⟩ = 1 (d) ⟨k⟩ = N − 1›

(a) True: undirected means \(A_{ij} = A_{ji}\). (b) False: every pair is directly linked, so the diameter is 1. (c) True: every distance is 1. (d) True: each node links to all \(N - 1\) others.
