8Fixed points and stability

Syllabus · bifurcation (foundation)

A dynamical system is a rule that says how something changes over time, such as a population, the number of infected people, or the charge on a capacitor. A fixed point is a value where the change stops, so the system stays there forever. A fixed point is stable if, after a small push, the system comes back to it, and unstable if a small push sends it away. This section shows how to find fixed points and test their stability. Everything in Parts 3 and 4 uses this.

What the exam can ask
  • Find all fixed points of \(\dot x = f(x)\) and say which are stable.
  • Draw the phase line (a plot of \(\dot x\) against \(x\), with arrows).
  • Explain why a negative slope means stable.

The equation

\[\dot x = f(x)\]

\(x\) is the quantity that changes (say, a population). \(\dot x\) is its rate of change over time (M6): positive means \(x\) is increasing, negative means decreasing. \(f(x)\) is a formula that gives this rate for each value of \(x\).

Example: \(\dot x = x(1 - x)\). At \(x = 0.5\), the rate is \(0.5\times0.5 = 0.25\), so \(x\) is growing. At \(x = 2\), the rate is \(2\times(-1) = -2\), so \(x\) is shrinking. At \(x = 1\), the rate is 0, so \(x\) does not change.

Fixed points

A fixed point \(x^*\) is a value where the rate of change is zero:

\[f(x^*) = 0\]

For \(\dot x = x(1-x)\): \(x(1 - x) = 0\) when \(x = 0\) or \(x = 1\). Those are the two fixed points.

Stability, as a picture

Think of a ball on a hilly surface. A ball resting at the bottom of a valley rolls back if you nudge it: that is a stable fixed point. A ball balanced on a hilltop rolls away if you nudge it: that is an unstable fixed point. Both are places where the ball can rest, but only one survives a small disturbance.

The phase line · reading stability from a plot

Plot \(f(x)\) (the rate) against \(x\).

  • Where the curve is above the axis, \(\dot x > 0\), so \(x\) increases. Draw an arrow pointing right.
  • Where the curve is below the axis, \(\dot x < 0\), so \(x\) decreases. Draw an arrow pointing left.
  • Where the curve crosses the axis, \(\dot x = 0\). That is a fixed point.

If the arrows on both sides point towards a fixed point, it is stable. If they point away, it is unstable.

The slope test

Look at the picture again. At the stable point \(K\), the curve crosses the axis going downhill (from above to below). At the unstable point 0, it crosses going uphill. Downhill means negative slope, uphill means positive slope. So you can test stability with the slope \(f'(x^*)\) (M6) instead of drawing:

\[f'(x^*) < 0\ \Rightarrow\ \text{stable}, \qquad f'(x^*) > 0\ \Rightarrow\ \text{unstable}, \qquad f'(x^*) = 0\ \Rightarrow\ \text{the test cannot decide}\]

The reason, in one line: if you push the system a small distance \(\eta\) (Greek "eta") from the fixed point, the push obeys \(\dot\eta\approx f'(x^*)\,\eta\). That is the equation \(\dot y = ay\) from M8 with \(a = f'(x^*)\), so the push shrinks if the slope is negative and grows if it is positive.

Optional · the full reasoning

Write \(x = x^* + \eta\), where \(\eta\) is small. Since \(x^*\) does not change, \(\dot x = \dot\eta\). Near \(x^*\), the curve \(f\) is close to its tangent line, so \(f(x^* + \eta)\approx f(x^*) + f'(x^*)\eta\). The first term is 0 because \(x^*\) is a fixed point. So \(\dot\eta\approx f'(x^*)\eta\), whose solution is \(\eta(t) = \eta(0)e^{f'(x^*)t}\). When the slope is exactly 0 the tangent line is flat and says nothing, which is why the test fails there. Those are exactly the places where bifurcations happen (§9).

Worked example · logistic growth

\(\dot x = rx\left(1 - \frac xK\right)\), with \(r\) and \(K\) positive numbers. (\(x\) is a population, \(r\) its growth rate, \(K\) the largest population the environment can support.)

  1. Fixed points: \(rx(1 - x/K) = 0\) when \(x = 0\) or \(x = K\).
  2. Multiply out \(f(x) = rx - \frac rK x^2\), so the slope is \(f'(x) = r - \frac{2r}{K}x\).
  3. \(f'(0) = r > 0\): unstable. \(f'(K) = r - 2r = -r < 0\): stable.

So any small positive population grows until it reaches \(K\) and then stays there.

How to write it in the exam
  1. Set \(f(x) = 0\) and solve for every fixed point.
  2. Differentiate to get \(f'(x)\).
  3. Put each fixed point into \(f'\): negative means stable, positive means unstable.
  4. If asked, draw the phase line with arrows to confirm.
What to remember
  • Fixed point: \(f(x^*) = 0\).
  • \(f'(x^*) < 0\) stable, \(f'(x^*) > 0\) unstable, \(f'(x^*) = 0\) undecided.
  • Phase line: arrows towards the point means stable.

9The four bifurcations

Syllabus · bifurcation

Most systems contain a number you can adjust, called a parameter (for example a growth rate or an infection rate), written \(r\). As you slowly change \(r\), the fixed points move. Usually nothing dramatic happens. But at certain values of \(r\), fixed points suddenly appear, disappear, or swap between stable and unstable. That sudden change is a bifurcation. There are four standard types in one dimension, and each has a simple example equation called its normal form.

What the exam can ask
  • "Describe the role of \(r\). What type of bifurcation do you expect?" for a given equation. (2024 mid-sem Q3, 7 marks)
  • Draw the bifurcation diagram (fixed points against \(r\)), marking stable and unstable branches.
  • State the normal form of each bifurcation.

Watching one bifurcation happen

Take \(\dot x = r - x^2\) and try three values of \(r\).

  • \(r = -1\): \(-1 - x^2 = 0\) means \(x^2 = -1\), which has no real solution. No fixed points.
  • \(r = 0\): \(-x^2 = 0\) gives only \(x = 0\). One fixed point.
  • \(r = 1\): \(1 - x^2 = 0\) gives \(x = 1\) and \(x = -1\). Two fixed points. The slope is \(f'(x) = -2x\), so \(f'(1) = -2\) (stable) and \(f'(-1) = 2\) (unstable).

As \(r\) passes 0, a stable and an unstable fixed point appear together out of nothing. That is a saddle-node bifurcation. For general \(r > 0\) the fixed points are \(x^* = \pm\sqrt r\).

A bifurcation diagram draws this: \(r\) along the horizontal axis, the fixed points \(x^*\) up the vertical axis, with each branch marked stable or unstable.

Line style used by the course

The course note draws stable branches dashed and unstable branches solid. Most textbooks do the opposite. The diagrams below follow the course note and also use colour: teal = stable, orange = unstable. In the exam, write the word "stable" or "unstable" next to each branch so there is no confusion.

The four types, worked out

For each one: set \(f(x) = 0\) to find the fixed points, then use the slope to test them, exactly as in §8.

Saddle-node · \(\dot x = r - x^2\)

Fixed points \(x^* = \pm\sqrt r\), which exist only for \(r \ge 0\). Slope \(f' = -2x\): at \(+\sqrt r\) it is negative (stable), at \(-\sqrt r\) positive (unstable). What happens: a stable/unstable pair is created from nothing (or, going the other way, collides and disappears).

Transcritical · \(\dot x = rx - x^2 = x(r - x)\)

Fixed points \(x^* = 0\) and \(x^* = r\), for every \(r\). Slope \(f' = r - 2x\): at 0 it is \(r\), at \(r\) it is \(r - 2r = -r\). So for \(r < 0\), 0 is stable and \(r\) is unstable; for \(r > 0\), 0 is unstable and \(r\) is stable. What happens: the two branches cross and exchange stability.

Supercritical pitchfork · \(\dot x = rx - x^3 = x(r - x^2)\)

Fixed points \(x^* = 0\) always, plus \(\pm\sqrt r\) when \(r > 0\). Slope \(f' = r - 3x^2\): at 0 it is \(r\); at \(\pm\sqrt r\) it is \(r - 3r = -2r\), negative. What happens: 0 loses stability at \(r = 0\) and two stable branches grow out of it, like the prongs of a pitchfork.

Subcritical pitchfork · \(\dot x = rx + x^3 = x(r + x^2)\)

Fixed points \(x^* = 0\) always, plus \(\pm\sqrt{-r}\) when \(r < 0\). Slope \(f' = r + 3x^2\): at 0 it is \(r\); at \(\pm\sqrt{-r}\) it is \(r - 3r = -2r\), which is positive because \(r < 0\). What happens: the two side branches are unstable. After \(r = 0\) nothing nearby is stable, so a small push sends the system far away. This is linked to sudden, dramatic jumps.

The Strogatz slides use the letters \(y\) and \(\mu\) (Greek "mu") instead of \(x\) and \(r\), and write the saddle-node as \(\dot y = y^2 + \mu\). That version has its two fixed points for \(\mu < 0\) instead of \(r > 0\). It is the same bifurcation, mirrored.

How to tell which type you have

  1. Solve \(f(x; r) = 0\) for the fixed points in terms of \(r\), and note for which \(r\) they exist.
  2. Count the fixed points on each side of the critical value of \(r\).
  3. Find the slope \(f'\) on each branch and mark it stable or unstable.
  4. Match the pattern.
    • 0 fixed points on one side and 2 on the other: saddle-node.
    • 2 on both sides, crossing and swapping stability: transcritical.
    • 1 becomes 3, symmetric about 0: pitchfork. Supercritical if the new branches are stable, subcritical if unstable.

Bifurcations happen only where the slope test fails, so the critical point can be found by solving \(f = 0\) and \(f' = 0\) together.

Worked example · 2024 mid-sem Q3(a)

\(\dot x = rx - x^2\), where \(r\) is a parameter. Describe the role of \(r\). What type of bifurcation do you expect?

  1. \(x(r - x) = 0\), so the fixed points are \(x^* = 0\) and \(x^* = r\).
  2. The slope is \(f'(x) = r - 2x\). So \(f'(0) = r\) and \(f'(r) = -r\).
  3. For \(r < 0\): \(f'(0) < 0\), so 0 is stable, and \(x^* = r\) is unstable. For \(r > 0\): 0 is unstable and \(x^* = r\) is stable.
  4. The two branches meet at \(r = 0\) and exchange stability: a transcritical bifurcation.

Role of \(r\): it acts like a growth rate. When \(r\) is negative, any small \(x\) dies out to 0. When \(r\) is positive, 0 becomes unstable and \(x\) settles at \(x^* = r\).

Worked example · 2024 mid-sem Q3(b)

\(\dot x = 1 + rx + x^2\). Describe the bifurcations as \(r\) varies.

  1. The fixed points solve \(x^2 + rx + 1 = 0\). By the quadratic formula, \(x^* = \frac{-r\pm\sqrt{r^2 - 4}}{2}\).
  2. A square root of a negative number is not real, so fixed points exist only when \(r^2 \ge 4\), that is \(r \ge 2\) or \(r \le -2\). For \(-2 < r < 2\) there are none. At \(r = \pm2\) there is one. For \(|r| > 2\) there are two.
  3. The slope is \(f'(x) = r + 2x\). Putting in the two roots gives \(f' = +\sqrt{r^2 - 4}\) for the "+" root (unstable) and \(-\sqrt{r^2 - 4}\) for the "−" root (stable).
  4. So a stable/unstable pair is created as \(r\) passes 2, and another as \(r\) passes \(-2\): two saddle-node bifurcations, at \(r = 2\) and \(r = -2\).

For \(-2 < r < 2\), \(1 + rx + x^2\) is positive for every \(x\), so \(x\) keeps increasing and never settles.

Optional · the worked quintic example from the course note

\(\dot x = rx + x^3 - x^5\). Fixed points: \(x = 0\), or, writing \(y = x^2\), \(y^2 - y - r = 0\), so \(y = \frac{1\pm\sqrt{1+4r}}{2}\) and \(x = \pm\sqrt y\). The slope is \(f' = r + 3y - 5y^2\), and on the non-zero branches \(r = y^2 - y\), so \(f' = 2y(1 - 2y)\). The upper branch (\(y > \frac12\)) is stable and the lower branch (\(y < \frac12\)) is unstable. They meet at \(y = \frac12\), \(r = -\frac14\), a saddle-node fold. The lower branch reaches 0 at \(r = 0\), a subcritical pitchfork. Between \(r = -\frac14\) and 0, both \(x = 0\) and the upper branch are stable.

The course note writes the slope as \(2y(2 - 3y)\). Working it out from the note's own equations gives \(2y(1 - 2y)\), which puts the change of stability at the fold \(y = \frac12\), as it should be. Check with your class notes if this comes up.

How to write it in the exam
  1. Set \(f(x; r) = 0\) and write the fixed points as functions of \(r\), with the range of \(r\) where they exist.
  2. Differentiate, evaluate \(f'\) on each branch, and state stable or unstable on each side of the critical \(r\).
  3. Name the bifurcation and give the critical value of \(r\).
  4. Sketch the fixed points against \(r\) and label every branch "stable" or "unstable".
  5. Describe the role of \(r\): what the long-run state is below and above the critical value.
What to remember
  • Saddle-node \(r - x^2\): pair born from nothing.
  • Transcritical \(rx - x^2\): branches cross and swap.
  • Supercritical pitchfork \(rx - x^3\): two stable branches appear.
  • Subcritical pitchfork \(rx + x^3\): two unstable branches, sudden jump.
  • Course convention: dashed = stable, solid = unstable. Label anyway.

10Bistability and hysteresis · the spruce budworm

Syllabus · bifurcation (course note example)

Some systems have two different stable states for the same value of the parameter. Which one you end up in depends on where you start. This is bistability. If you then slowly raise the parameter and lower it again, the system jumps between the two states at two different points, so the way up is not the way down. That is hysteresis. The course note shows both with a model of an insect pest, the spruce budworm.

What the exam can ask
  • Explain bistability and the role of the unstable middle fixed point.
  • Explain hysteresis using the budworm model.
  • State how to find a fold point: solve \(f = 0\) and \(f' = 0\) together.

The model

\[\dot x = r x\left(1 - \frac{x}{K}\right) - \frac{x^2}{1 + x^2}, \qquad K = 10\]

\(x\) is the budworm population. The first part is logistic growth (§8) with growth rate \(r\). The second part is birds eating budworms. It levels off for large \(x\), because birds can only eat so many however many budworms there are.

\(x^* = 0\) is always a fixed point, and it is unstable, since the slope there is \(r > 0\). Dividing the rest by \(x\) and clearing the fractions, the other fixed points solve a cubic (an equation with \(x^3\)):

\[-\frac{r}{10}x^3 + r x^2 - \left(1 + \frac{r}{10}\right)x + r = 0 .\]

A cubic can have up to three solutions. That is why up to three positive fixed points can exist at the same time.

\(r\)Positive fixed pointsStability
0.250.26stable (only a low state)
0.380.43stable (just below the first fold at 0.384)
0.500.68, 2.00, 7.32stable, unstable, stable
0.567.73stable (only a high state, just past the second fold at 0.560)

Bistability

For \(r\) between about 0.384 and 0.560, there are three positive fixed points: stable, unstable, stable. The low stable state is a small "refuge" population kept down by birds. The high stable state is an "outbreak". The unstable one in the middle is a threshold: at \(r = 0.5\), a population starting below 2 ends at 0.68, and one starting above 2 ends at 7.32.

Hysteresis

  1. Start with a small \(r\), on the low branch, and slowly increase \(r\). The population stays low.
  2. At \(r\approx0.560\) the low stable state meets the unstable middle state and both disappear (a saddle-node, §9). The population has nowhere nearby to settle, so it jumps up to the outbreak branch.
  3. Now slowly decrease \(r\). The population stays on the high branch, even below 0.560, until \(r\approx0.384\), where the high state disappears in the other fold. Only then does it drop back down.

The path going up differs from the path coming down. That is hysteresis. In practice, it means that undoing the cause of an outbreak (bringing \(r\) back to where it was) does not end the outbreak. You have to push \(r\) much lower.

Finding a fold

At a fold, the curve of \(\dot x\) just touches the axis without crossing it. Two things are true at once there: it is a fixed point, and the slope is zero.

\[f(x^*; r) = 0 \qquad\text{and}\qquad f'(x^*; r) = 0\]

Solving these two equations together gives the fold points (for the budworm with \(K = 10\), \(r\approx0.384\) and \(r\approx0.560\)).

What to remember
  • Bistable: two stable states with an unstable threshold between them.
  • Hysteresis: the jump up and the jump down happen at different \(r\). Each jump is a saddle-node (fold).
  • Fold: \(f = 0\) and \(f' = 0\) together. Budworm folds at \(r\approx0.384\) and \(0.560\).
