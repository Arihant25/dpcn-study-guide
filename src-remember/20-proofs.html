Show that \(\sum_i k_i = 2L\) (the handshaking lemma), and that the number of odd-degree nodes is even.

Count the link-ends two ways.

  • Total link-ends \(= 2L\)every link has exactly two ends
  • Total link-ends \(= \sum_i k_i\)node \(i\) holds \(k_i\) of them
  • So \(\sum_i k_i = 2L\)same thing counted twice
  • \(2L\) is even, so an even number of the \(k_i\) are odda sum is even only if it has an even number of odd terms

Full proof: Quiz 1 guide §3

Show that \([A^n]_{ij}\) is the number of walks of length \(n\) from \(i\) to \(j\).

Matrix multiplication sums over the middle node, and \(A_{ik}A_{kj} = 1\) only when \(i\to k\to j\) is a real walk.

  • \([A^2]_{ij} = \sum_k A_{ik}A_{kj}\)rule for multiplying matrices
  • \(A_{ik}A_{kj} = 1\) exactly when \(i\to k\to j\) is a walk, else 0both links must exist
  • So \([A^2]_{ij}\) counts 2-step walkssumming over every middle node \(k\)
  • \([A^n]_{ij} = \sum_k [A^{n-1}]_{ik}A_{kj}\)\((n-1)\)-step walks to \(k\), then one last step. Repeat (induction).

Full proof: Quiz 1 guide §4

Show that the number of triangles is \(\frac16\operatorname{tr}(A^3)\).

A triangle is a closed walk of length 3, and each triangle gets counted 6 times.

  • \([A^3]_{ii}\) = closed 3-step walks from \(i\)walk-counting result above
  • A closed 3-walk \(i\to a\to b\to i\) is a triangleno self-loops, so the three nodes are different and all linked
  • \(\operatorname{tr}(A^3) = \sum_i [A^3]_{ii}\) = all closed 3-walks
  • Each triangle gives \(3\times2 = 6\) of them3 starting corners, 2 directions
  • Triangles \(= \frac16\operatorname{tr}(A^3)\)

Full proof: Quiz 1 guide §4

Show that an Euler circuit needs every degree even, and an Euler trail needs exactly 2 odd nodes.

Every time the trail walks into a node, it walks out on a new link, so links get used in pairs.

  • At a middle node, links are used in (in, out) pairsarrive on one link, leave on another unused one
  • \(k_v = 2\times\) (number of visits), which is evenevery link is used exactly once
  • Start node: one extra "out". End node: one extra "in". Both odd.
  • Closed trail: start = end, the extras pair up, so all even
  • So circuit means 0 odd nodes, open trail means exactly 2 (its ends), more than 2 means neither

Full proof: Quiz 1 guide §5

On a path of \(N\) nodes, show that the node at position \(i\) has betweenness \((i-1)(N-i)\).

There's only one route between any two nodes, and it goes through you exactly when they're on opposite sides of you.

  • Every pair has exactly one shortest patha path graph has no loops
  • It passes through node \(i\) iff one end is left of \(i\) and the other is right
  • \(i-1\) nodes on the left, \(N-i\) on the right
  • Betweenness \(= (i-1)(N-i)\)each such pair adds \(1/1 = 1\)

Full method: Quiz 1 guide §8

Show that the forward difference has error \(O(h)\) and the central difference \(O(h^2)\).

Taylor-expand. In the central difference, stepping forward and back makes the \(h^2\) terms cancel.

  • \(f(x_0\pm h) = f(x_0) \pm hf' + \frac{h^2}{2}f'' \pm \frac{h^3}{6}f''' + \dots\)Taylor series
  • \(\frac{f(x_0+h) - f(x_0)}{h} = f' + \frac h2 f'' + \dots\), so error \(O(h)\)
  • \(f(x_0+h) - f(x_0-h) = 2hf' + \frac{h^3}{3}f''' + \dots\)subtract. \(f\) and \(f''\) terms cancel.
  • \(\frac{f(x_0+h) - f(x_0-h)}{2h} = f' + \frac{h^2}{6}f''' + \dots\), so error \(O(h^2)\)

Full proof: Quiz 1 guide §10

Solve \(\dot u = a - bu\) (this is also the charging capacitor).

Separate the variables and integrate. The answer slides exponentially to the fixed point \(a/b\).

  • \(u^* = a/b\), stable\(a - bu^* = 0\), and slope \(-b < 0\)
  • \(\frac{du}{a - bu} = dt\)separate
  • \(-\frac1b\ln\frac{a - bu(t)}{a - bu(0)} = t\)integrate from 0 to \(t\)
  • \(u(t) = \frac ab + \left(u(0) - \frac ab\right)e^{-bt}\)
  • Capacitor: \(V_0 = q/C + R\dot q\) gives \(a = V_0/R\), \(b = 1/RC\), so \(q(t) = CV_0(1 - e^{-t/RC})\)

For \(P(k) = Ck^{-\gamma}\), find \(C\), and say when it is finite.

Probabilities add up to 1. Treat \(k\) as continuous and integrate.

  • \(\int_{k_{\min}}^\infty Ck^{-\gamma}\,dk = 1\)total probability is 1
  • \(C\left[\frac{k^{1-\gamma}}{1-\gamma}\right]_{k_{\min}}^\infty = 1\)
  • \(C\,\frac{k_{\min}^{1-\gamma}}{\gamma-1} = 1\)\(k^{1-\gamma}\to0\) at infinity only if \(\gamma>1\)
  • \(C = (\gamma-1)k_{\min}^{\gamma-1}\), finite only for \(\gamma>1\)

Full proof: Mid-sem guide §1

Find ⟨k⟩ and ⟨k²⟩ for a power law, and show that ⟨k²⟩ diverges for \(\gamma\le3\).

Same integral with one more \(k\) each time. Each extra \(k\) raises the \(\gamma\) you need by 1.

  • \(\langle k\rangle = C\int_{k_{\min}}^\infty k^{1-\gamma}dk = \frac{\gamma-1}{\gamma-2}k_{\min}\)finite only if \(\gamma>2\)
  • \(\langle k^2\rangle = C\int_{k_{\min}}^\infty k^{2-\gamma}dk\)
  • \(\gamma<3\): \(\frac{k^{3-\gamma}}{3-\gamma}\to\infty\)the power \(3-\gamma\) is positive
  • \(\gamma = 3\): \(\int\frac{dk}{k} = [\ln k]\to\infty\)do this case separately, the power rule would divide by 0
  • \(\gamma>3\): \(\langle k^2\rangle = \frac{\gamma-1}{\gamma-3}k_{\min}^2\)
  • Real networks have \(2<\gamma<3\): finite ⟨k⟩, infinite ⟨k²⟩

Full proof: Mid-sem guide §1

Explain why linear bins give a noisy tail on a log-log plot, and why log bins fix it.

The tail has very few nodes, so equal-width bins there hold 0 or 1 node. Make the bins wider as \(k\) grows.

  • \(\log P = \log C - \gamma\log k\), a straight line of slope \(-\gamma\)take logs of \(Ck^{-\gamma}\)
  • Linear bins: tail bins get 0 or 1 node\(P(k)\) is tiny for large \(k\)
  • So the tail is noisy, flattens into a floor, and zeros can't be plotted\(\log 0\) is undefined
  • Log bins grow by a fixed factor (1, 2, 4, 8, …), so wide tail bins collect enough nodes
  • Divide each count by \(N\times\) bin width, and plot at the bin centre

Full answer: Mid-sem guide §2

Star with \(N\) nodes: show that \(\langle l\rangle = 2(N-1)/N\) and that every clustering coefficient is 0.

Only two kinds of pair, hub–leaf (distance 1) and leaf–leaf (distance 2). No two leaves are linked, so no triangles.

  • \(N-1\) hub–leaf pairs at distance 1directly linked
  • \(\frac{(N-1)(N-2)}{2}\) leaf–leaf pairs at distance 2only route is through the hub
  • Total distance \(= (N-1) + (N-1)(N-2) = (N-1)^2\)
  • \(\langle l\rangle = \frac{(N-1)^2}{N(N-1)/2} = \frac{2(N-1)}{N}\to2\)divide by the number of pairs
  • \(C_{\text{hub}} = 0\), \(C_{\text{leaf}} = 0\), so \(\langle C\rangle = 0\)no two leaves linked, and a leaf has one neighbour. It's a tree.

Open chain of \(N\) nodes: show that \(\langle l\rangle = (N+1)/3\).

There are \(N-j\) pairs at distance \(j\). Add up and divide by the number of pairs.

  • \(N-j\) pairs at distance \(j\), for \(j = 1,\dots,N-1\)slide a gap of length \(j\) along the chain
  • \(\sum_j j(N-j) = N\cdot\frac{N(N-1)}{2} - \frac{(N-1)N(2N-1)}{6}\)\(\sum j\) and \(\sum j^2\) up to \(N-1\)
  • \(= \frac{N(N-1)(N+1)}{6}\)
  • \(\langle l\rangle = \frac{N(N-1)(N+1)/6}{N(N-1)/2} = \frac{N+1}{3}\)

Full proof: Mid-sem guide §3

Ring of \(N\) nodes: show that \(\langle l\rangle\approx N/4\), and \(\approx N/(2k)\) when each node has degree \(k\).

From any node, the distances run 1, 2, …, up to about \(N/2\), two nodes at each. Their average is about \(N/4\).

  • From one node: 2 nodes at each distance \(1, 2, \dots, N/2\)go either way round
  • Average of \(1,\dots,N/2\) \(\approx\frac{N}{4}\)half the largest value
  • Every node looks the same, so \(\langle l\rangle\approx N/4\)
  • Degree \(k\): each step covers \(k/2\) places, so \(\langle l\rangle\approx\frac{N/4}{k/2} = \frac{N}{2k}\)\(k = 2\) gives back \(N/4\)

Full proof: Mid-sem guide §3

Show that the ER degree distribution becomes Poisson for large \(N\) and small \(p\). Find ⟨k⟩ and ⟨k²⟩.

Start from the binomial, keep ⟨k⟩ fixed, and approximate each of its three factors.

  • \(P(k) = \binom{N-1}{k}p^k(1-p)^{N-1-k}\)choose which \(k\) of the \(N-1\) links exist, each with probability \(p\)
  • \(\binom{N-1}{k}\approx\frac{(N-1)^k}{k!}\)\(k\ll N\)
  • \(p^k = \frac{\langle k\rangle^k}{(N-1)^k}\)\(p = \langle k\rangle/(N-1)\)
  • \((1-p)^{N-1-k}\approx e^{-\langle k\rangle}\)\((1 - x/n)^n\to e^{-x}\)
  • \(P(k) = e^{-\langle k\rangle}\frac{\langle k\rangle^k}{k!}\)multiply. \((N-1)^k\) cancels.
  • ⟨k⟩ \(= p(N-1)\), variance \(=\) ⟨k⟩, so \(\langle k^2\rangle = \langle k\rangle + \langle k\rangle^2\)

Full proof: Mid-sem guide §4

Derive the giant-component equation \(S = 1 - e^{-\langle k\rangle S}\).

A node is outside the giant component if each other node is either not linked to it, or linked but outside too.

  • \(u = 1 - S\)chance a node is outside
  • Per other node: \(1 - p + pu\)no link, or a link to an outside node
  • \(u = (1 - p + pu)^{N-1} = \left[1 - \frac{\langle k\rangle(1-u)}{N-1}\right]^{N-1}\)independent, and \(p = \langle k\rangle/(N-1)\)
  • \(u = e^{-\langle k\rangle(1-u)}\)\((1 - x/n)^n\to e^{-x}\)
  • \(S = 1 - e^{-\langle k\rangle S}\)put \(u = 1 - S\)

Full proof: Mid-sem guide §5

Show that a giant component exists if and only if \(\langle k\rangle>1\), and that \(\beta = 1\).

Draw \(y = S\) and \(y = 1 - e^{-\langle k\rangle S}\). The curve starts with slope ⟨k⟩ and bends down, so it can rise above the line only if ⟨k⟩ > 1.

  • \(S = 0\) is always a solution\(1 - e^0 = 0\)
  • Slope of the curve at 0 is ⟨k⟩, and it's concave\(y_2' = \langle k\rangle e^{-\langle k\rangle S}\), \(y_2'' < 0\)
  • ⟨k⟩ ≤ 1: curve starts no steeper and only flattens, so it stays below \(y = S\). No positive root.
  • ⟨k⟩ > 1: curve starts above the line but is below it at \(S = 1\), so they cross once in between\(1 - e^{-\langle k\rangle} < 1\)
  • Near threshold: \(S\approx\langle k\rangle S - \frac{\langle k\rangle^2S^2}{2}\), so \(S\approx\frac{2(\langle k\rangle-1)}{\langle k\rangle^2}\sim(\langle k\rangle-1)^1\), \(\beta = 1\)expand \(e^{-x}\) to \(x^2\), divide by \(S\)

Show that an ER graph has \(\langle l\rangle\approx\ln N/\ln\langle k\rangle\).

You reach ⟨k⟩ nodes in one step, ⟨k⟩² in two, ⟨k⟩d in \(d\). That explodes, so very few steps reach everyone.

  • About \(\langle k\rangle^r\) nodes at distance \(r\)the neighbourhood is tree-like (no nearby loops)
  • \(N\sim1 + \langle k\rangle + \dots + \langle k\rangle^d\approx\langle k\rangle^d\)the last term dominates
  • \(\ln N\approx d\ln\langle k\rangle\)take logs
  • \(\langle l\rangle\approx d\approx\frac{\ln N}{\ln\langle k\rangle}\), which grows slowly (concave in \(N\))

Full proof: Mid-sem guide §6

Show that in an ER graph \(C_i = p\) for every degree, and sketch \(\bar C\) against \(N\).

Whether two of your friends are linked is just another coin flip with probability \(p\).

  • \(C_i = e_i\big/\binom{k_i}{2}\)linked neighbour pairs over all neighbour pairs
  • \(E[e_i] = p\binom{k_i}{2}\)each pair is linked independently with probability \(p\)
  • \(E[C_i] = p\), and \(k_i\) cancels
  • \(\bar C = p\approx\langle k\rangle/N\)\(\langle k\rangle\approx Np\)
  • So \(\bar C\to0\) like \(1/N\) (slope −1 on log-log), but real networks keep \(\bar C\) high whatever \(N\)

Full proof: Mid-sem guide §6

Show that \(\langle k_{nn}\rangle = \frac{\langle k^2\rangle}{\langle k\rangle} = \langle k\rangle + \frac{\operatorname{Var}(k)}{\langle k\rangle}\ge\langle k\rangle\) (friendship paradox).

Following a link lands on a node with probability proportional to its degree, so hubs get over-counted.

  • \(q_k = \frac{kP(k)}{\langle k\rangle}\)a degree-\(k\) node has \(k\) links pointing to it
  • \(\langle k_{nn}\rangle = \sum_k kq_k = \frac{\langle k^2\rangle}{\langle k\rangle}\)
  • \(= \frac{\langle k\rangle^2 + \operatorname{Var}(k)}{\langle k\rangle} = \langle k\rangle + \frac{\operatorname{Var}(k)}{\langle k\rangle}\)\(\langle k^2\rangle = \langle k\rangle^2 + \operatorname{Var}\)
  • \(\ge\langle k\rangle\), equal only if all degrees are equala variance is never negative
  • ER: \(\operatorname{Var} = \langle k\rangle\), so \(\langle k_{nn}\rangle = \langle k\rangle + 1\)

The same ratio \(\operatorname{Var}(k)/\langle k\rangle\) tests for ER. About 1 means Poisson (ER). Much bigger than 1 means hubs, so a power law (scale-free).

Show that a fixed point of \(\dot x = f(x)\) is stable when \(f'(x^*)<0\).

Push it a little. The push grows or shrinks like \(e^{f'(x^*)t}\).

  • \(x = x^* + \varepsilon\), so \(\dot\varepsilon = f(x^* + \varepsilon)\)\(x^*\) is constant
  • \(\dot\varepsilon\approx f(x^*) + f'(x^*)\varepsilon = f'(x^*)\varepsilon\)Taylor, and \(f(x^*) = 0\)
  • \(\varepsilon(t) = \varepsilon_0e^{f'(x^*)t}\)
  • Shrinks if \(f'(x^*)<0\) (stable), grows if \(f'(x^*)>0\) (unstable)

Full proof: Mid-sem guide §8

For \(\dot x = rx - x^2\), describe the role of \(r\) and name the bifurcation.

Two fixed points, 0 and \(r\), pass through each other at \(r = 0\) and swap stability.

  • \(x^* = 0\) or \(x^* = r\)\(x(r - x) = 0\)
  • \(f'(x) = r - 2x\), so \(f'(0) = r\), \(f'(r) = -r\)
  • \(r<0\): 0 stable, \(r\) unstable. \(r>0\): 0 unstable, \(r\) stable.
  • They swap stability at \(r = 0\): transcritical bifurcation

Same recipe for the others. \(\dot x = 1 + rx + x^2\) has \(x^* = \frac{-r\pm\sqrt{r^2-4}}{2}\), real only for \(|r|\ge2\), with \(f' = \pm\sqrt{r^2-4}\). So a stable and an unstable point appear together at \(r = \pm2\): two saddle-node bifurcations.

Solve the SIS model \(\dot I = \beta SI - \gamma I\), \(S + I = 1\). Find \(I^*\) and when the disease dies out.

With \(S = 1 - I\) it's the logistic equation, so it rises in an S-curve to \(1 - \gamma/\beta\).

  • \(\dot I = (\beta-\gamma)I - \beta I^2 = aI\left(1 - \frac IK\right)\)\(S = 1 - I\). \(a = \beta - \gamma\), \(K = 1 - \gamma/\beta\)
  • \(\frac{dI}{I(1 - I/K)} = a\,dt\), and \(\frac{1}{I(1-I/K)} = \frac1I + \frac{1}{K - I}\)separate, partial fractions
  • \(\ln\frac{I}{K - I} = at + \ln\frac{I_0}{K - I_0}\)integrate, use \(I(0) = I_0\)
  • \(I(t) = \dfrac{K}{1 + \frac{K - I_0}{I_0}e^{-(\beta-\gamma)t}}\)
  • \(t\to\infty\): \(I^* = 1 - \gamma/\beta\) when \(\beta>\gamma\)
  • \(\beta<\gamma\): \(f'(0) = \beta - \gamma < 0\), so \(I = 0\) is stable and the disease dies out

SIS with ⟨k⟩ contacts, infection rate β, recovery δ, \(\lambda = \beta/\delta\). Write the equation and find the threshold \(\lambda_c\).

Gains minus losses. Gains need a healthy person (\(1-i\)) meeting infected contacts (\(\langle k\rangle i\)) at rate β.

  • Loss: \(-\delta i\)each infected person recovers at rate δ
  • Gain: \(+\beta\langle k\rangle i(1-i)\)susceptible fraction × infected contacts × rate
  • \(\frac{di}{dt} = \beta\langle k\rangle i(1-i) - \delta i\)
  • \(i = 0\) or \(i^* = 1 - \frac{1}{\lambda\langle k\rangle}\)set \(di/dt = 0\)
  • \(i^*>0\) needs \(\lambda\langle k\rangle>1\), so \(\lambda_c = 1/\langle k\rangle\)a fraction can't be negative
  • More contacts means a lower threshold. \(R_0 = \lambda\langle k\rangle\) is how many each case infects.

Show that the Laplacian \(L = D - A\) has eigenvalues \(\ge0\), and as many zero eigenvalues as components.

\(\mathbf x^TL\mathbf x\) is a sum of squares over the links.

  • \(L\mathbf 1 = 0\)each row sums to \(k_i - k_i = 0\)
  • \(\mathbf x^TL\mathbf x = \sum_{\text{links }(i,j)}(x_i - x_j)^2\ge0\)
  • For a unit eigenvector, \(\mathbf x^TL\mathbf x = \lambda\), so \(\lambda\ge0\)
  • \(\lambda = 0\) needs \(x_i = x_j\) on every link, so \(\mathbf x\) is constant on each component
  • One such vector per component, so the zero count = the number of components

Full proof: Mid-sem guide §12

Show that diffusion \(\dot x_i = C\sum_jA_{ij}(x_j - x_i)\) ends with every node at the average.

Write it with the Laplacian, split into eigenvectors, and every part except the constant one dies away.

  • \(\dot{\mathbf x} = -CL\mathbf x\)\(\sum_jA_{ij}(x_j - x_i) = -\sum_jL_{ij}x_j\)
  • \(\mathbf x(t) = \sum_r a_r(t)\mathbf v_r\)eigenvectors of \(L\)
  • \(\dot a_r = -C\lambda_ra_r\), so \(a_r(t) = a_r(0)e^{-C\lambda_rt}\)\(L\mathbf v_r = \lambda_r\mathbf v_r\)
  • \(\lambda_1 = 0\) part stays. All others decay (connected network).
  • That part is the constant vector, so every node ends at the average. Speed set by \(\lambda_2\).

SIS on a network, \(\dot i_k = -\gamma i_k + \beta(1 - i_k)\sum_jA_{kj}i_j\). How does the network affect the early stage, and when does the disease not spread?

Early on everything is small, so drop the product term. Then the largest eigenvalue of \(A\) sets the growth.

  • Each eigenvector part grows like \(e^{(\beta\kappa_r - \gamma)t}\)\(A\mathbf v_r = \kappa_r\mathbf v_r\)

  • So \(\kappa_1\) sets the speed and \(\mathbf v_1\) says which nodes get hit first
  • No spread if \(\beta\kappa_1 - \gamma<0\), that is \(\beta/\gamma<1/\kappa_1\)

Solve \(\dot{\mathbf x} = A\mathbf x\) in 2-D, and get the eigenvalue equation \(\lambda^2 - \tau\lambda + \Delta = 0\).

Guess \(e^{\lambda t}\mathbf v\). It works exactly when \(\mathbf v\) is an eigenvector.

  • Try \(\mathbf x = e^{\lambda t}\mathbf v\): \(\lambda e^{\lambda t}\mathbf v = e^{\lambda t}A\mathbf v\)
  • \(A\mathbf v = \lambda\mathbf v\)cancel \(e^{\lambda t}\neq0\)
  • \(\det(A - \lambda I) = (a-\lambda)(d-\lambda) - bc = 0\)\(\mathbf v\neq0\)
  • \(\lambda^2 - \tau\lambda + \Delta = 0\), \(\tau = a + d\), \(\Delta = ad - bc\), so \(\lambda = \frac{\tau\pm\sqrt{\tau^2 - 4\Delta}}{2}\)
  • \(\mathbf x(t) = c_1e^{\lambda_1t}\mathbf v_1 + c_2e^{\lambda_2t}\mathbf v_2\)linear, so solutions add. \(c_1, c_2\) from \(\mathbf x(0)\).

Full proof: After mid-sem guide §1

Classify a 2-D fixed point using \(\tau\) and \(\Delta\).

Read it off \(\lambda = \frac{\tau\pm\sqrt{\tau^2-4\Delta}}{2}\). \(\Delta = \lambda_1\lambda_2\) and \(\tau = \lambda_1 + \lambda_2\).

  • \(\Delta<0\): eigenvalues real with opposite signs, so a saddle\(\lambda_1\lambda_2 = \Delta\)
  • \(\Delta>0\), \(\tau^2>4\Delta\): real, same sign, so a node
  • \(\Delta>0\), \(\tau^2<4\Delta\): complex, so a spiral
  • Stable if \(\tau<0\), unstable if \(\tau>0\)\(\tau\) is the sum (or twice the real part)
  • \(\tau = 0\), \(\Delta>0\): \(\lambda = \pm i\sqrt\Delta\), a center

Four fixed points. The coexistence one is a saddle, so one species always wins.

  • \(J = \begin{pmatrix}3 - 2x - 2y & -2x\\ -y & 2 - x - 2y\end{pmatrix}\)

  • \((3,0)\): \(\lambda = -3, -1\), and \((0,2)\): \(\lambda = -1, -2\). Both stable nodes.triangular matrices, read the diagonal
  • \((1,1)\): \(\Delta = 1 - 2 = -1<0\), saddle, \(\lambda = -1\pm\sqrt2\)
  • Only "rabbits only" or "sheep only" survive: competitive exclusion
