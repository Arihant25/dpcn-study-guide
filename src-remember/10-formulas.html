Page 1 · Network basics (classes 1 to 6)

Open the Quiz 1 guide →
  • Degree of node \(i\)\(k_i = \sum_j A_{ij}\) (the row sum of the adjacency matrix)
  • Handshaking lemma\(\sum_i k_i = 2L\), so \(\langle k\rangle = 2L/N\)
  • Walks\([A^n]_{ij}\) = number of walks of length \(n\) from \(i\) to \(j\)
  • Triangles\(\frac16\operatorname{tr}(A^3)\)
  • Euler paths0 odd-degree nodes gives a circuit, 2 gives a trail, more gives none
  • Clustering of node \(i\)\(C_i = \dfrac{2L_i}{k_i(k_i-1)}\), where \(L_i\) = links among \(i\)'s neighbours
  • Closeness\(1/\sum_j d_{ij}\)
  • Betweenness\(\sum_{s,t}\sigma_{st}(v)/\sigma_{st}\) (share of shortest paths through \(v\))
  • Eigenvector centrality\(A\mathbf x = \lambda_{\max}\mathbf x\)
  • Complete graph, tree\(N(N-1)/2\) links, and \(N-1\) links
  • Euler's method\(y_{n+1} = y_n + h\,f(y_n)\)
  • Derivative errorsForward difference \(O(h)\), central difference \(O(h^2)\)

Page 2 · Mid-sem topics

Open the Mid-sem guide →
  • Power law\(P(k) = Ck^{-\gamma}\), with \(C = (\gamma-1)k_{\min}^{\gamma-1}\)
  • Its averages\(\langle k\rangle = \frac{\gamma-1}{\gamma-2}k_{\min}\) (needs \(\gamma>2\)), \(\langle k^2\rangle = \frac{\gamma-1}{\gamma-3}k_{\min}^2\) (needs \(\gamma>3\))
  • On log-log axes\(\log P = \log C - \gamma\log k\), a straight line of slope \(-\gamma\)
  • Average path lengthStar \(\frac{2(N-1)}{N}\), chain \(\frac{N+1}{3}\), ring \(\approx\frac N4\), ring with degree \(k\) \(\approx\frac{N}{2k}\)
  • Random (ER) graph\(\langle k\rangle = p(N-1)\), Poisson \(P(k) = e^{-\langle k\rangle}\frac{\langle k\rangle^k}{k!}\), variance = ⟨k⟩
  • Giant component\(S = 1 - e^{-\langle k\rangle S}\). Exists if \(\langle k\rangle>1\). Near it \(S\approx2(\langle k\rangle-1)\)
  • Fully connectedwhen \(\langle k\rangle > \ln N\)
  • ER distances, clustering\(\langle l\rangle\approx\frac{\ln N}{\ln\langle k\rangle}\), and \(C = p = \langle k\rangle/N\)
  • Friendship paradox\(\langle k_{nn}\rangle = \langle k^2\rangle/\langle k\rangle\). For ER it's \(\langle k\rangle + 1\)
  • 1-D stabilityFixed point \(f(x^*) = 0\). Stable if \(f'(x^*)<0\)
  • The four bifurcationsSaddle-node \(r - x^2\), transcritical \(rx - x^2\), pitchfork \(rx - x^3\), subcritical \(rx + x^3\)
  • SIS\(\dot I = (\beta-\gamma)I - \beta I^2\), endemic level \(I^* = 1 - \gamma/\beta\), dies out if \(\beta<\gamma\)
  • Laplacian\(L = D - A\). Number of zero eigenvalues = number of components
  • On a networkDiffusion \(\dot{\mathbf x} = -CL\mathbf x\) ends at the average. SIS spreads if \(\beta/\gamma > 1/\kappa_1\)

  • 2-D linear system\(\lambda^2 - \tau\lambda + \Delta = 0\), where \(\tau = a + d\), \(\Delta = ad - bc\)
  • Classify it\(\Delta<0\) saddle. Otherwise \(\tau<0\) stable, and \(\tau^2>4\Delta\) node, \(\tau^2<4\Delta\) spiral, \(\tau = 0\) center
  • Jacobian\(J_{ij} = \partial f_i/\partial x_j\) at the fixed point. Stable if every eigenvalue has negative real part
  • Rabbits vs sheepCoexistence point \((1,1)\) is a saddle, so one species wins
  • Predator–preyCenter at \((d/c,\ a/b)\), \(\lambda = \pm i\sqrt{ad}\), so populations cycle
  • Hopf, polar form\(\dot z = (\mu + i\omega - |z|^2)z\) gives \(\dot r = \mu r - r^3\), \(\dot\theta = \omega\). Cycle of radius \(\sqrt\mu\)
  • Map stability\(x^* = f(x^*)\), stable if \(|f'(x^*)|<1\)
  • Logistic map\(x_{n+1} = rx_n(1-x_n)\). \(x^* = 1 - 1/r\) stable for \(1
  • LorenzOrigin stable iff \(\rho<1\). Other points \(\left(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho-1\right)\)
  • Two oscillators\(\dot\phi = \Delta\omega - (k_1+k_2)\sin\phi\). Lock iff \(|\Delta\omega|\le k_1+k_2\). \(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1+k_2}\)
  • Kuramoto\(re^{i\psi} = \frac1N\sum_j e^{i\theta_j}\), critical coupling \(K_c = \frac{2}{\pi g(0)}\)
  • May's criterionA large random system is stable if \(\sqrt{SC\sigma^2} < d\)
  • Double pendulumEqual masses: \(\omega = \sqrt{g/L}\,\sqrt{2\pm\sqrt2}\)
