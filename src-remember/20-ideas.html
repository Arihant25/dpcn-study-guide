The two questions behind most answers

That's a lot of formulas. The good news is that most exam questions after class 4 ask one of just two things. Once you see this, many of the formulas above stop being separate facts.

Question 1 · Is it stable?

Nudge the system a little. If it comes back, it's stable. If it runs away, it's unstable. The test is always "look at the slope at the fixed point". Only the kind of slope changes.

Kind of systemStable when
1-D flow \(\dot x = f(x)\)\(f'(x^*) < 0\)
2-D or 3-D flowEvery eigenvalue of the Jacobian has negative real part (in 2-D, \(\tau<0\) and \(\Delta>0\))
Map \(x_{n+1} = f(x_n)\)\(|f'(x^*)| < 1\)
Large random system\(\sqrt{SC\sigma^2} < d\) (May)

Why is a map different? A flow adds a little bit each instant, so the sign of the slope matters. A map multiplies the error by \(f'\) every step, so its size matters. Multiply by 0.5 over and over and you shrink to nothing. Multiply by 2 and you blow up.

Question 2 · Where is the threshold?

Most "critical values" in the course come from one ratio reaching 1. Below it, nothing happens. Above it, something takes off.

What happensThreshold
A giant component appears\(\langle k\rangle = 1\)
A disease (SIS) spreads\(\beta/\gamma = 1\)
A disease spreads on a network\(\beta\kappa_1/\gamma = 1\)
A map's fixed point stops being stable\(|f'(x^*)| = 1\) (logistic map, \(r = 3\))
The Lorenz origin stops being stable\(\rho = 1\)
Two oscillators lock together\(|\Delta\omega|/(k_1+k_2) = 1\), because \(\sin\phi\) can't go past 1
A large system stops being stable\(\sqrt{SC\sigma^2}/d = 1\)

For flows the threshold is a slope reaching 0 instead: the Hopf bifurcation happens at \(\mu = 0\), and every 1-D bifurcation happens where \(f' = 0\). The power-law exponents 2 and 3 are the odd ones out. They're where ⟨k⟩ and ⟨k²⟩ stop being finite.

One recipe for stability

This one recipe answers the SIS question, every bifurcation question, rabbits vs sheep, predator–prey, Lorenz, the Hopf question and the two-oscillator question. Learn it once and you've learnt half the paper.

  1. Find the fixed points. Set every rate to zero and solve.
  2. Take the slope. In 1-D that's \(f'(x)\). In 2-D or 3-D it's the Jacobian \(J\).
  3. Put each fixed point in. In 1-D read the sign. In 2-D work out \(\tau\) and \(\Delta\).
  4. Say what it means. "Stable, so the disease settles at \(1-\gamma/\beta\)", or "saddle, so the species can't coexist".

For a map, step 3 checks \(|f'| < 1\) instead. Even the two-oscillator question is a 1-D problem in disguise, because the phase difference \(\phi\) obeys a single equation.

Six derivations, the short way

Past papers ask for these most often. Each one is written as a chain of short lines, with the reason after "∵". Cover the page, write the chain from memory, then check. The full versions are in the guides.

1 · SIS model

  • \(\dot I = \beta SI - \gamma I\)infections minus recoveries
  • \(S = 1 - I\)everyone is either S or I
  • \(\dot I = (\beta-\gamma)I - \beta I^2\)
  • \(I = 0\) or \(I^* = 1 - \gamma/\beta\)set \(\dot I = 0\)
  • \(f'(0) = \beta - \gamma\)slope at \(I = 0\)
  • If \(\beta<\gamma\), \(I = 0\) is stable, so the disease dies out. If \(\beta>\gamma\) it settles at \(I^*\).

Full version with the solution \(I(t)\): Mid-sem guide §11

2 · Power-law constant and average

  • \(\int_{k_{\min}}^\infty Ck^{-\gamma}\,dk = 1\)probabilities add up to 1
  • \(C\,\dfrac{k_{\min}^{1-\gamma}}{\gamma-1} = 1\)\(k^{1-\gamma}\to0\) at infinity only if \(\gamma>1\)
  • \(C = (\gamma-1)k_{\min}^{\gamma-1}\)
  • \(\langle k\rangle = \int k\cdot Ck^{-\gamma}\,dk = \dfrac{\gamma-1}{\gamma-2}k_{\min}\)same integral with one more \(k\), needs \(\gamma>2\)
  • \(\langle k^2\rangle = \dfrac{\gamma-1}{\gamma-3}k_{\min}^2\)one more \(k\) again, needs \(\gamma>3\)

Spot the pattern? Each extra power of \(k\) knocks 1 off the bottom. Real networks have \(2<\gamma<3\), so ⟨k⟩ is finite but ⟨k²⟩ blows up.

Full version: Mid-sem guide §1

3 · Giant component

  • \(u = 1 - S\)\(u\) = chance a node is outside the giant component
  • \(u = (1 - p + pu)^{N-1}\)every other node is either not linked to it, or linked but also outside
  • \(u = \left(1 - \frac{\langle k\rangle S}{N-1}\right)^{N-1}\to e^{-\langle k\rangle S}\)\(p = \langle k\rangle/(N-1)\) and \((1 - x/n)^n\to e^{-x}\)
  • \(S = 1 - e^{-\langle k\rangle S}\)
  • The right side has slope ⟨k⟩ at \(S = 0\), so it crosses the line \(y = S\) again only if \(\langle k\rangle>1\).

4 · Stability of a map

  • \(x^* + \varepsilon_{n+1} \approx f(x^*) + f'(x^*)\varepsilon_n\)value plus slope times change

  • \(\varepsilon_n = [f'(x^*)]^n\varepsilon_0\), which shrinks only if \(|f'(x^*)|<1\)

5 · Limit cycle and Hopf bifurcation

  • \(\dot z = (\mu + i\omega - |z|^2)z\), with \(z = re^{i\theta}\)
  • \(\dot z = (\dot r + ir\dot\theta)e^{i\theta}\)product rule
  • \(\dot r + ir\dot\theta = (\mu - r^2)r + i\omega r\)cancel \(e^{i\theta}\)
  • \(\dot r = \mu r - r^3\), \(\dot\theta = \omega\)match real and imaginary parts
  • For \(\mu>0\): \(r = 0\) unstable (slope \(\mu\)), \(r = \sqrt\mu\) stable (slope \(-2\mu\)). That circle is the limit cycle.

6 · Two coupled oscillators

  • \(\dot\theta_1 = \omega_1 + k_1\sin(\theta_2-\theta_1)\), \(\dot\theta_2 = \omega_2 + k_2\sin(\theta_1-\theta_2)\)
  • \(\dot\phi = (\omega_2-\omega_1) - (k_1+k_2)\sin\phi\)\(\phi = \theta_2 - \theta_1\), subtract
  • \(\sin\phi^* = \dfrac{\omega_2-\omega_1}{k_1+k_2}\)locked means \(\phi\) stops changing
  • \(|\omega_2-\omega_1| \le k_1+k_2\)a sine can't go past 1
  • \(\Omega = \dfrac{k_2\omega_1 + k_1\omega_2}{k_1+k_2}\)multiply the equations by \(k_2\) and \(k_1\), add, and \(\sin\phi^*\) cancels
