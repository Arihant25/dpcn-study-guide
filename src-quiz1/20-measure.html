7Clustering coefficient

Module 2b · slides 2–7

Clustering asks whether your neighbours are also neighbours of each other ("are my friends friends with each other?"). It is a number between 0 (none of your neighbours know each other) and 1 (all of them do).

What the exam can ask
  • Compute the clustering of given nodes in a drawn graph (Quiz 1 Q1, both sets).
  • Average clustering; clustering of special graphs (complete = 1, tree or bipartite = 0).
\[C_i = \frac{L_i}{k_i(k_i - 1)/2} = \frac{2L_i}{k_i(k_i-1)}, \qquad \langle C\rangle = \frac1N\sum_iC_i\]

\(k_i\) is the degree of node \(i\), so it has \(k_i(k_i-1)/2\) pairs of neighbours. \(L_i\) is how many of those pairs are actually linked. \(C_i\) is defined only when \(k_i\ge2\); for \(k_i < 2\) the slides set it to 0.

Method to learn
  1. List the neighbours of node \(i\) and count them: \(k_i\).
  2. List every pair of neighbours: there are \(k_i(k_i-1)/2\).
  3. Count how many of those pairs are linked: \(L_i\).
  4. Divide: \(C_i = L_i\big/\frac{k_i(k_i-1)}{2}\).

Average over the 7 nodes: \((\frac16 + \frac13 + \frac23 + 1)/7 = \frac{13}{6}/7 = \frac{13}{42}\approx0.31\).

A second, whole-network version is the transitivity: \(3\times\)(number of triangles) ÷ (number of connected triples, i.e. paths of two links). It weighs high-degree nodes more than the plain average does.

What to remember

\(C_i = 2L_i/(k_i(k_i-1))\); \(\langle C\rangle\) = average. Complete graph: 1. Tree, star or bipartite graph: 0.

8The four centralities

Module 2b · slides 8–41

A centrality is a score that says how important a node is. "Important" can mean different things, so there are four standard scores: how many links a node has (degree), how close it is to everyone (closeness), how often it lies on shortest routes between others (betweenness), and how well connected its neighbours are (eigenvector). They pick out influencers in a social network, critical routers on the internet, or super-spreaders of a disease.

What the exam can ask
  • Match each centrality to its idea (multiple choice).
  • Compute betweenness and closeness of given nodes (Quiz 1, both sets).
  • Compute eigenvector centrality by the power method.
CentralityIdeaFormula
DegreeMany direct connections\(C_D(v) = k_v\); normalised \(k_v/(N-1)\) (slide 14 divides by \(N\))
ClosenessClose to everyone (spreads information fast)\(C_C(v) = \dfrac{1}{\sum_u d(v,u)}\); normalised \(\dfrac{N-1}{\sum_u d(v,u)}\)
BetweennessLies on many shortest routes (a broker or bottleneck)\(C_B(v) = \displaystyle\sum_{s\ne v\ne t}\frac{\sigma_{st}(v)}{\sigma_{st}}\); normalised by dividing by \(\frac{(N-1)(N-2)}{2}\)
EigenvectorLinked to important nodes\(\lambda x_i = \sum_jA_{ij}x_j\), i.e. \(A\mathbf x = \lambda\mathbf x\) with the largest \(\lambda\)

\(d(v,u)\) is the distance from \(v\) to \(u\). \(\sigma_{st}\) is the number of shortest paths between \(s\) and \(t\), and \(\sigma_{st}(v)\) the number of those that pass through \(v\). The betweenness sum is over pairs \(\{s,t\}\) not containing \(v\).

Method to learn · betweenness and closeness by hand
  1. Closeness of \(v\): find the distance from \(v\) to every other node (BFS, §6), add them, take \(1/\text{sum}\) (or \((N-1)/\text{sum}\) normalised).
  2. Betweenness of \(v\): list every pair of other nodes. For each pair, count the shortest paths between them and how many pass through \(v\). Add up the fractions.
  3. Shortcut on a path (a line of nodes): there is exactly one route between any two nodes, so a node at position \(i\) of \(N\) lies between every node on its left and every node on its right: \(C_B = (i-1)(N-i)\).
  4. Shortcut for an end node or a node whose neighbours are all linked to each other: betweenness 0 (no shortest path needs to pass through it).

Worked example · 2024 Quiz 1 Q1, the bowtie
  1. Clustering. X has neighbours L and Y, which are linked: \(C_X = 1/1 = 1\). Y has 4 neighbours (6 pairs), of which 2 pairs are linked (X–L and U–D): \(C_Y = 2/6 = 1/3\).
  2. (a) Degree of Y > X? \(k_Y = 4\), \(k_X = 2\). True.
  3. (b) Betweenness of X > Y? X's neighbours are linked, so no shortest path needs X: \(C_B(X) = 0\). Every route from {X, L} to {U, D} passes through Y: 4 pairs, \(C_B(Y) = 4\). False.
  4. (c) Closeness of X smaller than Y? X's distances 1, 1, 2, 2 (sum 6); Y's distances 1, 1, 1, 1 (sum 4). \(C_C(X) = 1/6 < C_C(Y) = 1/4\). True.

Eigenvector centrality and the power method

Degree counts each neighbour as 1. Eigenvector centrality counts each neighbour by its own importance: \(x_i\propto\sum_jA_{ij}x_j\). Writing the proportionality constant as \(1/\lambda\) gives \(A\mathbf x = \lambda\mathbf x\): the scores form an eigenvector of \(A\). We take the eigenvector of the largest eigenvalue, which for a connected network has all positive entries.

Method to learn · the power method
  1. Start with all scores equal: \(\mathbf x_0 = (1, 1, \dots, 1)\).
  2. Multiply by \(A\): each node's new score is the sum of its neighbours' scores. (The first step gives the degrees.)
  3. Divide by the vector's length \(\sqrt{\sum x_i^2}\) so the numbers stay small. That length is the "normalised value".
  4. Repeat. The normalised value settles at the largest eigenvalue \(\lambda\), and the vector settles at the eigenvector centrality. (The slides: "for exam purposes, stop when the normalised value converges".)
  5. Why it works: write \(\mathbf x_0\) as a mix of eigenvectors. Each multiplication by \(A\) multiplies the part along eigenvector \(r\) by \(\lambda_r\). After many steps the part with the largest \(|\lambda|\) outgrows all others.
Worked example · slide 28, a 2×2 matrix

\(A = \begin{pmatrix}2 & -12\\ 1 & -5\end{pmatrix}\), start \((1, 1)\). Dividing each result by its second entry:

\((-10, -4)\to(2.50, 1)\); \((28, 10)\to(2.80, 1)\); \((-64, -22)\to(2.91, 1)\); \((136, 46)\to(2.96, 1)\); … → \((3, 1)\).

Check: eigenvalues from \(\lambda^2 + 3\lambda + 2 = 0\) are \(-1, -2\); the dominant one is \(-2\), with eigenvector \((3, 1)\). The signs flip each step because \(\lambda = -2\) is negative.

Worked example · 2024 Surprise Quiz 2 Q2

Links A–B, A–C, A–D, B–C, C–D. A and C have degree 3, B and D degree 2. By symmetry write \(\mathbf x = (a, b, a, b)\). Then \(\lambda a = b + a + b\) (A's neighbours B, C, D) and \(\lambda b = 2a\) (B's neighbours A, C). Eliminating \(\lambda\) with \(t = a/b\): \(2t^2 - t - 2 = 0\), \(t = \frac{1 + \sqrt{17}}{4} = 1.28\), \(\lambda = 2t = 2.56\). Normalised: A, C ≈ 0.56 and B, D ≈ 0.44.

The official key gave 0.5 for every node, which is only right if all degrees were equal. Write the correct calculation and note the difference.

What to remember
  • Degree: \(k_v\). Closeness: \(1/\sum d\) (×\((N-1)\) normalised). Betweenness: \(\sum\sigma_{st}(v)/\sigma_{st}\) (÷\(\frac{(N-1)(N-2)}2\)). Eigenvector: \(A\mathbf x = \lambda_{\max}\mathbf x\).
  • Path: betweenness \((i-1)(N-i)\). Power method: multiply by \(A\), normalise, repeat.

9Special graphs

Module 2b · slides 42–45 · Module 3 · slides 12–18

A few graph shapes come up so often that they have names and their properties can be written down at once.

GraphWhat it isKey facts
Complete graph \(K_N\)Every pair of nodes linked\(L = \frac{N(N-1)}{2}\), every degree \(N-1\), every distance 1, clustering 1, adjacency matrix all 1s off the diagonal
Regular graphEvery node has the same degree \(k\)Ring (\(k = 2\)), lattices. \(\langle k_{nn}\rangle = \langle k\rangle\).
Bipartite graphNodes in two groups; links only go between groupsNo odd cycles, so no triangles: clustering 0. Examples: users–movies, authors–papers, customers–products, stars, square lattices.
TreeConnected, no cyclesExactly \(N - 1\) links. Removing any link disconnects it. Clustering 0.
Spanning treeA tree inside a connected graph that reaches every node\(N - 1\) links; found by removing one link from each cycle while keeping everything connected
CliqueA group of nodes all linked to each otherA complete graph inside a bigger graph

Bipartite projection. From a bipartite graph with groups U and V, the U-projection links two U-nodes if they share at least one V-neighbour (e.g. two actors who appeared in the same film).

Worked example · 2024 Surprise Quiz 2, spanning tree

A spanning tree needs \(6 - 1 = 5\) links, so remove 3, one from each cycle, without disconnecting anything. Removing B–C, C–D and E–F leaves A–B, A–C, B–E, C–F, D–F: connected, no cycles, 5 links. A spanning tree must cover all nodes, be connected, be acyclic and have \(N-1\) links; "must have a cycle" is the one property that does not describe it.
