TopicFormula or fact
Adjacency matrix\(A_{ij} = 1\) if \(i\to j\). Undirected ⇒ symmetric; no loops ⇒ zero diagonal; components ⇒ block-diagonal.
Degree\(k_i = \sum_jA_{ij}\); out = row sum, in = column sum. \(\sum k_i = 2L\), \(\langle k\rangle = 2L/N\) (directed: \(L/N\)). Odd-degree nodes come in even numbers.
Walks\([A^n]_{ij}\) = number of walks of length \(n\). \([A^2]_{ii} = k_i\). Triangles \(= \frac16\operatorname{tr}(A^3)\).
EulerConnected: 0 odd nodes ⇒ Euler circuit; 2 odd ⇒ Euler trail between them; more ⇒ none. Hamiltonian = every node once (no simple test).
Distance\(d_{\max} = \max d_{ij}\); \(\langle d\rangle = \sum_{\text{pairs}}d_{ij}\big/\frac{N(N-1)}2\). BFS labels = distances. Components = Laplacian nullity.
Clustering\(C_i = 2L_i/(k_i(k_i-1))\); \(\langle C\rangle = \frac1N\sum C_i\). Complete 1; tree/bipartite 0.
CentralitiesDegree \(k_v\) (norm. \(/(N-1)\)). Closeness \(1/\sum d\) (norm. ×\((N-1)\)). Betweenness \(\sum\sigma_{st}(v)/\sigma_{st}\) (norm. \(/\frac{(N-1)(N-2)}2\)); on a path \((i-1)(N-i)\). Eigenvector \(A\mathbf x = \lambda_{\max}\mathbf x\), power method.
Special graphs\(K_N\): \(\frac{N(N-1)}2\) links. Tree: \(N - 1\) links, no cycles. Bipartite: no odd cycles.
NumericalForward difference \(O(h)\), central \(O(h^2)\). Euler \(y_{n+1} = y_n + hf\). Truncation vs round-off error. \(u = \frac ab + (u_0 - \frac ab)e^{-bt}\); \(q = CV_0(1 - e^{-t/RC})\).
