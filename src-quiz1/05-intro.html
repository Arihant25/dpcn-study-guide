DPCN Quiz 1 Guide

This guide covers the first part of the course: how to describe a network and how to measure it. It assumes you know nothing. Every topic starts in plain words with a small example, every symbol is explained when it first appears, and every proof the course uses is written as numbered steps with the reason for each step next to it.

The earlier, longer version of this guide is still available as the original Quiz 1 guide.

How each section is laid out

  1. What this is about, in plain words.
  2. What the exam can ask.
  3. The explanation, built from a small example.
  4. The derivation or method to learn, in a black-bordered box, as numbered steps.
