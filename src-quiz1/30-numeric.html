10Derivatives on a computer, Euler's method, and two solved models

Module 2c1 · slides 1–21 · Module 2c2 · slides 1–3

Most equations in this course cannot be solved with a formula, so a computer steps the solution forward in small time steps. This needs an approximation of the slope (derivative) from nearby values. This section derives the two standard approximations and their errors, gives Euler's stepping method, and solves the two simple models the slides use to test it. Fixed points and stability of these models are in Mid-sem guide §8.

What the exam can ask
  • Derive the forward and central difference formulas and show their errors are of order \(h\) and \(h^2\).
  • Write Euler's update rule and do one or two steps by hand.
  • Name and explain the two kinds of numerical error.
  • Solve \(\dot u = a - bu\) or the RC circuit exactly and find the fixed point.

Taylor's formula

Near a point \(x_0\), a smooth function is well approximated by its value, plus slope times the step, plus a correction for curvature, and so on:

\[f(x_0 + h) = f(x_0) + hf'(x_0) + \frac{h^2}{2}f''(x_0) + \frac{h^3}{6}f'''(x_0) + \dots\]

\(h\) is a small step. \(f'\), \(f''\), \(f'''\) are the first, second and third derivatives (slope, slope of the slope, and so on).

Derivation to learn · forward and central differences
  1. Forward difference. Rearrange Taylor's formula: \[\frac{f(x_0 + h) - f(x_0)}{h} = f'(x_0) + \frac h2f''(x_0) + \dots\] So "rise over run" equals the slope plus an error proportional to \(h\): first order, written \(O(h)\). Halving \(h\) halves the error.
  2. Step backwards too: \(f(x_0 - h) = f(x_0) - hf'(x_0) + \frac{h^2}{2}f''(x_0) - \frac{h^3}{6}f'''(x_0) + \dots\) (odd powers change sign).
  3. Subtract the two expansions. The \(f(x_0)\) and \(\frac{h^2}{2}f''\) terms cancel: \(f(x_0 + h) - f(x_0 - h) = 2hf'(x_0) + \frac{h^3}{3}f'''(x_0) + \dots\)
  4. Divide by \(2h\): \[\frac{f(x_0 + h) - f(x_0 - h)}{2h} = f'(x_0) + \frac{h^2}{6}f'''(x_0) + \dots\] The error is proportional to \(h^2\): second order, \(O(h^2)\). Halving \(h\) quarters the error.
Worked example · \(f = \sin x\) at \(x_0 = 1\), \(h = 0.1\)

True slope \(\cos1 = 0.5403\).

  • Forward: \(\frac{\sin1.1 - \sin1}{0.1} = \frac{0.8912 - 0.8415}{0.1} = 0.4974\), error \(-0.043\).
  • Central: \(\frac{\sin1.1 - \sin0.9}{0.2} = \frac{0.8912 - 0.7833}{0.2} = 0.5394\), error \(-0.0009\), about 50 times smaller for the same \(h\).

Euler's method (the tangent-line method)

To solve \(\dot y = f(t, y)\) from a starting value \(y(t_0) = y_0\): at the current point you know the slope (the equation gives it), so move a small step \(h\) along that straight line, then repeat from the new point.

\[y_{n+1} = y_n + h\,f(t_n, y_n)\]

It is the forward difference used backwards: \(\frac{y_{n+1} - y_n}{h}\approx f(t_n, y_n)\). Its error over a fixed time span is proportional to \(h\) (first order). The Runge–Kutta method (RK4, After mid-sem guide §11) averages four slopes per step and is much more accurate. (A MATLAB comment on slide 14 says "Runge–Kutta", but the code is plain Euler.)

Worked example · \(\dot y = 1 - y\), \(y_0 = 0.2\), \(h = 0.1\)
  1. \(y_1 = 0.2 + 0.1(1 - 0.2) = 0.28\).
  2. \(y_2 = 0.28 + 0.1(1 - 0.28) = 0.352\).
  3. Exact answer (below): \(y(0.2) = 1 - 0.8e^{-0.2} = 0.345\). Euler's 0.352 is close; a smaller \(h\) gets closer.

The two kinds of error

  • Truncation (discretisation) error: from dropping the higher terms of the Taylor series, i.e. from using a straight line instead of the curve. It would happen even on a perfect computer, and shrinks as \(h\) shrinks.
  • Round-off error: from the computer storing numbers with finitely many digits. A tiny \(h\) means many more steps and more rounding, so making \(h\) extremely small can make this worse.

Two models solved exactly

Derivation to learn · \(\dot u = a - bu\) (Model 1)
  1. Fixed point: \(a - bu^* = 0\Rightarrow u^* = a/b\). Slope \(f'(u) = -b < 0\) (for \(b > 0\)): stable.
  2. Separate: \(\frac{du}{a - bu} = dt\).
  3. Integrate from 0 to \(t\): \(-\frac1b\ln\frac{a - bu(t)}{a - bu(0)} = t\).
  4. Remove the log: \(a - bu(t) = (a - bu(0))e^{-bt}\), so \[u(t) = \frac ab + \left(u(0) - \frac ab\right)e^{-bt}.\]
  5. Check: at \(t = 0\) it gives \(u(0)\); as \(t\to\infty\) it gives \(a/b\), the fixed point. With \(a = b = 1\), \(u(0) = 0.2\): \(u(t) = 1 - 0.8e^{-t}\).
Derivation to learn · charging a capacitor (Model 2, the RC circuit)
  1. Kirchhoff's law around the loop: battery voltage = capacitor voltage + resistor voltage, \(V_0 = \frac qC + iR\), where \(q\) is the charge and \(i = \dot q\) the current.
  2. Rearrange: \(\dot q = \frac{V_0}{R} - \frac{q}{RC}\). This is Model 1 with \(a = V_0/R\), \(b = 1/(RC)\).
  3. Fixed point: \(q^* = a/b = CV_0\) (fully charged). Slope \(-\frac1{RC} < 0\): stable.
  4. Solution with \(q(0) = 0\): \(q(t) = CV_0\big(1 - e^{-t/RC}\big)\). It rises from 0 to the maximum \(CV_0\); \(RC\) is the time scale.
  5. Numbers (slide 20): \(V_0 = 1.5\), \(C = 0.5\), \(R = 1\): \(q^* = 0.75\), \(RC = 0.5\), and at \(t = 0.5\), \(q = 0.75(1 - e^{-1}) = 0.474\).

Slide 17 says a perturbation "decreases if \(f'(u^*) > 0\)"; it should be "\(< 0\)". Slide 26 writes the SIS recovery as \(i\to r\); for SIS it is \(i\to s\).

What to remember
  • Forward \(\frac{f(x+h) - f(x)}{h}\): error \(O(h)\). Central \(\frac{f(x+h) - f(x-h)}{2h}\): error \(O(h^2)\).
  • Euler: \(y_{n+1} = y_n + hf(t_n, y_n)\). Errors: truncation (method) and round-off (digits).
  • \(\dot u = a - bu\): \(u = \frac ab + (u_0 - \frac ab)e^{-bt}\). RC: \(q = CV_0(1 - e^{-t/RC})\).
