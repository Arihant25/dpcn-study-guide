Part 5Maps and chaos

11From a differential equation to a map

Deck 13 · slides 1–2, 10–13

Computers solve differential equations by taking small steps in time. If the step is too large, the numerical answer can behave completely differently from the true one. The slides use this to connect the smooth logistic equation to the logistic map, a step-by-step rule that can behave chaotically. This section also gives the Runge–Kutta method that the slides list.

Euler's step and the logistic map

Euler's method replaces the slope by "change over one step": \(\dot x\approx\frac{x_{n+1} - x_n}{\Delta t}\), so \(x_{n+1} = x_n + \Delta t\cdot f(x_n)\).

Derivation to learn · logistic equation → logistic map (slide 11)
  1. Start from \(\dot x = x(K - 1) - Kx^2\), a logistic equation with fixed point \(x^* = \frac{K-1}{K}\) (set \(x[(K-1) - Kx] = 0\)).
  2. Euler step: \(x_{n+1} = x_n + \Delta t\,[(K-1)x_n - Kx_n^2]\).
  3. Take the step size \(\Delta t = 1\): \(x_{n+1} = x_n + (K-1)x_n - Kx_n^2 = Kx_n - Kx_n^2\).
  4. So \(x_{n+1} = Kx_n(1 - x_n)\): the logistic map, with \(r = K\). Its non-zero fixed point \(1 - 1/K\) is the same as the equation's.

The smooth equation always settles at its fixed point. The map, as §12 and §13 show, can oscillate or become chaotic when \(K\) is large. The difference comes only from the large step. That is the point of the slide's question "what will be the ideal step size?": too large a step creates behaviour that is not in the real system.

For reference, the logistic equation \(\dot N = rN(1 - N/K)\) has the exact solution \(N(t) = \frac{K}{1 + Ae^{-rt}}\) with \(A = \frac{K - N_0}{N_0}\), the same S-shaped curve as the SIS solution in the Mid-sem guide.

The fourth-order Runge–Kutta method (RK4)

Euler uses the slope at the start of each step only. RK4 measures the slope at four places in the step and takes a weighted average:

\[\begin{aligned} k_1 &= f(t_j,\ y_j) && \text{(slope at the start)}\\ k_2 &= f\!\left(t_j + \tfrac h2,\ y_j + \tfrac h2k_1\right) && \text{(slope at the middle, using } k_1)\\ k_3 &= f\!\left(t_j + \tfrac h2,\ y_j + \tfrac h2k_2\right) && \text{(slope at the middle, using } k_2)\\ k_4 &= f(t_j + h,\ y_j + hk_3) && \text{(slope at the end)}\\ y_{j+1} &= y_j + h\left(\tfrac{k_1}{6} + \tfrac{k_2}{3} + \tfrac{k_3}{3} + \tfrac{k_4}{6}\right) \end{aligned}\]

The weights add to 1. The error for a fixed time span shrinks like the step size \(\Delta t\) for Euler, \((\Delta t)^2\) for improved Euler, and \((\Delta t)^4\) for RK4. Halving the step makes RK4 about 16 times more accurate.

What to remember
  • Euler with \(\Delta t = 1\) turns \(\dot x = x(K-1) - Kx^2\) into \(x_{n+1} = Kx_n(1 - x_n)\).
  • RK4: four slopes, weights \(\frac16, \frac13, \frac13, \frac16\). Error orders: Euler \(\Delta t\), improved Euler \((\Delta t)^2\), RK4 \((\Delta t)^4\).

12Stability of a map, and cobweb diagrams

Deck 13 · slides 13–21

For a map \(x_{n+1} = f(x_n)\), a fixed point is a value that maps to itself. Whether nearby values are pulled in or pushed away depends on the slope \(f'(x^*)\), but the rule is different from differential equations: what matters is whether the slope's size is less than 1. A cobweb diagram lets you see the iteration on paper.

What the exam can ask
  • Derive the condition for a stable fixed point of \(x_{n+1} = f(x_n)\). (2024 Quiz 2, 2 marks, both sets)
  • Find the fixed points and their stability for \(f(x) = x^2\), \(f(x) = \cos x\), \(f(x) = rx(1-x)\). (2024 Quiz 2, 3 marks)
Derivation to learn · stability of a map's fixed point
  1. Fixed point: \(x^* = f(x^*)\).
  2. Small error. Write \(x_n = x^* + \varepsilon_n\), with \(\varepsilon_n\) small.
  3. One step. \(x^* + \varepsilon_{n+1} = f(x^* + \varepsilon_n) \approx f(x^*) + f'(x^*)\,\varepsilon_n\) (value plus slope times change).
  4. Cancel \(x^* = f(x^*)\) from both sides: \(\varepsilon_{n+1} = f'(x^*)\,\varepsilon_n\).
  5. Repeat \(n\) times: \(\varepsilon_n = [f'(x^*)]^n\,\varepsilon_0\). Each step multiplies the error by the same number.
  6. Conclusion. Repeated multiplication by a number shrinks to 0 only if the number's size is below 1: \[|f'(x^*)| < 1\ \Rightarrow\ \text{stable}, \qquad |f'(x^*)| > 1\ \Rightarrow\ \text{unstable}, \qquad |f'(x^*)| = 1\ \Rightarrow\ \text{bifurcation point}.\]

Compare with a differential equation (Mid-sem §8), where only the sign of the slope mattered. A map with slope \(-0.5\) is stable (error halves and flips sign each step), but a map with slope \(-2\) is unstable even though the slope is negative. A negative slope makes the iterates jump from one side of \(x^*\) to the other.

Worked examples

\(f(x) = x^2\). Fixed points: \(x = x^2\Rightarrow x(x - 1) = 0\Rightarrow x^* = 0, 1\). Slope \(f'(x) = 2x\). \(|f'(0)| = 0 < 1\): stable. \(|f'(1)| = 2 > 1\): unstable. (Start at 0.9: 0.81, 0.66, 0.43, … goes to 0. Start at 1.1: 1.21, 1.46, … runs away.)

\(f(x) = \cos x\) (\(x\) in radians). Fixed point: \(x^* = \cos x^*\), solved by repeated substitution: start at 1: \(\cos1 = 0.540\), \(\cos0.540 = 0.858\), \(0.654\), \(0.794\), … settling at \(x^*\approx0.739\). Slope \(f'(x) = -\sin x\), \(|f'(0.739)| = \sin0.739 \approx 0.674 < 1\): stable. Negative slope, so the iterates zig-zag around 0.739 as they converge.

\(f(x) = rx(1 - x)\), the logistic map. Fixed points: \(x = rx(1-x)\Rightarrow x^* = 0\) or \(1 = r(1 - x)\Rightarrow x^* = 1 - \frac1r\). Slope \(f'(x) = r(1 - 2x)\).

  • \(f'(0) = r\): stable if \(r < 1\) (the population dies out).
  • \(f'(1 - \frac1r) = r\left(1 - 2 + \frac2r\right) = 2 - r\): stable if \(|2 - r| < 1\), that is \(1 < r < 3\).
  • At \(r = 3\), \(f' = -1\): a bifurcation (§13).

Numbers: \(r = 2.5\) gives \(x^* = 1 - 0.4 = 0.6\) with slope \(2 - 2.5 = -0.5\), stable. The slide's table confirms it: starting from 0.5 the iterates go 0.625, 0.586, 0.607, 0.597, … → 0.6.

Cobweb diagrams

Draw the curve \(y = f(x)\) and the diagonal \(y = x\). Start at \(x_0\) on the horizontal axis. Go vertically to the curve (that height is \(x_1 = f(x_0)\)), then horizontally to the diagonal (which moves you to \(x_1\) on the horizontal axis). Repeat. Fixed points are where the curve meets the diagonal.

What to remember
  • Map fixed point \(x^* = f(x^*)\), stable iff \(|f'(x^*)| < 1\).
  • Logistic map: \(x^* = 0\) stable for \(r < 1\); \(x^* = 1 - 1/r\) with \(f' = 2 - r\), stable for \(1 < r < 3\).
  • \(\cos x\): \(x^* = 0.739\), stable. \(x^2\): 0 stable, 1 unstable.

13Period doubling and the route to chaos

Deck 13 · slides 14, 22–26

As \(r\) increases past 3, the logistic map stops settling on one value and instead alternates between two values (a 2-cycle). Further on it alternates between 4, then 8, and so on, faster and faster, until about \(r = 3.57\) where the values never repeat: chaos. This sequence is the period-doubling route to chaos.

Derivation to learn · the 2-cycle
  1. A 2-cycle is a pair \(x_1, x_2\) with \(f(x_1) = x_2\) and \(f(x_2) = x_1\). So each is a fixed point of the twice-applied map: \(f(f(x)) = x\).
  2. For the logistic map this is a degree-4 equation. Two of its solutions are the ordinary fixed points (0 and \(1 - 1/r\)), which also satisfy it. Dividing those out leaves a quadratic, whose solutions are \[x_\pm = \frac{(r+1)\pm\sqrt{(r-3)(r+1)}}{2r}.\]
  3. These are real only if \((r - 3)(r + 1)\ge0\), that is \(r\ge3\). So the 2-cycle is born at \(r = 3\), exactly where the fixed point loses stability (its slope reaches \(-1\)). This is a period-doubling bifurcation.
  4. Numbers, \(r = 3.2\): \(\sqrt{0.2\times4.2} = \sqrt{0.84} = 0.9165\). \(x_\pm = \frac{4.2\pm0.9165}{6.4} = 0.7995\) and \(0.5130\). The slide's table shows the iterates from 0.5 going 0.800, 0.512, 0.7995, 0.5129, … exactly these two values.

Step 2 is quoted, not derived on the slides. The slides show it with plots of \(f(f(x))\): at \(r = 2.8\) it crosses the diagonal only at 0 and the fixed point; at \(r = 3.2\) it crosses at two more points, the 2-cycle.

\(r\)Long-run behaviourExample from the slides' table
\(r < 1\)extinction, \(x\to0\)\(r = 0.5\): 0.125, 0.055, 0.026, … → 0
\(1 < r < 3\)one fixed value \(1 - 1/r\)\(r = 1.5\) → 0.333; \(r = 2.5\) → 0.6
\(3 < r < 3.449\)2-cycle\(r = 3.2\): 0.7995, 0.5130
\(3.449 < r < 3.544\)4-cycle\(r = 3.5\): 0.875, 0.383, 0.827, 0.501
\(3.544 < r < 3.57\)8-cycle, 16-cycle, …\(r = 3.55\): an 8-cycle

\(r > 4\)values leave \([0, 1]\) and go to infinity

Chaos here means deterministic (a fixed rule, no randomness) yet never repeating, and extremely sensitive to the starting value: two starting values differing in the sixth decimal place give completely different sequences after a few dozen steps.

The slides end this topic with the Mandelbrot set: the complex map \(z_{k+1} = z_k^2 + c\). A complex number \(c\) belongs to the set if the iterates starting from 0 stay bounded. Its boundary is endlessly detailed.

What to remember
  • 2-cycle: \(f(f(x)) = x\); \(x_\pm = \frac{(r+1)\pm\sqrt{(r-3)(r+1)}}{2r}\), born at \(r = 3\) where \(f'(x^*) = -1\).
  • Doublings at 3, 3.449, 3.544, …; chaos from about 3.57; escape for \(r > 4\).

14The Lorenz system

Deck 13 · slides 4–9

Lorenz's three-variable model of air convection was the first famous example of chaos in a differential equation. For some parameter values its path never settles and never repeats, looping around two centres in a butterfly shape. The exam-style task is the one from 2024 Quiz 2: find the fixed points and their Jacobians.

What the exam can ask
  • Find the fixed points of the Lorenz system and construct the Jacobian at each. (2024 Quiz 2, 4 marks; "eigenvalue analysis is not required")
  • State when the origin is stable, and what the characteristic equation at \(P_1\) gives for given numbers.
\[\dot x = \sigma(y - x), \qquad \dot y = \rho x - y - xz, \qquad \dot z = -\beta z + xy\]

\(\sigma, \rho, \beta\) are positive constants (sigma, rho, beta). The usual values are \(\sigma = 10\), \(\beta = 8/3\). Slide 9 writes the same system with \(r\) for \(\rho\) and \(b\) for \(\beta\).

Derivation to learn · fixed points and Jacobians
  1. \(\dot x = 0\) gives \(\sigma(y - x) = 0\), so \(y = x\).
  2. \(\dot z = 0\) gives \(\beta z = xy = x^2\), so \(z = x^2/\beta\).
  3. \(\dot y = 0\) gives \(\rho x - x - xz = x(\rho - 1 - z) = 0\). So \(x = 0\), or \(z = \rho - 1\).
  4. Case \(x = 0\): then \(y = 0\), \(z = 0\). Fixed point \(P_0 = (0, 0, 0)\).
  5. Case \(z = \rho - 1\): from step 2, \(x^2 = \beta z = \beta(\rho - 1)\), so \(x = \pm\sqrt{\beta(\rho - 1)}\), real only if \(\rho > 1\). Fixed points \[P_{1,2} = \left(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho - 1\right).\]
  6. Jacobian (partial derivatives of each rate with respect to \(x, y, z\)): \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
  7. At \(P_0\): \(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}\). One eigenvalue is \(-\beta\) (the \(z\) row is separate); the other two come from the top-left block, \(\lambda^2 + (\sigma + 1)\lambda + \sigma(1 - \rho) = 0\). Both are negative exactly when \(\rho < 1\). So the origin is stable for \(\rho < 1\).
  8. At \(P_1\) (write \(c = \sqrt{\beta(\rho-1)}\), so \(\rho - z = 1\)): \[J(P_1) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & -c\\ c & c & -\beta\end{pmatrix}.\] At \(P_2\), replace \(c\) by \(-c\).
With numbers · \(\sigma = 10,\ \beta = 8/3,\ \rho = 23\) (slides 6–8)
  1. \(c = \sqrt{\frac83\times22} = \sqrt{58.67} = 7.66\). So \(P_{1,2} = (\pm7.66,\ \pm7.66,\ 22)\).
  2. The characteristic equation at \(P_1\) is \(\lambda^3 + (\beta + \sigma + 1)\lambda^2 + \beta(\rho + \sigma)\lambda + 2\beta\sigma(\rho - 1) = 0\).
  3. Coefficients: \(\beta + \sigma + 1 = \frac83 + 11 = \frac{41}{3}\); \(\beta(\rho + \sigma) = \frac83\times33 = 88\); \(2\beta\sigma(\rho - 1) = 2\times\frac83\times10\times22 = \frac{3520}{3}\).
  4. So \(\lambda^3 + \frac{41}{3}\lambda^2 + 88\lambda + \frac{3520}{3} = 0\), with roots \(\lambda = -13.56\) and \(-0.054\pm9.30i\).
  5. All real parts are negative, and there is a complex pair: \(P_1\) (and \(P_2\)) is a stable spiral. (Check: the roots add to \(-13.67 = -41/3\).)

The two non-zero fixed points stay stable up to \(\rho_c = \frac{\sigma(\sigma + \beta + 3)}{\sigma - \beta - 1} = 24.74\) (slide 9). Above it, the motion becomes chaotic. The slides add that between \(\rho = 13.93\) and \(24.06\) the system shows transient chaos (chaotic for a while before settling), and from 24.06 a chaotic attractor exists alongside the stable points.

What to remember
  • Fixed points: \((0,0,0)\) and \(\left(\pm\sqrt{\beta(\rho-1)}, \pm\sqrt{\beta(\rho-1)}, \rho - 1\right)\) for \(\rho > 1\).
  • \(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}\). Origin stable iff \(\rho < 1\).
  • \(\rho = 23\): \(P_{1,2}\) stable spirals. Chaos for \(\rho > 24.74\) (\(\sigma = 10, \beta = 8/3\)).
