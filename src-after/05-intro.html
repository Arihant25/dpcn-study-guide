MThe new maths you need

This half of the course uses a few tools that the first half did not: the determinant and eigenvalues of a 2×2 matrix, complex numbers, partial derivatives and iterated maps. Each is explained here with an example. Sums, integrals, e, ln and ordinary slopes are explained in section M of the Mid-sem guide.

M1 · Trace and determinant of a 2×2 matrix

For a 2×2 matrix \(A = \begin{pmatrix} a & b\\ c & d\end{pmatrix}\):

  • the trace is the sum of the diagonal, \(\tau = a + d\) (\(\tau\) is Greek "tau");
  • the determinant is "down-diagonal minus up-diagonal", \(\Delta = ad - bc\) (\(\Delta\) is Greek "delta").

Example: \(A = \begin{pmatrix}1 & 1\\ 4 & -2\end{pmatrix}\) has \(\tau = 1 + (-2) = -1\) and \(\Delta = 1\times(-2) - 1\times4 = -6\).

M2 · Eigenvalues and eigenvectors of a 2×2 matrix, step by step

Recall (Mid-sem guide M9): an eigenvector \(\mathbf v\) is a direction that the matrix only stretches, \(A\mathbf v = \lambda\mathbf v\), and the stretch \(\lambda\) is the eigenvalue. To find them:

  1. Eigenvalues. Solve the quadratic \(\lambda^2 - \tau\lambda + \Delta = 0\). By the quadratic formula, \[\lambda = \frac{\tau\pm\sqrt{\tau^2 - 4\Delta}}{2}.\] (Why this equation: \(A\mathbf v = \lambda\mathbf v\) means \((A - \lambda I)\mathbf v = 0\) for a non-zero \(\mathbf v\), which happens only when \(\det(A - \lambda I) = 0\). Multiplying out \((a - \lambda)(d - \lambda) - bc = 0\) gives exactly this quadratic.)
  2. Eigenvector for each \(\lambda\). Write \((A - \lambda I)\mathbf v = 0\), meaning subtract \(\lambda\) from both diagonal entries and multiply by \(\mathbf v = (v_1, v_2)\). The two rows give the same condition; use one of them to find the ratio \(v_2/v_1\). Any multiple of an eigenvector is also an eigenvector, so pick a simple one.
Worked example

\(A = \begin{pmatrix}1 & 1\\ 4 & -2\end{pmatrix}\), with \(\tau = -1\), \(\Delta = -6\).

  1. \(\lambda^2 + \lambda - 6 = 0\), which factorises as \((\lambda - 2)(\lambda + 3) = 0\). So \(\lambda_1 = 2\), \(\lambda_2 = -3\).
  2. For \(\lambda = 2\): \(A - 2I = \begin{pmatrix}-1 & 1\\ 4 & -4\end{pmatrix}\). The first row says \(-v_1 + v_2 = 0\), so \(v_2 = v_1\). Take \(\mathbf v_1 = (1, 1)\).
  3. For \(\lambda = -3\): \(A + 3I = \begin{pmatrix}4 & 1\\ 4 & 1\end{pmatrix}\). The first row says \(4v_1 + v_2 = 0\), so \(v_2 = -4v_1\). Take \(\mathbf v_2 = (1, -4)\).
  4. Check: \(A(1,1) = (1 + 1,\ 4 - 2) = (2, 2) = 2\times(1,1)\). Correct.

Two shortcuts: the eigenvalues always add up to the trace (\(2 + (-3) = -1\)) and multiply to the determinant (\(2\times(-3) = -6\)). For a triangular matrix (zeros above or below the diagonal), the eigenvalues are just the diagonal entries.

M3 · Complex numbers

Some quadratics have no real solution, for example \(\lambda^2 + 1 = 0\). We write \(i\) for a number with \(i^2 = -1\), so the solutions are \(\lambda = \pm i\). A complex number is \(a + ib\), with real part \(a\) and imaginary part \(b\). When \(\tau^2 - 4\Delta < 0\), the eigenvalues are a pair \(\lambda = \frac{\tau}{2}\pm i\frac{\sqrt{4\Delta - \tau^2}}{2}\).

The key fact is Euler's formula: \(e^{i\theta} = \cos\theta + i\sin\theta\). So

\[e^{(a + ib)t} = e^{at}\big(\cos bt + i\sin bt\big).\]

This is what a complex eigenvalue does to a solution. The real part \(a\) decides growth (\(a > 0\)) or decay (\(a < 0\)), and the imaginary part \(b\) makes it rotate (oscillate) at angular speed \(b\). If \(a = 0\), it just rotates forever.

Polar form. A complex number \(z = x + iy\) can be described by its distance \(r\) from 0 and its angle \(\theta\): \(z = re^{i\theta}\), with \(x = r\cos\theta\), \(y = r\sin\theta\), \(r = |z| = \sqrt{x^2 + y^2}\). Multiplying by \(e^{i\theta}\) rotates; multiplying by a positive number stretches.

Rate of change in polar form (by the product rule for slopes): if \(z = re^{i\theta}\) with \(r\) and \(\theta\) changing in time, then

\[\dot z = \dot r\,e^{i\theta} + r\,i\dot\theta\,e^{i\theta} = (\dot r + ir\dot\theta)\,e^{i\theta}.\]

M4 · Partial derivatives

For a formula with two variables, \(f(x, y)\), the partial derivative \(\frac{\partial f}{\partial x}\) is the slope in the \(x\) direction: differentiate as usual, treating \(y\) as a fixed number. Example with \(f = 3x - x^2 - 2xy\):

  • \(\frac{\partial f}{\partial x} = 3 - 2x - 2y\) (the \(-2xy\) term behaves like \(-2y\times x\), slope \(-2y\));
  • \(\frac{\partial f}{\partial y} = -2x\) (only the \(-2xy\) term contains \(y\)).

M5 · Maps (step-by-step systems)

A differential equation \(\dot x = f(x)\) changes smoothly in time. A map \(x_{n+1} = f(x_n)\) jumps in steps: given this year's value \(x_n\), the formula gives next year's \(x_{n+1}\). Example: \(x_{n+1} = 2x_n\) starting from \(x_0 = 1\) gives 1, 2, 4, 8, … A fixed point of a map is a value that maps to itself, \(x^* = f(x^*)\).

What to remember
  • \(\tau = a + d\), \(\Delta = ad - bc\). Eigenvalues \(\lambda = \frac{\tau\pm\sqrt{\tau^2 - 4\Delta}}{2}\). Eigenvectors from one row of \((A - \lambda I)\mathbf v = 0\).
  • \(e^{(a+ib)t} = e^{at}(\cos bt + i\sin bt)\): real part = grow or decay, imaginary part = rotate.
  • \(z = re^{i\theta}\), \(\dot z = (\dot r + ir\dot\theta)e^{i\theta}\).
Check yourself
CalcFind the eigenvalues of \(\begin{pmatrix}3 & 0\\ 0 & 2\end{pmatrix}\) and of \(\begin{pmatrix}0 & 1\\ -1 & 0\end{pmatrix}\).›

The first is diagonal, so the eigenvalues are 3 and 2. The second has \(\tau = 0\), \(\Delta = 0 - (1)(-1) = 1\), so \(\lambda^2 + 1 = 0\) and \(\lambda = \pm i\).

CalcWhat does \(e^{(-0.5 + 2i)t}\) do as time passes?›

It equals \(e^{-0.5t}(\cos2t + i\sin2t)\): it rotates with angular speed 2 while its size shrinks like \(e^{-0.5t}\). A spiral inwards.
