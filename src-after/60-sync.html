Part 6Synchronisation

15Two coupled oscillators

Deck 13 · slides 28–31 · 2024 mid-sem Q1

In 1665 Huygens noticed that two pendulum clocks hanging from the same beam end up swinging in step. Heart pacemaker cells, fireflies flashing together and audiences clapping in rhythm do the same: oscillators that interact weakly tend to synchronise. This section shows how two coupled limit-cycle oscillators reduce to equations for their angles (phases) alone, then finds when they lock to a common frequency.

What the exam can ask
  • Write two coupled Stuart–Landau oscillators in polar form and explain the weak-coupling (phase-only) approximation.
  • For two phase oscillators, find the critical coupling for a common frequency, and the common frequency. (2024 mid-sem Q1, 7 marks)

From oscillators to phases

Two limit-cycle oscillators (§9 with \(\mu = 1\)), each pulled towards the other with strength \(K\):

\[\dot Z_1 = (1 + i\omega_1 - |Z_1|^2)Z_1 + K(Z_2 - Z_1), \qquad \dot Z_2 = (1 + i\omega_2 - |Z_2|^2)Z_2 + K(Z_1 - Z_2).\]
Derivation to learn · polar form of the coupled pair
  1. Write \(Z_j = r_je^{i\theta_j}\). Then \(\dot Z_1 = (\dot r_1 + ir_1\dot\theta_1)e^{i\theta_1}\).
  2. Divide the first equation by \(e^{i\theta_1}\): \[\dot r_1 + ir_1\dot\theta_1 = (1 + i\omega_1 - r_1^2)r_1 - Kr_1 + Kr_2e^{i(\theta_2 - \theta_1)}.\] (Because \(Z_2/e^{i\theta_1} = r_2e^{i(\theta_2-\theta_1)}\).)
  3. Use \(e^{i\phi} = \cos\phi + i\sin\phi\) and match real parts: \[\dot r_1 = r_1(1 - K - r_1^2) + Kr_2\cos(\theta_2 - \theta_1).\]
  4. Match imaginary parts and divide by \(r_1\): \[\dot\theta_1 = \omega_1 + K\frac{r_2}{r_1}\sin(\theta_2 - \theta_1).\] The same for oscillator 2 with 1 and 2 swapped.
  5. Weak coupling. The sizes \(r_1, r_2\) relax quickly back to the limit cycle, while the phases interact slowly. So set \(r_1\approx r_2\approx\) constant. Then \(r_2/r_1 = 1\) and only the phases remain: \[\dot\theta_1 = \omega_1 + K\sin(\theta_2 - \theta_1), \qquad \dot\theta_2 = \omega_2 + K\sin(\theta_1 - \theta_2).\]

This is the two-oscillator Kuramoto model. Each phase moves at its own natural speed \(\omega\), plus a pull towards the other: if oscillator 2 is ahead (\(\theta_2 > \theta_1\) by a little), \(\sin(\theta_2 - \theta_1) > 0\) speeds oscillator 1 up.

When do they lock?

The 2024 mid-sem used different couplings: \(\dot\theta_1 = \omega_1 + k_1\sin(\theta_2 - \theta_1)\), \(\dot\theta_2 = \omega_2 + k_2\sin(\theta_1 - \theta_2)\).

Derivation to learn · locking condition and common frequency
  1. Phase difference. Let \(\phi = \theta_2 - \theta_1\). Subtract the equations, using \(\sin(\theta_1 - \theta_2) = -\sin\phi\): \[\dot\phi = (\omega_2 - \omega_1) - (k_1 + k_2)\sin\phi.\]
  2. Locking means a common frequency, so \(\theta_1\) and \(\theta_2\) grow at the same rate and \(\phi\) stops changing: a fixed point of the \(\phi\) equation. \(\dot\phi = 0\) gives \[\sin\phi^* = \frac{\omega_2 - \omega_1}{k_1 + k_2}.\]
  3. A sine is between \(-1\) and 1, so a solution exists only if \(|\omega_2 - \omega_1| \le k_1 + k_2\). The critical coupling is \[k_1 + k_2 = |\omega_2 - \omega_1| \qquad (\text{for } k_1 = k_2 = k:\ k_c = |\omega_2 - \omega_1|/2).\]
  4. Which fixed point is stable. The slope of \(\dot\phi\) with respect to \(\phi\) is \(-(k_1 + k_2)\cos\phi\). Negative (stable) when \(\cos\phi^* > 0\), the solution with \(\phi^*\) between \(-90°\) and \(90°\).
  5. The common frequency \(\Omega\). When locked, \(\dot\theta_1 = \dot\theta_2 = \Omega\): \(\Omega = \omega_1 + k_1\sin\phi^*\) and \(\Omega = \omega_2 - k_2\sin\phi^*\). Multiply the first by \(k_2\), the second by \(k_1\), and add, so the \(\sin\phi^*\) terms cancel: \[(k_1 + k_2)\Omega = k_2\omega_1 + k_1\omega_2 \quad\Rightarrow\quad \Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}.\] With equal couplings this is the plain average \((\omega_1 + \omega_2)/2\).
With the exam's numbers · \(k_1 = k_2 = 2\), \(\omega_1 = 2\), \(\omega_2 = 10\)
  1. Difference of natural frequencies: \(|\omega_2 - \omega_1| = 8\).
  2. Total coupling: \(k_1 + k_2 = 4\).
  3. Locking needs \(8\le4\), which is false. \(\sin\phi^* = 8/4 = 2\) has no solution.
  4. So there is no common, stable frequency: the phase difference keeps increasing and the oscillators drift. They would need \(k_1 + k_2\ge8\) (each \(k\ge4\)). If they did lock, the frequency would be \(\Omega = (2\times2 + 2\times10)/4 = 6\).

The loss of locking at \(k_1 + k_2 = |\Delta\omega|\) is a saddle-node bifurcation of the \(\phi\) equation: the stable and unstable values of \(\phi^*\) meet at \(90°\) and disappear.

What to remember
  • \(\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi\).
  • Lock iff \(|\omega_2 - \omega_1|\le k_1 + k_2\). Common frequency \(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}\).
Check yourself
Calc\(\omega_1 = 3\), \(\omega_2 = 5\), \(k_1 = 1\), \(k_2 = 3\). Do they lock? At what frequency, and at what phase difference?›

\(|\Delta\omega| = 2\le k_1 + k_2 = 4\): yes. \(\Omega = (3\times3 + 1\times5)/4 = 14/4 = 3.5\). \(\sin\phi^* = 2/4 = 0.5\), stable solution \(\phi^* = 30°\). Check: \(\omega_1 + k_1\sin\phi^* = 3 + 0.5 = 3.5\).

16The Kuramoto model · many oscillators

Deck 13 · slides 33–37, 46–48

Now take \(N\) oscillators, each with its own natural frequency, every one pulled towards every other. With weak coupling they ignore each other and drift; above a critical coupling a group of them starts moving together. Kuramoto's trick is to measure "how together" they are with one number, the order parameter, and to rewrite each oscillator's equation in terms of it.

What the exam can ask
  • Define the order parameter \(re^{i\psi}\) and explain \(r\) and \(\psi\).
  • Derive the mean-field form \(\dot\theta_i = \omega_i + Kr\sin(\psi - \theta_i)\).
  • State the critical coupling \(K_c = 2/(\pi g(0))\).
\[\dot\theta_i = \omega_i + \frac KN\sum_{j=1}^{N}\sin(\theta_j - \theta_i), \qquad i = 1, \dots, N\]

\(\theta_i\) is the phase (angle) of oscillator \(i\); \(\omega_i\) its natural frequency, drawn from a distribution \(g(\omega)\) that is symmetric about 0, \(g(\omega) = g(-\omega)\); \(K\) the coupling strength.

The order parameter

\[re^{i\psi} = \frac1N\sum_{j=1}^{N}e^{i\theta_j}\]

Think of each oscillator as a dot on a circle of radius 1 at angle \(\theta_j\). The right side is the average position of the dots. Its distance from the centre, \(r\), measures coherence: \(r = 1\) if all dots are at the same angle (perfect sync), \(r\approx0\) if they are spread evenly (no sync). Its angle \(\psi\) is the average phase.

Derivation to learn · the mean-field equation
  1. Multiply the definition by \(e^{-i\theta_i}\): \(re^{i(\psi - \theta_i)} = \frac1N\sum_je^{i(\theta_j - \theta_i)}\).
  2. Take the imaginary part of both sides (\(e^{ia}\) has imaginary part \(\sin a\)): \[r\sin(\psi - \theta_i) = \frac1N\sum_j\sin(\theta_j - \theta_i).\]
  3. The right side is exactly the coupling sum in the model (divided by \(K\)). Substitute: \[\dot\theta_i = \omega_i + Kr\sin(\psi - \theta_i).\]
  4. Meaning: each oscillator now feels only the average (the "mean field"), pulled towards the average phase \(\psi\) with strength \(Kr\). The more synchronised the population (larger \(r\)), the stronger the pull, which synchronises it further.
  5. Rotating frame. Measure all phases relative to the average, so \(\psi = 0\): \[\dot\theta_i = \omega_i - Kr\sin\theta_i.\]
  6. Who locks. Oscillator \(i\) stops drifting when \(\dot\theta_i = 0\), i.e. \(\sin\theta_i = \omega_i/(Kr)\), possible only if \(|\omega_i|\le Kr\). Oscillators with natural frequency close to the average lock; the others keep drifting (partial synchronisation).

The critical coupling

\[K_c = \frac{2}{\pi g(0)}\]

Below \(K_c\), \(r = 0\) (incoherence). Above it, \(r\) grows continuously from 0, a phase transition like the giant component in random graphs. \(g(0)\) is the height of the frequency distribution at its centre: the more oscillators have similar frequencies (tall, narrow \(g\)), the smaller the coupling needed.

For the Lorentzian distribution on the slides, \(g(\omega) = \frac{\gamma/\pi}{\gamma^2 + \omega^2}\), we get \(g(0) = \frac{1}{\pi\gamma}\), so \(K_c = 2\gamma\), and the exact result above it is \(r = \sqrt{1 - K_c/K}\). Example: \(\gamma = 1\) gives \(K_c = 2\); at \(K = 4\), \(r = \sqrt{0.5} = 0.71\).

Slide error and exam scope

Slides 33 and 34 write the critical coupling as \(2/(\pi g(0)N)\). The extra \(N\) is wrong (the \(1/N\) is already inside the coupling term); slide 46 derives \(K_c = 2/(\pi g(0))\). The derivation of \(K_c\) for infinitely many oscillators (slides 39 to 46) is marked "Advanced Topics (Not for exam)" on slide 38, so learn the result, not the derivation.

Explosive synchronisation (slides 47–48)

On a network, the coupling uses the adjacency matrix: \(\dot\theta_i = \omega_i + \lambda\sum_jA_{ij}\sin(\theta_j - \theta_i)\). In the paper on the slides (Gómez-Gardeñes et al., 2011) each node's natural frequency equals its degree. On random (ER) networks \(r\) rises smoothly with \(\lambda\). On scale-free (Barabási–Albert) networks it jumps suddenly from about 0 to about 0.9, at a different \(\lambda\) when increasing than when decreasing: a first-order, "explosive" transition with hysteresis.

What to remember
  • \(re^{i\psi} = \frac1N\sum_je^{i\theta_j}\): \(r\) = coherence (0 to 1), \(\psi\) = average phase.
  • \(\dot\theta_i = \omega_i + Kr\sin(\psi - \theta_i)\); rotating frame \(\dot\theta_i = \omega_i - Kr\sin\theta_i\); locked if \(|\omega_i|\le Kr\).
  • \(K_c = 2/(\pi g(0))\); Lorentzian: \(K_c = 2\gamma\), \(r = \sqrt{1 - K_c/K}\).
