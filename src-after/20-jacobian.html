5The Jacobian · zooming in on a fixed point

Deck 11 · slides 31–34, 54–57 · Deck 12 · slides 7–8

Real models are not linear: they contain terms like \(x^2\) or \(xy\). Such systems usually cannot be solved exactly. But if you zoom in very close to a fixed point, every smooth curve looks like a straight line, so the system looks linear there. The matrix of that linear approximation is called the Jacobian. Its eigenvalues then classify the fixed point exactly as in §2. This is the most used tool in the second half of the course.

What the exam can ask
  • Derive the linearisation \(\delta\dot{\mathbf x} = J\,\delta\mathbf x\) using a Taylor expansion.
  • Write the Jacobian of a given system and evaluate it at each fixed point.
  • State the stability rule in terms of the eigenvalues.

The system

\[\dot x_1 = f_1(x_1, x_2), \qquad \dot x_2 = f_2(x_1, x_2).\]

A fixed point \((x_1^*, x_2^*)\) is where both rates are zero: \(f_1(x_1^*, x_2^*) = 0\) and \(f_2(x_1^*, x_2^*) = 0\).

Derivation to learn · linearisation
  1. Push the system a little. Write \(x_1 = x_1^* + \delta x_1\), \(x_2 = x_2^* + \delta x_2\), where \(\delta x_1, \delta x_2\) are small. Since \(x_1^*\) is constant, \(\dot x_1 = \delta\dot x_1\).
  2. Taylor-expand each rate (the 2-variable version of "value plus slope times change"): \[\delta\dot x_1 = f_1(x_1^* + \delta x_1,\ x_2^* + \delta x_2) = f_1(x_1^*, x_2^*) + \frac{\partial f_1}{\partial x_1}\delta x_1 + \frac{\partial f_1}{\partial x_2}\delta x_2 + \dots\] and the same for \(f_2\). The partial derivatives are evaluated at the fixed point.
  3. Use the fixed-point condition. \(f_1(x_1^*, x_2^*) = 0\), and the "…" terms (products of small numbers) are tiny, so drop them.
  4. Write it as a matrix: \[\begin{pmatrix}\delta\dot x_1\\ \delta\dot x_2\end{pmatrix} = \underbrace{\begin{pmatrix}\frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2}\\[3pt] \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2}\end{pmatrix}}_{J\ \text{(Jacobian)}}\begin{pmatrix}\delta x_1\\ \delta x_2\end{pmatrix}.\]
  5. This is a linear system (§1), so the push behaves like \(c_1e^{\lambda_1t}\mathbf v_1 + c_2e^{\lambda_2t}\mathbf v_2\) with \(\lambda\) the eigenvalues of \(J\).
  6. Stability rule. If every eigenvalue has negative real part, the push dies out: stable. If any has positive real part: unstable. Then classify the type (saddle, node, spiral) with \(\tau\) and \(\Delta\) of \(J\), as in §2.

The slide's equation (5) has a small typo: it writes \(x_2^* + \delta x_1\) as the second argument; it should be \(x_2^* + \delta x_2\). The slide also says stability needs "the largest eigenvalue" negative; strictly it is the largest real part.

One limitation: if the eigenvalues are purely imaginary (a center for \(J\)), the linear picture cannot decide what the nonlinear system does, because the tiny dropped terms can tip it either way. The predator–prey model in §7 is an example.

What to remember
  • \(J_{ij} = \partial f_i/\partial x_j\), evaluated at the fixed point.
  • All eigenvalues with negative real part: stable. Any with positive real part: unstable.
  • Recipe: fixed points → \(J\) in general → \(J\) at each point → \(\tau, \Delta\) or eigenvalues → type.

6Rabbits vs sheep · a complete worked analysis

Deck 11 · slides 35–47

Rabbits and sheep eat the same grass. Each would grow to a natural limit on its own, but they compete. Rabbits breed faster; sheep win the fights over grass. The question is whether both can survive together. Working through this model is exactly the kind of long derivation an exam asks for, so it is shown here in full.

What the exam can ask
  • Find all four fixed points, the Jacobian, the eigenvalues and eigenvectors at each fixed point, and classify them.
  • Sketch the phase portrait and explain the outcome (competitive exclusion).
\[\dot x = x(3 - x - 2y), \qquad \dot y = y(2 - x - y)\]

\(x\) = rabbits, \(y\) = sheep. Read the rabbit equation: on their own (\(y = 0\)) rabbits grow logistically, \(\dot x = x(3 - x)\), up to 3. Each meeting with a sheep costs them, the \(-2xy\) term. Sheep on their own grow to 2, and meeting rabbits costs them less, \(-xy\). (Logistic growth is explained in §8 of the Mid-sem guide.)

Derivation to learn · the full analysis
  1. Fixed points. \(\dot x = 0\) when \(x = 0\) or \(x + 2y = 3\). \(\dot y = 0\) when \(y = 0\) or \(x + y = 2\). Combine one condition from each:
    • \(x = 0,\ y = 0\): \((0, 0)\), nobody.
    • \(x = 0,\ x + y = 2\): \((0, 2)\), sheep only.
    • \(x + 2y = 3,\ y = 0\): \((3, 0)\), rabbits only.
    • \(x + 2y = 3,\ x + y = 2\): subtract to get \(y = 1\), then \(x = 1\). \((1, 1)\), both.
  2. Jacobian. Multiply out: \(f_1 = 3x - x^2 - 2xy\), \(f_2 = 2y - xy - y^2\). Partial derivatives (M4): \[J = \begin{pmatrix}3 - 2x - 2y & -2x\\ -y & 2 - x - 2y\end{pmatrix}.\]
  3. At \((0,0)\): \(J = \begin{pmatrix}3 & 0\\ 0 & 2\end{pmatrix}\). Diagonal, so \(\lambda = 3\) (eigenvector \((1,0)\)) and \(\lambda = 2\) (eigenvector \((0,1)\)). Both positive: unstable node. Paths leave along the slower direction, \((0,1)\), the \(y\)-axis.
  4. At \((3,0)\): \(J = \begin{pmatrix}3 - 6 & -6\\ 0 & 2 - 3\end{pmatrix} = \begin{pmatrix}-3 & -6\\ 0 & -1\end{pmatrix}\). Triangular, so \(\lambda = -3, -1\). Both negative: stable node. Eigenvector for \(-1\): row 1 of \(J + I\) is \(-2v_1 - 6v_2 = 0\), so \(\mathbf v = (3, -1)\). For \(-3\): \((1, 0)\). Paths come in along the slow direction \((3, -1)\).
  5. At \((0,2)\): \(J = \begin{pmatrix}3 - 4 & 0\\ -2 & 2 - 4\end{pmatrix} = \begin{pmatrix}-1 & 0\\ -2 & -2\end{pmatrix}\). Triangular, \(\lambda = -1, -2\): stable node. Eigenvector for \(-1\): row 2 of \(J + I\) is \(-2v_1 - v_2 = 0\), so \((1, -2)\). For \(-2\): \((0, 1)\).
  6. At \((1,1)\): \(J = \begin{pmatrix}3 - 2 - 2 & -2\\ -1 & 2 - 1 - 2\end{pmatrix} = \begin{pmatrix}-1 & -2\\ -1 & -1\end{pmatrix}\). \(\tau = -2\), \(\Delta = (-1)(-1) - (-2)(-1) = 1 - 2 = -1 < 0\): saddle. Eigenvalues from \(\lambda^2 + 2\lambda - 1 = 0\): \(\lambda = -1\pm\sqrt2\approx0.41,\ -2.41\).
  7. Conclusion. The only stable states are "rabbits only" and "sheep only". The coexistence point is a saddle, so it is never reached in practice.

This is the principle of competitive exclusion: two species competing for the same limited resource generally cannot coexist; one drives the other to extinction. Which one wins depends on where you start relative to the stable manifold.

The slides label the eigenvalues at \((3,0)\) and \((0,2)\) inconsistently (the subscripts 1 and 2 are swapped in places). The eigenvalues and eigenvectors themselves, as given above, are correct.

What to remember
  • Fixed points \((0,0)\) unstable node, \((3,0)\) and \((0,2)\) stable nodes, \((1,1)\) saddle.
  • \(J = \begin{pmatrix}3 - 2x - 2y & -2x\\ -y & 2 - x - 2y\end{pmatrix}\).
  • Competitive exclusion; the saddle's stable manifold separates the two outcomes.

7Predator and prey (Lotka–Volterra)

Deck 11 · slides 48–60

Records of Canadian lynx (predators) and snowshoe hares (prey) show both populations rising and falling in a roughly 10-year cycle, with the lynx peaks just after the hare peaks. More hares feed more lynx; more lynx eat more hares; the hares crash; the lynx starve; the hares recover. Volterra's model reproduces this cycle.

What the exam can ask
  • Write the model from its assumptions and explain each parameter.
  • Find the fixed points and the Jacobian, and classify the fixed points.

The model

Volterra's two assumptions: (1) per prey, the prey growth rate is a constant \(a\) without predators and falls in proportion to the number of predators; (2) per predator, the predator growth rate is negative (\(-d\)) without prey and rises in proportion to the number of prey.

\[\frac1N\frac{dN}{dt} = a - bP, \quad \frac1P\frac{dP}{dt} = cN - d \qquad\Longleftrightarrow\qquad \dot N = N(a - bP),\quad \dot P = P(cN - d)\]
SymbolMeaning
\(N\), \(P\)prey and predator populations
\(a\)how fast prey reproduce
\(b\)how fast prey are killed by predators
\(c\)how fast predators reproduce when fed on prey
\(d\)how fast predators die
Derivation to learn · fixed points and stability
  1. Fixed points. \(\dot N = 0\) when \(N = 0\) or \(P = a/b\). \(\dot P = 0\) when \(P = 0\) or \(N = d/c\). Combining: \((0, 0)\) and \((d/c,\ a/b)\).
  2. Jacobian. \(f_1 = aN - bNP\), \(f_2 = cNP - dP\): \[J = \begin{pmatrix}a - bP & -bN\\ cP & cN - d\end{pmatrix}.\]
  3. At \((0,0)\): \(J = \begin{pmatrix}a & 0\\ 0 & -d\end{pmatrix}\), \(\lambda = a > 0\) and \(-d < 0\): saddle. (Prey alone grow; predators alone die.)
  4. At \((d/c,\ a/b)\): \(a - b\cdot\frac ab = 0\), \(-b\cdot\frac dc\), \(c\cdot\frac ab\), \(c\cdot\frac dc - d = 0\): \[J = \begin{pmatrix}0 & -\frac{bd}{c}\\ \frac{ac}{b} & 0\end{pmatrix}.\]
  5. \(\tau = 0\), \(\Delta = 0 - \left(-\frac{bd}{c}\right)\left(\frac{ac}{b}\right) = ad > 0\). So \(\lambda^2 + ad = 0\Rightarrow\lambda = \pm i\sqrt{ad}\): purely imaginary, a center. The populations cycle around \((d/c, a/b)\).
Slide error

Slide 58 gives the eigenvalues at \((d/c, a/b)\) as \(\pm i\sqrt{ca}\). The correct value is \(\pm i\sqrt{ad}\), from \(\Delta = ad\) above. The conclusion (center) is unchanged. The small cycles near the fixed point have angular frequency \(\sqrt{ad}\), period \(2\pi/\sqrt{ad}\).

As noted in §5, a linear center does not by itself prove the nonlinear orbits close. For this model they do close, because the quantity \(cN - d\ln N + bP - a\ln P\) stays constant along every path (not on the slides; mention only if asked). The slide's MATLAB code comment says "Runge–Kutta 4th order", but the code is plain Euler, which makes the simulated cycles slowly spiral outwards.

What to remember
  • \(\dot N = N(a - bP)\), \(\dot P = P(cN - d)\).
  • \((0,0)\): saddle. \((d/c, a/b)\): center, \(\lambda = \pm i\sqrt{ad}\).
